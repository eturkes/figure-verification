# Figure integrity — the verification model (M19 law)

Binding sources: `.agent/spec.md` `Intent` + Decisions "Integrity-redesign rulings" + "M19 readings". This file = the rule matrix every M19 unit implements; a rule changes here first.

## Trust + flow

- Program = model-authored bytes, run UNCHANGED in the host's sandbox (OWUI's Pyodide; nucllei's nsjail jail, `.claude/rules/nucllei.md`); non-adversarial (ruling 7): no pre-run gate, the program shares the reader's interpreter. Python itself rejects invalid Python.
- `CLAUDE.md` `Execution` Charts + figures clause INAPPLICABLE to verification inputs (user ruling): the rule corpus `tests/figure_corpus/`, the banner arms + stub programs (`webui/banner.json`) + every test program = inputs whose form is the rule under test, misleading by design where the case says so. The clause binds a figure the repo publishes as its own deliverable (none today).
- Wrapper (RPC code) = loader prelude → reader source (base64, `<figure-reader>`) installs hooks → program exec'd as `<verified-figure>` (its stdout → a sink, warnings recorded, any exception caught) → every figure the program shows, or leaves open at its end, is drawn once + described → stdout = ONE tagged description line + ONE PNG line (exactly one figure only).
- Reader = trusted FACT reporter (`src/verifier/figure/reader.py`, matplotlib + pandas imported lazily; the one `verifier` module outside stdlib). Judge = stdlib core (`src/verifier/figure/`) = every DECISION. A fact the judge needs is reported; a decision never lives in the reader.
- Hooks: `Text.set_text` → a text's `site` = the last program line that set it OUTSIDE a draw (`Text.draw` re-sets its own text, so `show`/`savefig` would become every text's site). `Artist.__init__` → `site` = innermost `<verified-figure>` frame line, `origin` = qualname of the OUTERMOST frame in `matplotlib.axes._axes` / `matplotlib.axes._base` / `matplotlib.stackplot` (pyplot + pandas frames skipped; `plt.bar` ≡ `ax.bar`; `hist` wins over its inner `bar`). Call recorder on axis-altering methods → `calls` (slot → its LAST call the program made, directly or through pyplot + the reader's own pyplot hooks, recorded once matplotlib accepts it: a refused call sets nothing; its clock is taken as it STARTS, and a slot keeps the accepted call that started last — a setter a callback runs inside the call started later and decided the property). Slot `style` (`plt.xticks`/`plt.yticks` given any argument but `minor`, on the axes pyplot looks up BEFORE the call; `Axes.tick_params` per axis its `axis` names; `Axis.set_tick_params`) = tick style: listed in the figure row (a tick font can drop a glyph) + the axes row, never a site. Input recorders on `hist` / `pie` / `fill_between` / `stackplot` attach the call's arrays to the artists they return. `site` + `calls` are DISPLAY ONLY (ruling 13); `origin` = family attribution, never proof of geometry — final artist properties decide every rule.
- Sandbox = Open WebUI 0.12.3's Pyodide 314.0.3 (CPython 3.14.2; the Pyodide release 0.11.3 shipped): matplotlib 3.10.8, pandas 3.0.2, numpy 2.4.3 + seaborn 0.13.2 (loaded for a program naming it, Q73; seaborn draws through `Axes` methods ⇒ origins + rules as above; its default error bars / CI band + `histplot` counts block, so the chart rules ask for `errorbar=None` + `plt.hist` (Q76); `hue` legends name their series through legend proxies, Q75). Gate host = the same four releases ⇒ a host-green corpus claim is still a host claim until its Pyodide leg (`.agent/measurements/`) reruns; I1 + I3 measure host = bundle on every census program. Earlier bundles drew differently, and the judge keeps reading both forms: 3.10 draws `fill_between` + `stackplot` as `FillBetweenPolyCollection` (3.8 + 3.9: `PolyCollection`) ⇒ both judged bands; `axhspan`/`axvspan` = `Rectangle` (3.9 + 3.10) vs `Polygon` (3.8) ⇒ both shapes judged; a missing glyph's warning = `… missing from font(s) …` (3.9 + 3.10) vs `… missing from current font.` (3.8) ⇒ the reader matches both; mathtext reports a glyph its font set lacks on the `matplotlib.mathtext` LOGGER (`Font … does not have a glyph for …`), never `warnings` ⇒ the reader counts each at `_mathtext._log.warning` itself, ahead of logger levels + `logging.disable`, and clears the module-wide parse cache per reply; path text (`TextPath`, a text marker) lays a missing glyph out as `.notdef` and warns nothing ⇒ the reader counts each index-0 glyph `_text_helpers.layout` yields (both versions; F7 `ja-mathtext`, `ja-marker-repeat`, `ja-textpath`). nucllei target (Q82) = the nucllei sandbox image (local build of `v20261020-01`: CPython 3.12.15, matplotlib 3.11.2, pandas 2.3.3, numpy 2.5.4, seaborn 0.13.2); its corpus leg = measurement NS (255 cases, one expected difference: `missing-glyph` passes by the jail's font); matplotlib 3.11 adds a pie's wedges before its labels (reader + judge unaffected). Pyodide leg of the rule corpus = measurement C1 (every case through the production wrapper in the installed bundle, judged on the host; bundle = host = expectation on all cases).

## Closed artist set (parts)

- Figure: exactly one shown figure (`no_figure` / `multiple_figures`). Children: patch · judged axes · `suptitle` (judged title) · figure legends (judged) · figure texts (listed) · anything else → `artist_not_judged`; `FigureImage` → `raster_image`.
- Axes: class exactly `Axes`, owned by the figure (`fig.axes`), never a child of another axes (inset) → else `axes_not_judged` (polar, 3D, `SecondaryAxis`, inset). A colorbar axes passes only as the colorbar of a judged scatter, holding its own solids + dividers alone, its tick labels naming their values. A rotated bar is no bar. Two judged axes sharing an axis at the same position = `axes_twin` (G2); overlapping positions otherwise = `axes_overlap`. Each panel judged alone.
- Axes children = structural slots (patch, 4 spines, x/y axis, 3 titles, legend) + data artists keyed (class, origin):

| family | class | origin |
|---|---|---|
| line | `Line2D` | `Axes.plot` `Axes.step` |
| scatter | `PathCollection` | `Axes.scatter` |
| bar | `Rectangle` in a `BarContainer` | `Axes.bar` `Axes.barh` |
| hist | `Rectangle` in a `BarContainer` | `Axes.hist` (histtype `bar`, one dataset) |
| pie | `Wedge` (+ its label/autopct `Text`) | `Axes.pie` |
| area | `FillBetweenPolyCollection` (3.10) / `PolyCollection` (3.8, 3.9) with recorded arrays | `Axes.fill_between` `stackplot` |
| area outline | `Line2D` = an area band's top edge | `Axes.plot` |
| reference | `Line2D` / `Rectangle` / `Polygon` | `Axes.axhline` `Axes.axvline` `Axes.axhspan` `Axes.axvspan` |
| text (listed, never judged) | `Text` `Annotation` | `Axes.text` `Axes.annotate` `Axes.bar_label` |
| legend proxy (no mark; Q75) | a zero-size `Rectangle` / a `Line2D` holding no point | none (the program added it: seaborn's `hue` keys), the handle of an entry of its OWN axes' legend; inked, untargeted or another class ⇒ `artist_not_judged` |

  Anything else → `artist_not_judged` naming class + origin (errorbar, boxplot, violin, contour, hexbin, quiver, table, user patches, `fill_betweenx`, step/stepfilled hist, …); `AxesImage` / `QuadMesh` from `imshow`/`pcolormesh`/`matshow` → `raster_image`. An axes holding no data artist → `no_data`.

## Axes rules

- `mark_not_in_data`: a data artist's data-bearing transform ≠ `transData` (line/area/pie: `get_transform`; bar: `get_data_transform`; scatter: `get_offset_transform`); reference marks: their data coordinate on the blended data axis (user: closed reference family).
- `scale_not_linear` (R3): a non-linear axis passes only when it is `log` AND that axis label or the panel title names it (`log`, `logarithmic`, `対数`, word-bounded / containment for JA); every other scale blocks.
- `axis_inverted`: either axis inverted (ruling 3; both axes).
- `tick_label_mismatch`: a visible non-empty tick label in view — major, or minor (the default minor formatter writes none) — must denote its position. Category axis: the category at that position. Date axis: a trusted date formatter (matplotlib.dates / pandas) passes; any other label must parse (ISO `YYYY-MM-DD[ HH:MM[:SS]]` | `YYYY-MM`) to the reader's date at that position. Numeric axis with a value role: the label parses as a number (NFKC; `−`→`-`; mathtext `$\mathdefault{…}$`, `10^{k}`, `a\times10^{k}`; `,` thousands; one leading `$ ¥ € £`; trailing `%` ⇒ candidates v/100 and v; one SI prefix (`1k` at 1000), powers `b^{k}` exact) whose value × 10^order + offset (ScalarFormatter) lies within half a unit of its last shown digit of the position. Numeric key axis carrying set labels (`set_ticklabels` / pandas / FixedFormatter) = a LABELLED KEY axis: its labels are keys (values row), not numbers.
- `point_clipped`: any drawn data coordinate (points, bar base + top, band vertices, every reference coordinate) outside the view interval; pie wedges are exempt (matplotlib draws them unclipped). A panel drawing a non-finite coordinate is read by `value_not_finite` alone (marks stage): autoscale skips that point, so its finite key can sit outside the limits (luna F3).
- `zero_not_in_limits` (R1): a magnitude mark (bar, hist, area) ⇒ 0 inside its value-axis view interval. Line + scatter may autoscale.

## Mark rules

- `mark_hidden`: a hidden axes, or a data artist not visible, alpha 0, or drawing no ink (transparent face + edge, no line and no marker, zero marker size); a scatter blocks when ANY point draws no ink (its cycled size 0, or a clear face with no visible edge).
- `value_not_finite`: NaN / ±inf among drawn data or recorded inputs, or a band that drew fewer points than its call received (a dropped point).
- `bar_not_from_zero` (G1, R1): every bar's base = 0, or (stacked) exactly the far end of another bar at the same position + thickness on the same side of 0.
- `bars_overlap`: two bars' rectangles overlap with positive area (grouped bars sit side by side).
- `category_not_unique`: two points of one series share a key (G8 overplot).
- `x_not_ordered` (G9): a line's key positions run both ways (monotone either way passes).
- `hist_counts`: hist rects contiguous on the recorded bin edges, heights = counts (or density) of the recorded inputs over those edges (numpy semantics, last bin closed); an input outside the edges, weights, `cumulative` or > 1 dataset blocks.
- `pie_not_whole`: wedges share one radius + width (an exploded centre passes), spans contiguous, total 360°, each span = 360 · value / Σ values (recorded inputs; |Δ| ≤ 1e-4°: matplotlib computes angles in float32); a partial `normalize=False` pie misses 360°.
- `area_not_from_zero`: each band GROUNDED: its base edge all zero, or exactly the far edge of a grounded band at the same x (bands resting only on each other block); arrays = the final polygon read back in the `fill_between` layout.
- `marker_size_varies` / `marker_color_varies`: a scatter collection whose sizes / face colours vary passes only with a size legend from that collection's `legend_elements("sizes")` / a colorbar or colour key (`legend_elements()`) of that collection (`mark_rules.py::_check_scatter`).
- `legend_mismatch`: each legend entry names one judged mark (handle = that artist/container anywhere in the figure, or a proxy with a mark's label + colour, or a legend proxy of its axes naming the ONE series mark of its RGB whose own label is hidden — empty or `_`-prefixed, as seaborn's bars + lines are (Q75)), or is a `legend_elements` key of a judged scatter; a series takes ONE name, keyed by its first artist (two bars of one container = one series; a pie names each wedge); with ≥ 2 series (line, points, bars, area) in a legended axes, every one named; pies + reference marks may stay unnamed.

## Values (ruling 4; R2, R4; user: series filter, ties)

- Reference marks: each value = zero, a request number, or a cell / whole-column reduction; a value one column alone holds draws that column, one several columns hold draws none (published as held by several columns).
- Pie keys = each wedge's drawn label Text (final text; removed, hidden, blank = none), else the legend entry naming the wedge; drawn labels are listed as unchecked text only when no values were compared.
- Series = one line · scatter collection · bar container · pie · area band · reference mark · hist input · each scatter channel a colorbar or legend key SHOWS (R8: colour values via colorbar / `legend_elements()`, sizes via `legend_elements("sizes")`; a shorter array cycles; keyed like the scatter's points). Name = the legend entry naming it (axes or figure legend); a label no legend shows names nothing. Point = (key, value); key = category (category axis), reader ISO date (date axis), number (numeric axis), label text or position slot (labelled key axis: the label within half the gap between labelled ticks, else an integral position j ≥ 0 = slot j, bound to the explanation's key order — pandas' order, or a raw explanation's key-sorted order, which a pivot draws; any other position = no key).
- Sources: each attached CSV (`csvread` profile; non-profile columns unusable) + the request (= every user message on the chat branch, `webui/paste_in/owui_files.py::request_text`; NFKC numbers incl. `,` thousands as both readings; integer ranges `a through b`, `a to b`, `a–b`, `a〜b`/`a~b`, `aからbまで`, ≤ 10,000 terms per request in total, a range past what is left = its ends alone (M21.1 F3: the request has no length cap); ASCII hyphen never a range).
- CSV explanations (closed): `raw(K,V)` (incl. `raw(K,K)`: a channel encoding its own point's key) · `index(V)` (row position) · `group(K,V,r)` r ∈ sum mean min max · `count(K)` · scalar `reduce(V,r)` / raw cell (reference marks). A series whose legend label equals cell values of column C draws from rows where C = label (user); C may be its key (the series shows its own label), and two filter columns over the same drawn columns are one reading (the first filter column in header order is published). Matching = injective rows (a row backs one point; slots bind before keyed points) with exact binary64 values (stacked: fl(base + c) = top); a channel point binds to its own scatter point's row or group (R8: its explanation is the scatter's, another numeric column or one reduction of it per group); a strict subset passes + publishes `N of M` (R2); no other pre-reduction filter.
- Per value EITHER (ruling 4): one CSV explanation per series, any point it leaves explained by request numbers (value) + request keys (numeric key ∈ numbers or default positions; text key ∈ casefolded NFKC request, R4 → else `label_not_in_request`). Mark-intrinsic arithmetic (stack offsets, hist counts, pie shares) is the mark's rule. Unexplained point ⇒ `value_not_found` (fix: attach a CSV or write the values out); `label_not_in_request` only for a typed value no file explanation backs. No source at all ⇒ integrity alone, disclosed.
- Ties: ≥ 2 explanations with different column sets fully explain one series ⇒ the request breaks it when it names the columns of exactly one, else `column_not_requested` (user). Same columns, different reductions (group of 1 ≡ raw) ⇒ canonical = raw, then the first of sum mean min max.
- **Computed values (Q45, user, session 10; contract `.agent/archive/contracts/q45.md`).** The judge runs values + columns twice at most (`judge.py::judge`): pass 1 = the vocabulary above; a pass-1 block on `value_not_found` / `label_not_in_request` / `column_not_requested` / `column_not_named` / `label_not_consistent` reruns them with `explain(…, admitted=True)` (fresh `MAX_WORK`), where `explain.py::computations` compete with the vocabulary per series (same columns ⇒ vocabulary, then `src/verifier/figure/computed.py::ORDER`, then a computation drawn whole before one drawn in part, then base family; different columns ⇒ R7), then `explain.py::_typed` (one computation of `Request.sequence`, membership, R4 keys) for a series still unexplained. Pass 2 passing publishes; when pass 1 blocked on a VALUE and pass 2 explained every series (`judge.py::_values` flag) but blocks on a column, pass 2's column reason surfaces; else pass 1's verdict stands. Closed list (`computed.py`): of one vocabulary explanation in its pair order — `square` v·v, `cumsum` sequential, `diff` (pair 0 drops), `share` v/T, `percent` (100v)/T | (v/T)·100 | v·(100/T), T ∈ {numpy pairwise (stdlib replica), sequential, CPython Neumaier, pandas Kahan, `math.fsum`}; of numeric columns a ≠ b — `ratio` `difference` `product` `total`, per row (keyed by any column or row position) or over both columns' Kahan sums per group of a third column. Every variant matched EXACTLY (no tolerance); a non-finite value or a zero denominator is no candidate. Channels (R8) take the same per-row/per-group computations bound to their point's row or group, computed mains included (`Explanation.rows` carries a row-keyed computation's source rows); scaling by a constant is none. Reference marks take none. G10: a one-series computation keeps its base's reduction; a ratio of group sums contributes `mean`, its other ops `sum`; per row none (`explain.py::summary`). Chance rates = measurement X1 (shipped candidates + matcher), published beside each computation in `docs/verification.md`.

Anchoring = the shipped matcher (`anchoring.py`, law `.claude/rules/pysrc.md`): substitution (demo) | strict (production), aliases, short words + suffixes, Q38 stops + negation.
- G10 (`label_not_consistent`): titles, axis labels, axes legend entries, the panel's colorbar labels (against that panel's reductions) + suptitle/supxlabel/supylabel, figure legend entries (against every panel's) naming a header column neither drawn nor a drawn series' R6 filter column (it draws nothing, yet the legend shows its values: `Revenue by month and region`, luna F1; `columns.py::_labelled`); over a reduction, another reduction's summary word.
- Publication (tier 3): per-group counts beside every reduction (G11), `N of M` subsets, listed on-chart text, integrity-only status.
