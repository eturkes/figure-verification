# Assurance law — test design + process (earned across M1–M12)

Test design:
- 100% branch coverage answers "did the line execute", never "does a red exist": it misses data-domain gaps, lookup-table entries, a line's EFFECT, and each conjunct of a compound guard. Coverage scope is package-NAME based ⇒ a test loading a MUTATED module copy registers it under a name OUTSIDE `verifier`. Credit EVERY applied fix by its own mutation, keyword flips included; the pin is a test reaching a DIFFERENT verdict under the mutant. MAIN's rerun: `-x --no-cov`, require nonzero rc, restore bytes + verify sha256 in a `finally`; a message-only mutation is NOT a predicate mutation — neuter the condition; where dataset/formula twins make whole-file anchors ambiguous, anchor on the enclosing function (last occurrence, asserted after the formula block marker); clear `src/**/__pycache__` after a same-size mutate/restore (CPython invalidates on mtime+size, so a same-size restore reuses the MUTANT code object).
- A test that reads a production constant to build its expectation pins NOTHING ⇒ hand-state closed maps as LITERALS. An exact key-set assertion pins shape, never values. A fail-closed allowlist/registry needs its refusal pinned against NEAR-MISS inputs of the same family + every id a later unit intends to add.
- CLOSED dispatch enumerates every admitted variant: an `else:` tail or `.get(k, default)` over a variant space is a catch-all — this repo's most-repeated defect class — treat it as a defect until a near-miss refusal pins it.
- ORDERING needs call-counting bombs on the downstream work, one per refusal reason, never outcome assertions; a duplicated predicate hides its earlier copy from exception-based tests. Caller-supplied policy is pinned as THREADED at every public entry separately, with a policy STRICTER than default; equal-value arguments hide threading defects ⇒ argument SPY + a witness where the values diverge. Threading: patch the SEAM itself, arm the layer beneath as a bomb, assert identity (`is`).
- A FAKE must match the real API's strictness: a tolerant fake un-pins the finding it was built for (a fake ignoring a kwarg leaves it unpinned at 100% branch). Assert on the recorded call; reject what the real object rejects.
- Module-level dispatch maps bind function objects at import ⇒ `monkeypatch.setattr` no-ops silently; spy the entry with `monkeypatch.setitem` and annotate such maps `dict[...]`. Under `mypy --strict`, patch the directly-imported module/class object, never through another module.
- A purity bomb on a global PYTEST ITSELF uses (`os.environ`, `builtins.open`) must be withdrawn inside the test BODY under `with monkeypatch.context() as m:`, asserting after the block. Fixture teardown runs after the call-phase report, and pytest's progress writer reads `os.environ['COLUMNS']` through `shutil.get_terminal_size` in exactly that window ⇒ the test PASSES and the whole run dies as INTERNALERROR whose traceback names the bomb, hiding every other result. It surfaces only once the code under test stops raising early, so a suite written against absent modules looks clean and the crash arrives with the implementation.
- Split canonical FORM (byte-exact under an injected fixed TCB, across MEASURED interpreter patches alone) from provenance WIRING (each field equals its live source, loading no vector; `__struct_fields__` pinned as an exact set). A regenerated vector is co-derived ⇒ pair it with a HAND-AUTHORED one.
- Guard witnesses MIXED not uniform; independent bounds need their JOINT corner; declared-parameter authority needs a DISAGREEMENT witness; exactness witnesses include a non-binary decimal (0.2) — `Decimal(repr(f))` is an unsound float-fidelity oracle, recompute as `round(Fraction.from_float(f), scale) == Fraction(d)`.
- A differential that sets no `PYTHONPATH` can compare a tree against ITSELF (editable `.pth`) ⇒ every differential ships a loud vacuity guard. A source-mutation probe proves it applied (`cmp`/grep) before its rc means anything. Re-apply a reviewer-proposed mutant against CURRENT tests before adding its pin.
- Hypothesis: profiles in `tests/conftest.py` (`ci` derandomized default; `HYPOTHESIS_PROFILE=dev`); import `DrawFn`/`SearchStrategy` from `hypothesis.strategies` so property tests pass `mypy --strict`; `st.characters(codec="utf-8")` = encodable text; `msgspec.json.encode(float)` always emits a float token ⇒ float-injection tests encode floats directly; order-sensitivity as a property is hollow ⇒ one concrete anchor; `PYTHONHASHSEED` varies only via subprocess. Object-identity witnesses retain the objects. Artifact-route tests set a per-test `state_dir`.
- `get_args()` on a PEP-695 `type X = Literal[...]` alias returns `()` ⇒ use `get_args(X.__value__)`. `git check-ignore` suppresses tracked files ⇒ negative ignore tests pass `--no-index` + prove tracking with `git ls-files --error-unmatch`.
- `cast`, not `assert`, narrows `X | None` at a gated use site (an assert's never-taken branch fails the 100% gate); a branch unreachable by construction (`Path(name).stem`, `fullmatch` id) fails `warn_unreachable` — check constructability first.

Process:
- A "no edit needed" list is an assertion ⇒ re-verify each with a named search + rc + positive control; re-derive a ruling's factual core before restating or acting on it. A claim-narrowing fix SWEEPS every restatement across src + tests + docs (enumerate by search first; a twin whose NAME claims the narrowed property survives longest). Enum widening in a language without exhaustiveness checking breaks CONSUMERS while mypy stays green ⇒ every total map gets its own exact-set pin + mutant; `src/verifier/replay.py` mirrors `archive.py`'s role vocabulary on purpose — widen both in one commit.
- A diff-blind suite states a contract READING: where a red asserts more than the ratified predicate, the predicate wins and the suite is corrected. A scope ruling silently closes input paths other predicates assume ⇒ re-derive reachability after every scope ruling. Exception family matches what is wrong (`NotImplementedError` for an unimplemented path, never an integrity family).
- Every HTTP surface an archived artifact can reach is part of a widening unit's claim sweep (`/spec` `/certificate` `/chart` `/table` `/script` `/replay` per mode); example/doc guarantee strings (`examples/index.json`, `examples/README.md`) are claim surface too. Relocating code drops the rationale it carried ⇒ diff removed-vs-relocated lines after any extraction. Splitting a shared message by mode ⇒ byte-pin the UNCHANGED mode's canonical report (sha256). A stored-TEXT differential between two implementations of one DDL contract surfaces form noise ⇒ rule on admitted/refused SETS. A backward walk over a schema-rebuilding pipeline keys on (name, POSITION), never name alone.
- Verification integrity (`CLAUDE.md` `Engineering`), project bindings: a unit's grading check is FIXED at its contract — a threshold, case or gate moves only inside a unit the user approves, and that unit records the original check's firing. The skip-marked SKELETON is a WITHIN-unit device: it clears at that unit's own close, and a skip outliving its unit fails S8 unless its reason names a live tracker (`ops.md`). A skeleton's `Skeleton: each body is pytest.skip` docstring stops being true at the same close ⇒ sweep the module docstrings with the bodies, or a fresh agent reads implemented suites as unwritten ones. Hardcoding is the defect S8 cannot see: an implementation returning a fixture's expected value, or graded against an expected-output table its contract does not own, satisfies the suite and not the contract — mutation credit + the differential oracles are what price it, `L-HARD` in `.agent/review.md` adjudicates it per unit.
- Claim discipline: cite only retained-log numbers; frame unproven root causes as hypotheses; scope determinism to `(device, config)`. Refuted probes (do not re-investigate): DuckDB `executemany` does not route large in-domain Decimals through float64; in-process SVG byte-determinism holds.
