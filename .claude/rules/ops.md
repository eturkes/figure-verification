# Project operations

- Env: `uv sync --locked` builds `.venv` (py 3.13, gitignored); non-interactive shells `export UV_PROJECT_ENVIRONMENT=.venv UV_LINK_MODE=copy` before any `uv` call. Nested venvs are per-layer: `.venv-model` (py3.12 CUDA runtime, `UV_PROJECT_ENVIRONMENT="$PWD/.venv-model" uv sync --locked --project model_backend/runtime`), `.venv-webui` (open-webui 0.10.2). A claim about a non-default venv names its interpreter absolutely (`uv pip check --python "$PWD/.venv-model/bin/python"`); a RELATIVE `UV_PROJECT_ENVIRONMENT` resolves against the NESTED project.
- **Gate = `bash tools/gate.sh`** — the ONE invocation; a human, an agent + CI (`.github/workflows/gate.yml`) all run exactly it, so one recorded result is one claim. Eight stages, each printing `<name> rc=N`, all run even after one fails: `format` `lint` `types` `tests` (the four below) · `audit` (`uv audit`, OSV+PyPI over the committed lock) · `secrets` (`detect-secrets-hook` over `git ls-files` against the SLIM `.secrets.baseline` — slim = no line numbers + no timestamp ⇒ deterministic bytes, drift-stable; a FULL baseline returns rc 3 on one line of drift and wants to rewrite itself, which breaks idempotence on a clean tree) · `workflows` (`zizmor .github/`) · `shell` (`shellcheck` over `git ls-files '*.sh'` + a ban on `shellcheck disable=`; the sole host binary, SKIPPED-and-announced when absent). `.secrets.baseline` = 107 audited-benign findings (SHA-256 digests + Ed25519 vectors = the project's substance, loopback dev defaults already `# noqa: S105`, a `user:pass@host` URL-injection NEGATIVE vector, a `TOP-SECRET` SVG fixture); regenerate with `uv run --locked detect-secrets scan --slim --exclude-files '^\.secrets\.baseline$'` — REQUIRED whenever a commit adds a hash/digest/key-shaped literal to a tracked file (the stage names the file:line, and a new digest is indistinguishable from a leak until it is baselined; read the named line before regenerating). Static-config invariants of all this = `tests/test_gate.py` (G6-G12: stage list, CI-calls-no-tool-directly, Dependabot ecosystems + 7-day cooldown, 40-hex `uses:` pins, `contents: read`, `persist-credentials: false`, probe coverage). Attached-state liveness = `tests/test_spec.py` (S1-S5: five sections in order, every `Artifacts` path tracked, every `.agent/deferred.md` row carrying `Accept:`, every rules/docs/archive pointer resolving, every `M<m>.<u> CLOSED` unit's contract moved to `.agent/archive/contracts/`). `.agent/spec.md` has NO size budget: every line binds current or future work, superseded text dies in the commit that supersedes it, and `Accept:` clauses are excluded from the pointer sweep because a deferral names what it will CREATE.
- **Gate positive controls = `bash tools/gate-probe.sh`** — 19 probes, 19 FIRED, rc=0 (~10 s). Scope = the PURPOSE-BUILT checks only, which have no upstream suite behind them: `tests/test_gate.py` G6-G12 + `tests/test_spec.py` S1-S5 + `shell_lint`'s blanket-disable ban; ruff/mypy/`uv audit`/detect-secrets/zizmor/shellcheck carry their own. Each probe mutates ONE tracked file, runs the single owning check, and demands nonzero rc whose OUTPUT names the expected cause — rc alone cannot attribute a compound guard, and three tests carry two probes each (`g6-ci-gate-step`/`g6-ci-direct-tool`, `g7-ecosystem`/`g7-cooldown`, `g10-exec-bit`/`g10-blanket-disable`). Targets restore after every probe + in an EXIT trap, re-verified by sha256 + execute bit; `git status --porcelain` after a run = the check. `gate.sh` runs its stages from `main` behind a `BASH_SOURCE`/`$0` guard so the probe SOURCES it and fires the shipped `shell_lint` instead of reimplementing its grep. G12 keeps the set honest: every `^def test_` name in BOTH suites must appear in the probe script, so a new check without a firing input fails the gate. Two defects the first run surfaced, both invisible to a green gate: YAML types a bare `run: true` as a BOOL ⇒ G6's membership test died `TypeError` instead of reporting the missing gate step (fixed with `str()`); a planted `disable=` directive at EOF is SC1072 ⇒ shellcheck failed one step AHEAD of the ban and left the ban unproven (the plant now ships a trailing command). Firing-input literals that the checked surface would match (`shellcheck disable=`, the G12 probe's test name) are assembled at run time — spelled out, each would trip its own check from inside the probe file.
- Gate internals = `uv run --locked ruff format --check .` · `uv run --locked ruff check .` · bare `uv run --locked mypy` (`mypy_path=["src","tests"]`; NEVER `mypy src/` — a narrowed run once shipped 3 errors) · `uv run --locked pytest` (`-ra --strict-markers --cov`, 100% branch `fail_under` over `verifier` ONLY; `bench/`, `capture/`, `model_backend/`, `webui/`, `demo/` + tests-local modules sit outside). Record the command actually run — it IS the claim. Every tool THROUGH `uv run` or `.venv/bin/<tool>`: a bare `ruff` silently runs the host build + newer rules; a bare `mypy` dies rc 127. Coverage subsets need `--no-cov`; the decisive gate runs edit-free (an in-flight edit shifts line data). `exclude_also` covers TYPE_CHECKING/`__main__`/`@abstractmethod` only — an unimplemented `...`/`raise NotImplementedError` stub fails the gate.
- Shared live resources, one named holder per wave: ports 8000/8001/8080, the dGPU, `.venv-model`, `.venv-webui`, `.webui-data`, `.verifier-state/` (Ed25519 `signing.key` + `archive.sqlite3` — never echo the key). Heavy gitignored state (`.webui-data/`, `bench/reports/`, `.launch-logs/`, `models/`) is reached by bounded query only. No `.claude/settings.json` (a path-keyed `Read()` deny rule would gate Bash); `.claude/settings.local.json` = machine-local.
- Teammate worktrees: `.scratch/worktrees/<name>` on `wt/<name>`; from `<wt>` gate with `export UV_PROJECT_ENVIRONMENT=<primary>/.venv UV_LINK_MODE=copy PYTHONPATH=<wt>/src COVERAGE_FILE=<wt>/.coverage` + `uv run --no-sync --locked … pytest -p no:cacheprovider`. `PYTHONPATH=<wt>/src` is LOAD-BEARING: the shared venv's `verifier.pth` hard-codes the PRIMARY `src`, so without it a worktree gate exercises MAIN's code and reports green over edits it never ran. Reports `.scratch/agents/<name>.md`, roster `.scratch/agents/roster.md`; `.scratch/` is gitignored, so MAIN copies reports out before `git worktree remove`. Tracked `.claude/rules/` check out into every worktree and THAT copy is load-bearing: a `paths:` glob resolves against its own rules dir's root, so a teammate reading `<wt>/src/…` fires the worktree copy while the primary tree's rule stays silent (only `**`-prefixed globs fire from both) — prove a load with a planted nonce + self-report, never by grepping a transcript. After any worktree breach run the static gate before trusting the file (duplicate `def`s, double-applied renames are invisible to a reading pass); briefs carry an absolute `cd` on every command. A tip holding the only copy of an artifact is tagged `archive/<unit>-<role>` before its branch goes; `git tag -l 'archive/*'` = the inventory (18 tags, per-tag evidence → the archived roadmap § Retained tags; cite the TAGGED tip, never a pre-amend SHA; `archive/m12u2-rev` carries 10/15 checks that encode OVERRIDDEN readings — never implement against them).
- Read-and-conform-to set for every brief: gate above · oracles = `tests/` (+ `oracle.py`, `formula_oracle.py`), `examples/` corpus, `bench`/`demo` entry points · scope sources = `.agent/spec.md`, `POC_SCOPE.md`, `VPlot_SEMANTICS.md`.
- Unit lifecycle (IMPLEMENT): contract `.agent/contracts/<unit>.md` (testable predicates + invariant surfaces + tier + gate identity + probe seed) before code; every brief RESTATES the rulings that constrain its answers (the agent measures already-shipped code against them for free); a `test` teammate gets a COMMITTED skip-marked skeleton whose docstrings carry each predicate's acceptance check; planned text predates its predecessor ⇒ re-derive what is already true before what must change, and demand a distinct fault shape before adding an enum member; the contract + verdict table move to `.agent/archive/contracts/` at close. Review ledger `.agent/review.md`. Commit subject `<scope> (<unit>): <cause> → <fix>`; history `git log --grep "(M<m>[. ]"`. Closed milestone records = `.agent/archive/m<m>.md` + `closed-milestones.md`; the last roadmap snapshot + polish register + memory = `.agent/archive/{roadmap,polish,memory}.md`.
