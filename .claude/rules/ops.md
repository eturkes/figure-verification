# Project operations

- Env: `uv sync --locked` builds `.venv` (py 3.13, gitignored); non-interactive shells `export UV_PROJECT_ENVIRONMENT=.venv UV_LINK_MODE=copy` before any `uv` call. Nested venvs are per-layer: `.venv-model` (py3.12 CUDA runtime, `UV_PROJECT_ENVIRONMENT="$PWD/.venv-model" uv sync --locked --project model_backend/runtime`), `.venv-webui` (open-webui 0.10.2). A claim about a non-default venv names its interpreter absolutely (`uv pip check --python "$PWD/.venv-model/bin/python"`); a RELATIVE `UV_PROJECT_ENVIRONMENT` resolves against the NESTED project.
- **Gate = `bash tools/gate.sh`** — the ONE invocation; a human, an agent + CI (`.github/workflows/gate.yml`) all run exactly it, so one recorded result is one claim. `green` names the stages RUN + passed and nothing else: `gate.sh` prints `skipped: <names>` for what it did not run, and a not-run or missing check is reported by name or as `none`, never by omission. Eight stages, each printing `<name> rc=N`, all run even after one fails: `format` `lint` `types` `tests` (the four below) · `audit` (`uv audit`, OSV+PyPI over the committed lock) · `secrets` (`detect-secrets-hook` over `git ls-files` against the SLIM `.secrets.baseline` — slim = no line numbers + no timestamp ⇒ deterministic bytes, drift-stable; a FULL baseline returns rc 3 on one line of drift and wants to rewrite itself, which breaks idempotence on a clean tree) · `workflows` (`zizmor .github/`) · `shell` (`shellcheck` over `git ls-files '*.sh'` + a ban on `shellcheck disable=`; the sole host binary, SKIPPED-and-announced when absent). `.secrets.baseline` = 107 audited-benign findings (SHA-256 digests + Ed25519 vectors = the project's substance, loopback dev defaults already `# noqa: S105`, a `user:pass@host` URL-injection NEGATIVE vector, a `TOP-SECRET` SVG fixture); regenerate with `uv run --locked detect-secrets scan --slim --exclude-files '^\.secrets\.baseline$'` — REQUIRED whenever a commit adds a hash/digest/key-shaped literal to a tracked file (the stage names the file:line, and a new digest is indistinguishable from a leak until it is baselined; read the named line before regenerating). Static-config invariants of all this = `tests/test_gate.py` (G6-G12: stage list, CI-calls-no-tool-directly, Dependabot ecosystems + 7-day cooldown, 40-hex `uses:` pins, `contents: read`, `persist-credentials: false`, probe coverage). Attached-state liveness = `tests/test_spec.py` (S1-S8: five sections in order, every `Artifacts` path tracked, every `.agent/deferred.md` row carrying `Accept:`, every rules/docs/archive pointer in the attached state + ledger + scope sources resolving, every `M<m>.<u> CLOSED` unit's contract moved to `.agent/archive/contracts/`, the unfinished units in `Deferred` + only CLOSED ones in `Phase`, every well-formed contract citation in ANY tracked file resolving, every disabled case under `tests/` naming its tracker); the pointer sweep skips `Accept:` clauses, since a deferral names what it will CREATE. S4's surface = `.agent/{spec,deferred,review}.md` + `POC_SCOPE.md` + `VPlot_SEMANTICS.md` — NOT all live law: `.claude/rules/*.md` cites by bare basename + brace aggregate, which the resolver does not read, so widening to it is a `.agent/deferred.md` row. `.agent/archive/**` stays out of S4 for a different reason — a retired unit legitimately names a file later deleted outright (`.agent/outline.md`, the consumed scope seed), so there is nothing to repoint at. S5 + S7 are one close: S5 makes the close MOVE the contract, and that move is what strands every citation of the pre-archive path — test docstrings and `.agent/review.md` cite contracts, so closing a unit means rewriting them in the same commit. S8 reads `tests/` rather than the state files, because a skip and a pass print the same rc: a `skip`/`xfail` MARKER, a constant-condition `skipif`, a `marks=` marker on a parametrized case, a module `pytestmark` + an unguarded body `pytest.skip` must name a tracker — a `**M13.6**`-form spine unit in `Deferred`, or the `.agent/deferred.md` queue for an off-spine row. The spine form is a USER RULING over `CLAUDE.md`'s literal `.agent/deferred.md` row: a blocker inside an unfinished unit lives with that unit (`.agent/deferred.md`'s own routing header), and the approval the template demands rides the spine entry, which the user authors. Every shape is rooted in the module's OWN `pytest` binding ⇒ `from pytest import mark` is reached + an unrelated `other.mark.skip` does not fail the gate. S6 keeps `Deferred` open-only ⇒ a cited id stops counting at its unit's close, which is what turns the closing commit into the moment the skip is re-decided. `skipif` counts only on a CONSTANT condition — a dependency guard runs wherever its dependency exists, and `gate.sh` already announces it by name. S8 sees only what is STILL IN THE TREE: a deleted or tier-demoted case leaves no marker to read, so that half of the law stays a review judgment under `L-LAW`.
- **Gate positive controls = `bash tools/gate-probe.sh`** — 28/28 FIRED, rc=0, ~10 s. Scope = the PURPOSE-BUILT checks, the ones with no upstream suite: `tests/test_gate.py` G6-G12 + `tests/test_spec.py` S1-S8 + `shell_lint`'s blanket-disable ban (ruff/mypy/`uv audit`/detect-secrets/zizmor/shellcheck carry their own). Each probe mutates ONE tracked file, runs the single owning check, + demands nonzero rc whose OUTPUT names the expected cause — attribution rides the message, six tests carrying MORE than one probe each — five pairs (`g6-ci-gate-step`/`g6-ci-direct-tool`, `g7-ecosystem`/`g7-cooldown`, `g10-exec-bit`/`g10-blanket-disable`, `s4-dangling-pointer`/`s4-live-law-pointer`, `s6-open-unit-in-phase`/`s6-closed-unit-in-deferred`), one probe per conjunct of a compound guard, + S8's FOUR (`s8-untracked-{skip-marker,body-skip,param-marks,module-pytestmark}`), one per DETECTION path, since a decorator, a call statement, a keyword inside a parametrize list + a module-level assignment are materially different reads and deleting the helper behind one leaves the other three green. A widened sweep splits its probe with the widening: the S4 spec probe fires identically whether or not the added files are swept at all, so the added surface carries its own control. Targets restore after every probe + in an EXIT trap, re-verified by sha256 + execute bit; `git status --porcelain` after a run = the check. `gate.sh` runs its stages from `main` behind a `BASH_SOURCE`/`$0` guard, so the probe SOURCES it + fires the shipped `shell_lint` itself. G12 holds the set closed: every `^def test_` name in BOTH suites must appear in the probe script. Assemble every firing-input literal at run time (`shellcheck disable=`, the G12 probe's test name) — the probe file sits inside the surface its own checks scan. The exception is a check reading a NARROWER surface than the script sits in: S8 parses `.py` sources, so its plants carry literal names. A probe proves FIRING only — S8's `pytest`-rooting, whose job is to keep a LOOKALIKE from firing, carries no probe and rides the 100-file suite staying green. Three shapes to hold: YAML types a bare `run: true` as a BOOL ⇒ read every workflow `run:` through `str()`; a shellcheck directive at EOF is SC1072 ⇒ a planted directive ships a trailing command; a BACKTICK inside single quotes is SC2016 ⇒ a plant needing one builds it from `\140`, since the `shell` stage lints this file and SC2016 fails `shell_lint` one step before the ban it exists to prove.
- **Measurement harnesses = `.agent/measurements/`**, NOT in the gate and not in `mypy`'s `files`: each needs Node, a Pyodide download + minutes of runtime, and typing frozen numpy record scripts under `--strict` would buy a strictness hole or a `pandas-stubs` dep for no gate value. They are committed anyway because every published band + cell-text profile is a durable claim whose evidence would otherwise live only in gitignored scratch. `README.md` = id → claim table + run commands; corpora + result JSONs are gitignored (hundreds of MB), so a number is re-derived by rerunning, never by reading a stored file. `ruff` DOES lint them, under a 4-code per-file ignore (`S101` `PLR2004` `T201` `TID251`) whose rationale is in `pyproject.toml`. Making a rerun self-checking is a `.agent/deferred.md` row.
- Gate internals = `uv run --locked ruff format --check .` · `uv run --locked ruff check .` · bare `uv run --locked mypy` (`mypy_path=["src","tests"]`; NEVER `mypy src/` — a narrowed run once shipped 3 errors) · `uv run --locked pytest` (`-ra --strict-markers --cov`, 100% branch `fail_under` over `verifier` ONLY; `bench/`, `capture/`, `model_backend/`, `webui/`, `demo/` + tests-local modules sit outside). Record the command actually run — it IS the claim. Every tool THROUGH `uv run` or `.venv/bin/<tool>`: a bare `ruff` silently runs the host build + newer rules; a bare `mypy` dies rc 127. Coverage subsets need `--no-cov`; the decisive gate runs edit-free (an in-flight edit shifts line data). `exclude_also` covers TYPE_CHECKING/`__main__`/`@abstractmethod` only — an unimplemented `...`/`raise NotImplementedError` stub fails the gate.
- Shared live resources, one named holder per wave: ports 8000/8001/8080, the dGPU, `.venv-model`, `.venv-webui`, `.webui-data`, `.verifier-state/` (Ed25519 `signing.key` + `archive.sqlite3` — never echo the key). Heavy gitignored state (`.webui-data/`, `bench/reports/`, `.launch-logs/`, `models/`) is reached by bounded query only. No `.claude/settings.json` (a path-keyed `Read()` deny rule would gate Bash); `.claude/settings.local.json` = machine-local.
- Teammate worktrees: `.scratch/worktrees/<name>` on `wt/<name>`; from `<wt>` gate with `export UV_PROJECT_ENVIRONMENT=<primary>/.venv UV_LINK_MODE=copy PYTHONPATH=<wt>/src COVERAGE_FILE=<wt>/.coverage` + `uv run --no-sync --locked … pytest -p no:cacheprovider`. `PYTHONPATH=<wt>/src` is LOAD-BEARING: the shared venv's `verifier.pth` hard-codes the PRIMARY `src`, so without it a worktree gate exercises MAIN's code and reports green over edits it never ran. Reports `.scratch/agents/<name>.md`, roster `.scratch/agents/roster.md`; `.scratch/` is gitignored, so MAIN copies reports out before `git worktree remove`. Tracked `.claude/rules/` check out into every worktree and THAT copy is load-bearing: a `paths:` glob resolves against its own rules dir's root, so a teammate reading `<wt>/src/…` fires the worktree copy while the primary tree's rule stays silent (only `**`-prefixed globs fire from both) — prove a load with a planted nonce + self-report, never by grepping a transcript. After any worktree breach run the static gate before trusting the file (duplicate `def`s, double-applied renames are invisible to a reading pass); briefs carry an absolute `cd` on every command. A tip holding the only copy of an artifact is tagged `archive/<unit>-<role>` before its branch goes; `git tag -l 'archive/*'` = the inventory (20 tags; per-tag evidence → the archived roadmap § Retained tags; cite the TAGGED tip, never a pre-amend SHA; `archive/m12u2-rev` carries 10/15 checks that encode OVERRIDDEN readings — never implement against them; `archive/m13u3-orc` now retains only the differential oracle's BUILD HISTORY — the artifact itself ships in `main` as `tests/oracle_project.py` + `tests/test_pysrc_project_differential.py`, so a tag moves to the FINAL tip when its content merges).
- Running the FULL `tools/gate.sh` from a worktree resyncs the shared environment to that worktree: the script's internal `uv run --locked` carries no `--no-sync`, so it rewrites `.venv/lib/python3.13/site-packages/verifier.pth` to the worktree `src`. The `--no-sync` discipline above covers a direct `pytest`/`ruff`/`mypy` call, NOT the gate script. A teammate that gates from its worktree must restore the primary tree's editable install afterwards, and MAIN reads that `.pth` before trusting any decisive run — a `verifier.pth` pointing elsewhere makes a primary-tree green describe code it never ran.
- Read-and-conform-to set for every brief: gate above · oracles = `tests/` (+ `oracle.py`, `formula_oracle.py`), `examples/` corpus, `bench`/`demo` entry points · scope sources = `.agent/spec.md`, `POC_SCOPE.md`, `VPlot_SEMANTICS.md`.
- Unit lifecycle (IMPLEMENT): contract `.agent/contracts/<unit>.md` (testable predicates + invariant surfaces + tier + gate identity + probe seed) before code; every brief RESTATES the rulings that constrain its answers (the agent measures already-shipped code against them for free); a `test` teammate gets a COMMITTED skip-marked skeleton whose docstrings carry each predicate's acceptance check + whose every skip reason names the OWNING UNIT, since S8 reads that name as the tracker and the close is what retires it (the same close deletes the skips + the `Skeleton:` docstring line asserting them); planned text predates its predecessor ⇒ re-derive what is already true before what must change, and demand a distinct fault shape before adding an enum member; the contract + verdict table move to `.agent/archive/contracts/` at close, and every citation of the pre-archive path moves with them in the same commit (S7 decides it). Review ledger `.agent/review.md`. Commit subject `<scope> (<unit>): <cause> → <fix>`; body carries the RED WITNESS beside the measurements — the revision each new check was seen red on + the command that ran it (a purpose-built check names its `tools/gate-probe.sh` probe, a behavior test the unfixed SHA); history `git log --grep "(M<m>[. ]"`. Closed milestone records = `.agent/archive/m<m>.md` + `closed-milestones.md`; the last roadmap snapshot + polish register + memory = `.agent/archive/{roadmap,polish,memory}.md`.
- License `Apache-2.0 WITH LLVM-exception`; SPDX header in every source file. Git identity = global gitconfig; the user drives remote. Keep `.claude/commands/` absent — a project command masks the built-in `goal`.
- Census the instruction surface off `git ls-files`, never bare `rg`: project law lives in dot-dirs (`.claude/rules/`, `.agent/`) and `rg` skips those by default, returning a clean sweep byte-identical to a true one (`/usr/bin/grep -r` does descend them — the trap is tool-specific). `rg --hidden` also works; `git ls-files` additionally bounds the sweep to committed state.
