# Project operations

- Env: `uv sync --locked` builds `.venv` (py 3.14, gitignored); non-interactive shells `export UV_PROJECT_ENVIRONMENT=.venv UV_LINK_MODE=copy` before any `uv` call. Nested venvs are per-layer: `.venv-model` (py3.15 CUDA runtime, `UV_PROJECT_ENVIRONMENT="$PWD/.venv-model" uv sync --locked --project model_backend/runtime`; pyyaml has no cp315 wheel, so the sync builds it), `.venv-webui` (py3.11 = the official image's line, open-webui 0.12.3 from `webui/runtime/uv.lock`: `UV_PROJECT_ENVIRONMENT="$PWD/.venv-webui" uv sync --locked --project webui/runtime`; `uv pip check` reports exactly the 10 `open-webui` pins its `override-dependencies` lift). A claim about a non-default venv names its interpreter absolutely (`uv pip check --python "$PWD/.venv-model/bin/python"`); a RELATIVE `UV_PROJECT_ENVIRONMENT` resolves against the NESTED project.
- **Gate = `bash tools/gate.sh`** — the ONE invocation; a human, an agent + CI (`.github/workflows/gate.yml`) all run exactly it, so one recorded result is one claim. CodeQL (`.github/workflows/codeql.yml`: python · actions, `security-extended`, build-mode none) runs BESIDE it, never inside: its result is a hosted code-scanning upload no local command can make, so it is not a gate stage and a local green says nothing about it. G6-G9 bind every workflow, so it pins by SHA, keeps `contents: read` at the top (the `security-events: write` upload scope sits on its one job) and checks out credential-free at full depth. `green` names the stages RUN + passed and nothing else: `gate.sh` prints `skipped: <names>` for what it did not run, and a not-run or missing check is reported by name or as `none`, never by omission. Ten stages, each printing `<name> rc=N <s>s` (its wall-clock, `CLAUDE.md` `Execution` gate clause; the run closes on `gate rc=N <s>s`, both suites list their 10 slowest tests via `--durations=10`), all run even after one fails: `format` `lint` `types` `tests` (the four below) · `tests311` (the same suite on CPython 3.11, the official image's line: `gate.sh` `run_tests_py311` syncs `.venv-py311` from `tools/py311/uv.lock` — its own lock, since some root pins need 3.12 — then runs `.venv-py311/bin/python -m pytest -n auto` with `verifier` from `src`, no coverage; it decides runtime semantics the 3.11 mypy pass cannot, e.g. builtin `sum` is Neumaier from 3.12; test oracles bound to 3.12+ behaviour run behind `sys.version_info`) · `audit` (`audit_locks`: `uv audit` over the FOUR committed uv locks, root + `model_backend/runtime` + `webui/runtime` + `tools/py311`, + `pnpm audit --dir .agent/measurements` over the Node measurement harness's lock (pnpm from that harness's `packageManager` pin, in CI through `pnpm/action-setup`; rc 1 on any advisory or a registry error; a host without pnpm fails the stage), each run even when another fails; root + runtime ignore nothing; the demo Open WebUI lock passes `--ignore-until-fixed` for `WEBUI_RESIDUALS` alone — advisories with no fixed release, each id with its reason in `tools/gate.sh`, so a release that fixes one turns the stage red until the override moves) · `secrets` (`detect-secrets-hook` over `git ls-files` against the SLIM `.secrets.baseline` — slim = no line numbers + no timestamp ⇒ deterministic bytes, drift-stable; a FULL baseline returns rc 3 on one line of drift and wants to rewrite itself, which breaks idempotence on a clean tree) · `workflows` (`zizmor .github/`) · `spec` (`sh .agent/spec-lint .agent/spec.md`: section order, `Tasks` row shapes + the queue pointer last, `Phase` = `<PHASE> — <scope>` + routed state alone; `.agent/spec-lint` = a template file, copied in whole at each refresh beside `CLAUDE.md` + `.claude/agents/` (`CLAUDE.md` `Session flow`) ⇒ a fix lands in the template, never here) · `shell` (`shellcheck` over `git ls-files '*.sh'` + a ban on `shellcheck disable=`; the one host binary SKIPPED-and-announced when absent). `.secrets.baseline` = audited-benign findings alone (model snapshot + runtime lock digests, loopback dev defaults already `# noqa: S105`/`S106` — the measurement driver's private stub login among them, the fresh-credential test values of the loopback guard + its catalogue's `secret_key ==` anchors, the archived M13.0 contract's `user:pass@host` URL-injection NEGATIVE vector, the demo records' CSV + PNG + program digests under `.agent/measurements/m10u3/`, `m17u4/`, `m19u5/`, `m19u9/`, `q68/`, `q69/`, `q70/` + `deps-u3/`, and the template digests `tests/test_paste_in_templates.py` pins); regenerate with `uv run --locked detect-secrets scan --slim --exclude-files '^\.secrets\.baseline$'` — REQUIRED whenever a commit adds a hash/digest/key-shaped literal to a tracked file (the stage names the file:line, and a new digest is indistinguishable from a leak until it is baselined; read the named line before regenerating). Static-config invariants of all this = `tests/test_gate.py` (G6-G16: stage list, CI-calls-no-tool-directly, Dependabot ecosystems + 7-day cooldown, 40-hex `uses:` pins, `contents: read`, `persist-credentials: false`, probe coverage, G13 = the audited (tool, dir) pairs equal the dirs holding a tracked `uv.lock` (`uv audit`) or `pnpm-lock.yaml` (`pnpm audit`), G16 = ruff reads every shipped glob as py311 + `type_check` keeps the bare run and the 3.11 pass + `webui/runtime` stays `==3.11.*`). Attached-state liveness = `tests/test_spec.py` (S1-S9: five sections in order, every `Artifacts` path tracked, every `.agent/deferred.md` row carrying `Accept:` (a row = one entry: its `- ` line + the lines under it, to a blank line or the next list item; every list item a `- ` row; an empty queue passes), every rooted pointer in the attached state + ledger + every `.claude/rules/*.md` resolving (a queue row's `Accept:` clause, to the row's end, may name what it will CREATE; elsewhere `Accept:` is prose and cuts nothing), every `M<m>.<u> CLOSED` unit of the closed-unit record `.agent/archive/phase.md` with its contract moved to `.agent/archive/contracts/`, the unfinished units as `Tasks` `- [ ]` rows, no unit in `Phase` (its `>` request lines unread) + only CLOSED ones in the record, every well-formed contract citation in ANY tracked file resolving, every disabled case under `tests/` naming its tracker, `Phase` opening `<PHASE> — <scope>`; how each reads = `.claude/rules/gate-checks.md`). Closing a unit MOVES its contract (S5) + rewrites every citation of the pre-archive path in the same commit (S7: test docstrings + `.agent/review.md` cite contracts). A disabled case (S8) — a `skip`/`xfail` MARKER, a constant-condition `skipif`, a `marks=` marker on a parametrized case, a module `pytestmark` + an unguarded body `pytest.skip` — names a tracker: the `**M13.6**`-form unit of an open `- [ ]` row in `Tasks`, or the `.agent/deferred.md` queue for an off-spine row. The spine form is a USER RULING over `CLAUDE.md` `Engineering`'s `.agent/deferred.md` row: a blocker inside an unfinished unit lives with that unit (`.agent/deferred.md`'s own routing header), and the approval the template demands rides the spine entry, which the user authors. S8 reads open `- [ ]` rows alone ⇒ a cited id stops counting once its unit's close ticks the row `- [x] <sha>` or removes it, which is what turns the closing commit into the moment the skip is re-decided. `skipif` counts only on a CONSTANT condition — a dependency guard runs wherever its dependency exists, and `gate.sh` already announces it by name. S8 sees only what is STILL IN THE TREE: a deleted or tier-demoted case leaves no marker to read, so that half of the law stays a review judgment under `L-LAW`. Spec layout (follows `CLAUDE.md` `Session flow` five-section clause): `Phase` = `<PHASE> — <scope>` + the routed state alone (`spec` stage + S6 + S9); its history = the closed-unit record `.agent/archive/phase.md` S5 + S6 read ⇒ a unit's close ticks its `Tasks` row `- [x] <sha>` + appends its `<id> CLOSED` entry to the record, and each MAINTAIN request's close clears its ticked rows. A pause's resume note = one `- [ ] RESUME: …` `Tasks` row (S6 admits the shape; S8 reads a tracker from it only through a `**M<m>.<u>**` id), removed at resume close; S6 fails any `<id> CLOSED` inside `Tasks` ⇒ the note names finished work by SHA or description. S6 matches every `M<m>.<u>` token in the record's prose ⇒ inside the record, spell another unit only as `<id> CLOSED`, make every cross-reference descriptive (`the width census`), and never spell an amendment id `M13.6-1` there.
- **Fast gate (iteration) = `bash tools/fast-gate.sh [<pytest node|path> …]`**: `format` `lint` `types` `workflows` `spec` `shell` in parallel over the whole tree (the gate's own stage functions; ruff + mypy caches ⇒ seconds), then the named tests `--no-cov`. Never a claim: it always reports `tests311` `audit` `secrets` + coverage as skipped, so `green` = the full gate alone.
- **Gate positive controls = `bash tools/gate-probe.sh`**: every PURPOSE-BUILT check — the ones with no upstream suite: `tests/test_gate.py` G6-G16, `tests/test_spec.py` S1-S9, `shell_lint`'s blanket-disable ban (ruff/mypy/`uv audit`/`pnpm audit`/detect-secrets/zizmor/shellcheck + `spec-lint` carry their own) — ships one probe per detection path, which plants its firing input + demands that check's named cause; G12 holds the set closed (every test of both suites named by the script), G15 live (every node the script runs exists). A new purpose-built check ships its probe in the same commit. Probe mechanics + per-probe firing records = `.claude/rules/gate-checks.md`.
- **Measurement harnesses = `.agent/measurements/`**, NOT in the gate and not in `mypy`'s `files` (ruling on `CLAUDE.md` `Engineering`'s durable-claim clause: committed + rerun by hand, never a gate stage): each needs Node, a Pyodide download + minutes of runtime, and typing frozen numpy record scripts under `--strict` would buy a strictness hole or a `pandas-stubs` dep for no gate value. They are committed anyway because every published band + cell-text profile is a durable claim whose evidence would otherwise live only in gitignored scratch. `README.md` = id → claim table + run commands; corpora + result JSONs are gitignored (hundreds of MB), so a number is re-derived by rerunning, never by reading a stored file. Self-checking replay, BESIDE `bash tools/gate.sh`: `nice -n 19 ionice -c3 uv run --locked python .agent/measurements/rerun_all.py` (all 28 README ids, committed hand-stated `expected/<id>.json`, independent result projection + `check.py`; missing dependencies/results or drift ⇒ nonzero naming the id). Setup + per-id sources = `.agent/measurements/README.md`. The live legs' browser = `$CHROME`, a Chromium binary (path or `PATH` name), set per machine in the gitignored repo-root `.env` (template `.env.example`) ⇒ tracked files stay portable (`CLAUDE.md` `Authoring`, user ruling). Harness mechanics + the replay's positive control = `.claude/rules/gate-checks.md`.
- Gate internals = `uv run --locked ruff format --check .` · `uv run --locked ruff check .` · bare `uv run --locked mypy` (`mypy_path=["src","tests"]`; NEVER `mypy src/` alone — a narrowed run once shipped 3 errors) + a second pass `mypy --python-version 3.11 --cache-dir .mypy_cache/py311 src/verifier webui/paste_in` (`gate.sh` `type_check`: the shipped pair runs in the official image's CPython 3.11, M21.2 F11) · `uv run --locked pytest -n auto` (`-ra --strict-markers --cov`, 100% branch `fail_under` over `verifier`; `gate.sh` `run_tests`; `-n auto` = one pytest-xdist worker per CPU, pytest-cov combines their data before the floor is read; `-n` lives in `gate.sh`, never `addopts`, so a single-node run — `tools/gate-probe.sh`, `tools/mutate.py`, `tools/mutation_credit.py` — stays one process); `model_backend/`, `webui/` + tests-local modules sit outside it. Record the command actually run — it IS the claim. Every tool THROUGH `uv run` or `.venv/bin/<tool>`: a bare `ruff` silently runs the host build + newer rules; a bare `mypy` dies rc 127. Coverage subsets need `--no-cov`; the decisive gate runs edit-free (an in-flight edit shifts line data). `exclude_also` covers TYPE_CHECKING/`__main__`/`@abstractmethod` only — an unimplemented `...`/`raise NotImplementedError` stub fails the gate.

- Teammate worktrees: `.scratch/worktrees/<name>` on `wt/<name>`; from `<wt>` gate with `export UV_PROJECT_ENVIRONMENT=<primary>/.venv UV_LINK_MODE=copy PYTHONPATH=<wt>/src COVERAGE_FILE=<wt>/.coverage` + `uv run --no-sync --locked … pytest -p no:cacheprovider`. `PYTHONPATH=<wt>/src` is LOAD-BEARING: the shared venv's `verifier.pth` hard-codes the PRIMARY `src`, so without it a worktree gate exercises MAIN's code and reports green over edits it never ran. Reports `.scratch/agents/<name>.md`, roster `.scratch/agents/roster.md`; `.scratch/` is gitignored, so MAIN copies reports out before `git worktree remove`. Tracked `.claude/rules/` check out into every worktree and THAT copy is load-bearing: a `paths:` glob resolves against its own rules dir's root, so a teammate reading `<wt>/src/…` fires the worktree copy while the primary tree's rule stays silent (only `**`-prefixed globs fire from both) — prove a load with a planted nonce + self-report, never by grepping a transcript. After any worktree breach run the static gate before trusting the file (duplicate `def`s, double-applied renames are invisible to a reading pass); briefs carry an absolute `cd` on every command. A tip holding the only copy of an artifact is tagged `archive/<unit>-<role>` before its branch goes; `git tag -l 'archive/*'` = the inventory (per-tag evidence → the archived roadmap § Retained tags; cite the TAGGED tip, never a pre-amend SHA; `archive/m12u2-rev` carries 10/15 checks that encode OVERRIDDEN readings — never implement against them; `archive/m13u3-orc` retains the static-path differential oracle's build history; a tag moves to the FINAL tip when its content merges).
- Running the FULL `tools/gate.sh` from a worktree resyncs the shared environment to that worktree: the script's internal `uv run --locked` carries no `--no-sync`, so it rewrites `.venv/lib/python3.14/site-packages/verifier.pth` to the worktree `src`. The `--no-sync` discipline above covers a direct `pytest`/`ruff`/`mypy` call and NOTHING that shells out for itself: `tools/gate.sh`, `uv run --locked python tools/mutate.py <catalogue>`, `uv run --locked python tools/mutation_credit.py <node>` (its trials themselves run from a staged copy behind an import canary) and every `.agent/measurements/` script resync too, and the mutation driver does it during SETUP, before it prints its first line. A teammate that runs any of them from its worktree must restore the primary tree's editable install afterwards (`uv sync --locked` from the primary root), and MAIN reads that `.pth` BEFORE AND AFTER every decisive run — a `verifier.pth` pointing elsewhere makes a primary-tree green describe code it never ran, and a teammate's resync landing mid-run means a suite that started on the primary tree finishes reporting on someone else's bytes. The cheap posture while any teammate is live: name ONE holder of the shared environment, and re-read the `.pth` as part of reading the result.
- Read-and-conform-to set for every brief: gate above · oracles = `tests/` (+ the rule corpus `tests/figure_corpus/`) · scope sources = `.agent/spec.md` + `.claude/rules/figure.md`.
- Unit lifecycle (IMPLEMENT): contract `.agent/contracts/<unit>.md` (testable predicates + invariant surfaces + tier + gate identity + probe seed) before code; every brief RESTATES the rulings that constrain its answers (the agent measures already-shipped code against them for free); a `tester` teammate gets a COMMITTED skip-marked skeleton whose docstrings carry each predicate's acceptance check + whose every skip reason names the OWNING UNIT, since S8 reads that name as the tracker and the close is what retires it (the same close deletes the skips + the `Skeleton:` docstring line asserting them); planned text predates its predecessor ⇒ re-derive what is already true before what must change, and demand a distinct fault shape before adding an enum member; the contract + verdict table move to `.agent/archive/contracts/` at close, and every citation of the pre-archive path moves with them in the same commit (S7 decides it). Review ledger `.agent/review.md`. Commit subject (adapts `CLAUDE.md` `Execution` Git) `<scope> (<unit>): <cause> → <fix>`; body carries the RED WITNESS beside the measurements — the revision each new check was seen red on + the command that ran it (a purpose-built check names its `tools/gate-probe.sh` probe, a behavior test the unfixed SHA); history `git log --grep "(M<m>[. ]"`. Closed milestone records = `.agent/archive/m<m>.md` + `closed-milestones.md`; the last roadmap snapshot + polish register + memory = `.agent/archive/{roadmap,polish,memory}.md`.

A new source file ships the line in the commit that adds it. Git identity = global gitconfig; the user drives remote.
- Census the instruction surface off `git ls-files`, never bare `rg`: project law lives in dot-dirs (`.claude/rules/`, `.agent/`) and `rg` skips those by default, returning a clean sweep byte-identical to a true one (`/usr/bin/grep -r` does descend them — the trap is tool-specific). `rg --hidden` also works; `git ls-files` additionally bounds the sweep to committed state.
- Live law (`.claude/rules/*.md`) cites tracked code as `<file>.py::<name>` (`<file>.py::<Class>.<member>` for a class-level name, a bare `<file>.py` for a module header), never `<file>.py:<line>`, which strands on the first edit above it. `tests/test_symbol_citations.py` decides it: each symbol citation must name ONE tracked `.py` (an ambiguous basename such as `checks.py` takes its full path) holding that definition, and a line citation into any tracked `.py` fails; upstream sources (Open WebUI, transformers) match no tracked path and stay line-cited.
- Template drift (`CLAUDE.md`, `.claude/agents/`, `.agent/spec-lint`): a widened template rule → widen the project lens; a narrowed one strands project pointers → restate the evidence project-side or drop the pointer.
