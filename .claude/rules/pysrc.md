# Request anchoring + the CSV profile (`verifier.figure.anchoring`, `verifier.pysrc`)

Binding sources: `.agent/spec.md` Decisions "Integrity-redesign rulings" (5) + "Production-vs-demo rulings"; the judge that calls this law = `.claude/rules/figure.md` § Values + § Columns.

## Request anchoring (CSV figures)

- Drawn columns = the columns whose explanation backs the drawn values (`.claude/rules/figure.md` § Columns); `src/verifier/figure/columns.py::check_anchoring` compares them with the request. A request naming no header column anchors nothing; request language and header language may differ arbitrarily, so anchoring refines, never gates, the value check.
- **Substitution (the demo's rule, Q8):** refuse `column_not_requested` only on a SUBSTITUTION = a named column undrawn AND a drawn column unnamed. Either half alone passes: `chart revenue` leaves the key to the program; three named columns let a two-column chart pick two. A tie refuses too.
- **Strict (production's rule, Q37):** the substitution check, then: a request that names OR negates ≥ 1 header column (`anchoring.py::anchors`) must name every drawn column a request can name (`anchoring.py::nameable`: a folded name or an admin alias ≥ the anchor minimum), else `column_not_named`. A drawn negated column is unnamed ⇒ refuses; a column two headers fold to can never be named. Production pays in request wording, never in proposer strength. The rule lives in the generated artifact, never in the model's reach: `webui/paste_in/filter.py::Filter._ANCHORING` = `strict`, the demo subclass (`webui/paste_in/demo_filter.py`) = `substitution`.
- **Matcher.** Safe because the model gets no vote: the targets = the file's REAL header, so a typo fix cannot invent a column. NFKC + `casefold`; words split at every non-word char (`_` included) and where ASCII meets another script (`regionごとのrevenue`). Exact names first, longest first, each consuming its span (`unit price` never also names `price`): an ASCII header ≥ 3 chars = an exact word sequence, a non-ASCII header ≥ 2 chars = containment (Japanese has no word spaces). Then a one-word name ≥ 5 chars also matches one span within Levenshtein 1. A span within 1 of names of TWO columns, or one name two headers fold to = a tie. Lexical only: `temperature` never names `temp_c` unless an admin alias says so.
- **Stops + negation (Q38).** Before naming, `anchoring.py::_unnamed_places` consumes the closed EN stop phrases (`chronological order` … `in order`, unless one is a header's whole name) + every negated name: the longest name, else one ASCII word within one edit of a 5+-char name, right after `not` `no` `without` `except` `excluding` `rather than` `instead of` (the cue's successor first, then past one `the`/`any`), or a name right before `ではなく` `じゃなく` `でなく` `以外` `を除` (a space between them where the name ends in ASCII). The scan stays linear in the request. A consumed place names nothing + joins no tie; the same name elsewhere still names.
- **Japanese short words (Q41, strict alone).** `anchoring.py::_short_names`: a whole kanji run (`々` + every CJK ideograph block NFKC leaves in place: Ext A, the main block, compatibility `﨑`, Ext B+ `𠮷`) of the folded request, read before any name is consumed, equal to a 2-4 character Japanese name minus its first or last character names it (`月ごと` → `年月`, `日ごと` → `日付`) — unless a Japanese header name overlaps the run (the exact name takes it), the run fits names of two columns (names neither) or precedes a Japanese negation cue. Q42: a run ending in one grouping suffix (`anchoring.py::_SUFFIXES` = `単位` `別` `毎` `次`, cut once, at the end) is read again without it (`月別` → `年月`); the run and its stem fitting different names = a tie. Risk: a word ending in a listed suffix by itself (`区別`, `目次`) can name a header its stem fits (`区` → `地区`). Trust limit: a short word names the one header it fits (`年ごと` over a header whose only fit is `年齢` names `年齢`).
- **Admin aliases (Q43).** `Aliases` = (column, alias) pairs — ADMIN configuration, never model-supplied: the production tool's `Valves.column_aliases` text (`webui/paste_in/aliases.py::parse_aliases`), recorded in the receipt, read by the filter from it alone. `anchoring.py::_keys` folds each alias onto every header column whose folded name equals the alias's column, so an alias is another name of its column wherever a header name counts (exact naming, the one-edit tier, Q38, Q41/Q42, G10 labels + the summary-word exemption), under both rules. An alias of a column the header lacks is ignored; one two columns share, or equal to another column's name, is a tie; an anchoring-length alias makes a short column nameable under strict. Names of ONE column at one place never tie. Open WebUI lets the tool's owner, an admin or a write-granted user edit Valves ⇒ the admin guide makes an administrator the owner and keeps write access away from chat users.
- A model-produced translation of the request may never become the anchor: the model would then control both sides of the comparison. An admin alias is the one translation that anchors, because neither the model nor the chat user writes it.
- **G10 labels** (`columns.py::check_labels`, law `.claude/rules/figure.md` § Columns): a label naming a header column the chart does not draw refuses `label_not_consistent`; over a reduction, so does another reduction's summary word or `median` (`anchoring.py::summaries`, EN whole words + JA containment). Without a reduction, summary words go unread (a raw column may hold totals); a summary word inside a header word names that column (`total_revenue`). A group's `min`/`max` IS one of its cells, so those values are a raw subset (R2) whose canonical explanation is raw: no reduction is drawn and no summary word is read over them.

## CSV profile (`src/verifier/pysrc/csvread.py`; consumer `src/verifier/figure/sources.py::read_table`)

- **Restrict, never reimplement.** The sandbox calls plain `pd.read_csv`, whose default float parser is not correctly rounded: 326,834 of 1,000,000 adversarial cells disagree with stdlib `float` (12,053 by 2-7,262 ulp), and no significant-digit cap repairs it. Admitted cell text = `-?(?:0|[1-9][0-9]*)(?:\.[0-9]{1,6})?`, ≤ 15 significant digits, finite, not a signed zero, inside int32 IN AN INTEGER COLUMN (a column pandas infers float64 — any token with a decimal point — is bounded by the 15-digit cap alone, Q12). Measured: 0/4,000,000 bit mismatches against target Pyodide across plain + quoted fields (T7); Q12 0/1,345,852 host↔Pyodide to ±2**53 (T8). Two clauses bind the RENDERER: Pyodide's integer bar raises outside int32, and matplotlib bar erases the sign of `-0.0`. Full profile + its refusal complement = `.agent/archive/contracts/m13u5.md` § The C10 ruling.
- A STRUCTURAL fault refuses the whole file (`Unreadable`: `csv_not_parsable` | `csv_too_large` | `work_budget_exceeded`): BOM, NUL, a bare CR, invalid UTF-8, an empty or duplicate header name, a ragged row, no data row, the size/row/column/cell caps, the work meter. A CELL outside the profile leaves its column with no numbers (it stays a text key), so no explanation reads it as a value; the 19 pandas NA spellings (`csvread.NA_SPELLINGS`) + boolean text are never numbers.
- A demo dataset never spells a group key with a pandas NA spelling (`data/sales.csv` writes North America `US`): pandas would drop those rows from `groupby`.

## Group reductions (`src/verifier/pysrc/aggregate.py`), measured, never chosen

- pandas reduces a float64 group with ordered binary64 Kahan compensation in file-row order: naive left-to-right differs on 2,761/4,000 admitted-profile groups (worst 8,192 ulp), `math.fsum` on 1,483 (worst 5,252 ulp), Kahan on 0/16,062. `mean` = that Kahan sum over the count; an int64 `mean` casts each value then sums (witness `[2**53, 1, 0]`, a 1-ulp split from the exact mean). `min`/`max` update on strict `<`/`>`, keeping the first tied value's bits. Key order = pandas' `sort=True`: ascending, code point for text, numeric for numbers, locale-independent; one text cell turns every key to text. Host vs both Pyodide builds: 0 differences over 96,372 reduction rows (R1-R8). Pins = `tests/test_pysrc_aggregate.py` + `tools/mutants/aggregate.toml`.
