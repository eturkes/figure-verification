# Purpose-built checks — how each reads + what fires it

Running them + the law they impose = `.claude/rules/ops.md`; this file = their mechanics + firing records.

- Probe mechanics (`tools/gate-probe.sh`): each probe mutates ONE tracked file — the one exception, `s8-ticked-row-not-a-tracker`, writes the planted skip AND its ticked `Tasks` row, because S8's ticked-row exclusion is reachable only through both — runs the single owning check, + demands nonzero rc whose OUTPUT names the expected cause. Targets restore after every probe + in an EXIT trap, re-verified by sha256 + execute bit; `git status --porcelain` after a run = the check. `gate.sh` runs its stages from `main` behind a `BASH_SOURCE`/`$0` guard, so the probe SOURCES it + fires the shipped `shell_lint` itself. G12 = every `^def test_` name in BOTH suites appears in the probe script; G15 = every `tests/…py::<name>` node the script runs is a `def` in that file, since a renamed test leaves its probe planting an input nothing reads.
- Firing records — attribution rides the message; the tests carrying MORE than one probe each: G16's four (`g16-ruff-floor`, `g16-mypy-floor`, `g16-bare-mypy`, `g16-demo-floor`: one per conjunct), G17's four (`g17-ci-trigger`, `g17-stage-matrix`, `g17-fail-fast`, `g17-stage-argument`: one per conjunct of the CI fan-out), eight pairs (`g6-ci-gate-step`/`g6-ci-direct-tool`, `g7-ecosystem`/`g7-cooldown`, `g10-exec-bit`/`g10-blanket-disable`, `g13-nested-lock-audit`/`g13-pnpm-lock-audit` (the pnpm half of G13's widening), `s3-acceptance-check`/`s3-row-shape` (both append, so each fires on an empty queue), `s4-dangling-pointer`/`s4-live-law-pointer`, `s6-open-unit-in-phase`/`s6-closed-unit-in-tasks`, `s9-phase-without-name`/`s9-phase-without-scope`), one probe per conjunct of a compound guard, + S3's third (`s3-blank-line-ends-row`: a row = one entry, which a blank line ends), + S6's two row-shape probes (`s6-ticked-row-without-sha`, `s6-row-neither-shape`: every top-level `Tasks` row is `- [ ] ` or `- [x] <sha> `) + its record half (`s6-open-unit-in-record`: the second file S6 reads carries its own control), + S4's third (`s4-rules-pointer`, the `.claude/rules/` half of its widened sweep) + fourth (`s4-queue-pointer`: the queue half, each row read as one entry) + fifth (`s4-queue-line-scan`: each line of a row pairs its own backticks) + sixth (`s4-rules-accept-tail`: outside a queue row `Accept:` cuts nothing), + S8's SIX (`s8-untracked-{skip-marker,body-skip,param-marks,module-pytestmark,class-decorator,class-pytestmark}`), one per DETECTION path, plus its ticked-row exclusion (`s8-ticked-row-not-a-tracker`), since a decorator, a call statement, a keyword inside a parametrize list, a module-level assignment, a class decorator + a class-level assignment are materially different reads and deleting the helper behind one leaves the others green. G18's four (`g18-ci-skipped-stage`: the gate's `failed+=` for skipped stages deleted ⇒ a CI skip passes; `g18-ci-untracked-skip`: the conftest's exit-status flip neutered ⇒ an untracked skip passes; `g18-ci-closed-tracker`: `tests/trackers.py::names_tracker` admits any unit spelling ⇒ a skip citing a ticked or absent unit passes; `g18-ci-collection-skip`: the collection-report hook neutered ⇒ a module-level `importorskip` passes), one per detection path, `tests/conftest.py` + `tests/trackers.py` among the probe targets. G20's one (`g20-restore-exit`: the `|| rc=3` line deleted from `tools/probe-restore.sh` ⇒ a failed restore exits 0; the probe script SOURCES that file before its trap, so the running script keeps its sound copy). G21's one (`g21-dangling-symlink`: a tracked file replaced by a link to a missing target; `tools/probe-restore.sh` unlinks before it copies back, since `cp` writes through a destination symlink). G22's one (`g22-machine-path`: a home directory appended to a rule, assembled at run time because G22 scans this script). G23's three (`g23-suite-argv`, `g23-py311-argv`: each suite's `--durations=10` deleted; `g23-stage-timing`: `elapsed` printing nothing). G24's one (`g24-hypothesis-default`: the conftest's default profile `dev`). G25's two (`g25-fast-gate-stage`: `parallel spec` deleted; `g25-fast-gate-skips`: `secrets` dropped from the skip names). S10's three (`s10-unparsable-frontmatter`, `s10-unquoted-glob`, `s10-dead-glob`: one per frontmatter fault, each planted after `paths:` in `owui.md`) + S11's two (`s11-loaded-import`: `@.claude/rules/owui.md`; `s11-untracked-import`: `@.agent/no-such-file.md`, each appended to `ops.md`). G19's one (`g19-early-secrets`: the `early secrets` line deleted ⇒ the scan starts in its usual place, after `format`, which waits for it until it fails). `spec` stage (`.agent/spec-lint`): the pre-refresh `Phase` (old opening + closed-unit history) → `spec rc=1` naming `Phase line 1`.
- In-file controls (purpose-built checks outside the two probed suites; each ships its firing input beside it): `tests/test_cli_help.py` (every tracked entry point: `--help` rc 0 + `usage:`, an unknown argument rc 2; the entry-point set pinned; red on the pre-argparse tree: 6 commands), `tests/test_demo_data.py` (no `data/*.csv` cell pandas reads as missing; control = `data/deliberately_dirty.csv`), `tests/test_no_inference.py` (the judging core imports stdlib + `verifier` alone, no dynamic import, none of the `random`, `secrets` or `uuid` modules; control = each refused shape; one description = one verdict under hash seeds 0 + 1, fired by an interpretation text carrying `hash(…)`), `tests/test_paste_in_font.py::test_the_test_font_answers_for_every_character_the_tracked_inputs_hold` (red on the pre-regeneration font), `tests/test_mutation_catalogues.py::test_a_selector_pytest_does_not_collect_is_not_a_kill` (a helper, a stale `[id]`, a missing file), `tests/test_verification_docs.py::test_q72_every_diagram_colour_meets_its_contrast_floor` (the retired `#b6c3d1` border below 3:1; an unlisted colour).
- A widened sweep splits its probe with the widening: the S4 spec probe fires identically whether or not the added files are swept at all, so the added surface carries its own control.
- Assemble every firing-input literal at run time (`shellcheck disable=`, the G12 probe's test name) — the probe file sits inside the surface its own checks scan. The exception is a check reading a NARROWER surface than the script sits in: S8 parses `.py` sources, so its plants carry literal names. A probe proves FIRING only — S8's `pytest`-rooting, whose job is to keep a LOOKALIKE from firing, carries no probe and rides the whole suite staying green.
- Three shapes to hold: YAML types a bare `run: true` as a BOOL ⇒ read every workflow `run:` through `str()`; a shellcheck directive at EOF is SC1072 ⇒ a planted directive ships a trailing command; a BACKTICK inside single quotes is SC2016 ⇒ a plant needing one builds it from `\140`, since the `shell` stage lints this file and SC2016 fails `shell_lint` one step before the ban it exists to prove.
- S4 reads `.agent/{spec,deferred,review}.md` + every `.claude/rules/*.md`, deciding only ROOTED pointers (`.agent/`, `.claude/rules/`, `docs/`): a bare basename (`ops.md`, `oracle.py`) stays unread and a brace aggregate is skipped as a set. `.agent/archive/**` stays out of S4 for a different reason — a retired unit legitimately names a file later deleted outright (the consumed scope seed `outline.md`, once under `.agent/`), so there is nothing to repoint at.
- S6 reads PROSE, not headings: `_UNIT = re.compile(r"M(\d+)\.(\d+)([a-z]?)")` matches every `M<m>.<u>` token anywhere in the closed-unit record, which is why a neighbouring unit named in a closing entry fails the gate even when it is closed elsewhere in the same paragraph.
- S8 reads `tests/` rather than the state files, because a skip and a pass print the same rc. Every shape is rooted in the module's OWN `pytest` binding ⇒ `from pytest import mark` is reached + an unrelated `other.mark.skip` does not fail the gate.
- Measurement replay (`.agent/measurements/rerun_all.py`) positive control: plant R1's expected Kahan difference count 0→1, run `… rerun_all.py --check-only R1`, require nonzero + `R1: FAIL`, restore + SHA-256 equality. A full replay (no ids) first runs the driver's `cli_contract` (`rerun_all.py`; cited without `::`: `tests/test_symbol_citations.py` parses a cited file under 3.11 too, and the harnesses spell 3.14 syntax): every harness `--help` → rc 0 + `usage:`, an unknown argument → rc 2 + `error:`, before it measures (the harnesses stay outside `tests/test_cli_help.py`: the `tests311` suite would run them on CPython 3.11); control = the pre-argparse `t5.py` copied into the directory → `cli: FAIL` naming it. `ruff` lints the harnesses under a 4-code per-file ignore (`S101` `PLR2004` `T201` `TID251`) whose rationale is in `pyproject.toml`. M15/M16 own a private stub stack + browser, never the user's live resources; `$CHROME` unset ⇒ the leg fails naming it; `rerun_all.py` reads `.env` itself, a shell recipe runs `set -a; . ./.env; set +a`, the environment wins. M16's scheme passes need a `$CHROME` honouring CDP `prefers-color-scheme` emulation (a build pinning the scheme fails `schemes`); its PNG inspection stays judgment-only.
