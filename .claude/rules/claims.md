# Claim scope — what the project may say (a loose restatement is a regression)

- Verified = {validated spec, independently recomputed plotted table, emitted artifact inlining only that table, provenance certificate} mutually consistent + checks passed. Trusted, NOT verified: vl-convert/Vega, SVG rasterization, browser, pixels, matplotlib + the interpreter, the Pyodide sandbox + its bundled packages. Formula input is executable expression DATA ⇒ dataset mode's "pure data, no executable path" never transfers; python mode retires "impossible by construction" for code smuggling (recomputation strong · admission BY ALLOWLIST · containment TRUSTED).
- Script-artifact negative claim, byte-identical in `emit_formula_outcome`, `POC_SCOPE.md`, `README.md`: *Only a verified 200 returns or archives a script artifact; every failed verdict does neither.* Stated over VERDICTS, never non-2xx responses — a 507/500 can land after an in-memory build; the atomic commit keeps those bytes out.
- Replay reproduces no artifact bytes and no signature: `exact` = four certified hashes re-derive + the VCert v0.3 payload re-encodes byte-identical + TCB `drift=()`. A certificate binds each check's `{id, method, status}` only. Attestation proves canonical strict payload + exact bytes/MIME + trusted-key signature, nothing more. `/table` + `/script` serve digest-addressed bytes, NOT certificate-graph authenticated.
- `canon`'s six SHA-256 identities: dataset = raw CSV (tag-free source identity); table = typed-NDJSON (the ONLY permutation-invariant one); spec = msgspec canonical re-encode; manifest = raw bytes; formula = resolved canonical source; matplotlib-script = exact emitted bytes — the last five domain-tagged. Evaluator = hand-rolled pure Python (never pandas/polars): total control of row/column order + nulls, Fraction Σ, one HALF_EVEN quantize. Certified digests are DOMAIN-TAGGED: compare bytes with `canon.hash_table_bytes` / `canon.hash_matplotlib_script` against the AUTHENTICATED VCert v0.3 bindings, never `hashlib.sha256(body)` and never the POST verdict's unauthenticated fields. `spec_hash` = the SOLE spelling-sensitive certified digest (`2*x + 1` vs `2 * x+1` share the other three). A verified certificate is all-pass by construction (`CertifiedCheck.status = Literal["pass"]`); mix by METHOD — formula set `{construction, deterministic_recompute, z3_smt}` over 13 checks.
- Formula claims: values bounded = `deterministic_recompute`; rounding + points-from-recomputation = `construction`; no candidate-point match claim; solver proves nondecreasing x, sample strictness is the sole strictly-increasing authority. Float64 fidelity = round-tripping each projected point at its declared decimal scale + strictly increasing x — not binary64 identity, pixels or execution. Interpreter portability is measured (3.13.5↔3.13.14 under injected TCBs), never general. Canonical normalization = whitespace, redundant grouping, decimal spelling, unary plus, exponent spelling — no folding, no algebraic rewrite (provenance-critical).
- Guidance: "the grammar enforces the guidance schema" is FALSE on every surface; the grammar constrains generation TOWARD the schema, enforcement is evidenced by named both-ways witnesses, strict re-decode is the sole admission authority; never "the subset xgrammar supports". The proposer is transport + signed route only; guidance is a closed operator-pinned selector granting no semantic trust. No measured formula error-gradient claim exists.
- Human-facing text at a demo boundary inherits claim discipline: stub outcomes stated flatly, real-model arms conditional (`Expect …`); an STE rewrite must not upgrade a hedge into an assertion — re-check every rewritten behavioural sentence against `POC_SCOPE.md`. Root `README.md` = the single PoC-acceptance sweep, 10 criteria → evidence + boundary.
- Structure that holds the claims: VCert v0.3 = closed exact-family correlation (formula = `FormulaSource` + `matplotlib-script` + `FormulaTcb`, four hashes; dataset stays v0.2 emitted); the builder RE-HASHES all four carriers + refuses on mismatch, never reparses/re-evaluates; a fresh certificate stamps the LIVE TCB (archived TCB = comparison evidence only). `vcert.py` = neutral provenance leaf. A rejected formula verdict OMITS plot keys (`{attempt_id, layer, results, verified}`); a plot with no signed verified attempt answers 404 in both modes; a `/chart` 404 proves nothing alone (discriminate via co-located `/certificate` + `/table` + `/script` 200s, before AND after replay). Formula replay classifies mode after `read_attempt`, before any verdict. `formula_source` has no canonical decoder; archive containment is insert-time admission only, never "unrepresentable".
- Evaluator envelope: one cumulative `WorkBudget` per run (admitted sample = `5 + AST tariff`, every node 1, `Pow` = `1 + |exponent|`; charge precedes guard; refused charge consumes zero); check order domain-order → sample cap → endpoint bits → parse → schedule/bounds/strictness → row eval → y quantize → row admit; `formula.domain_ordered` before `sample_points_strictly_increasing` (no fixture isolates them). Parser ceilings (`_MAX_FORMULA_AST_DEPTH=64`, paren 64, digits 512 < CPython's 640 minimum) are trusted-caller policy bounds validated FIRST in `parse_expr`; `max_formula_ast_depth=32` caps a flat sum at 32 terms. Registry: register only check ids whose emitter exists; methods by MECHANISM.
- REJECTED: a parser work meter; self-scan of the emitted script; a third verdict shape; a widened generic `VerificationRun`; `max_length` on `DecimalText`.
