# M20.2 — "Show checks": each row lists the program lines related to its check

Tier **kernel**: `webui/paste_in/excerpts.py` + `checks.py` + `filter.py` quote model-authored bytes into the user's chat on the sole publication path; a wrong, missing or mis-marked line and a fault that costs the verdict have no downstream re-check.

## Rulings

- **X1 (user, AskUserQuestion, session 9)** values + columns rows also list the data-preparation lines: a static trace of the program text (display only; it can miss a line, never decides).
- **X2 (user)** run passed ⇒ one note `RAN`, no listing; attach (passed or failed) ⇒ one note `NO_LINES`; run failed ⇒ the raising statement marked, else the whole program.
- **X3 (user)** a not-checked row lists no lines.
- **X4 (MAIN, advisor)** the program row keeps the whole program; every listed line widens to its whole statement + the headers of the blocks around it; the ±2 context lines leave excerpts (kept only as listing priority inside the whole-program fallback); a failing row with no related line lists the whole program (the pre-M20 failing listing).
- **X5 (MAIN)** supersedes M18 ruling 1's "the passed `program` row + the failing row list the program" and ruling 13's listing clause; the mark stays ruling 13's line.

## Predicates

- **E1 recorded rows** (`excerpts.py::_recorded`, description facts, every figure + axes):
  - `figure` = figure sites · figure titles + texts · axes titles + axis labels · axes text artists · legend sites · tick-label calls (`xticks` `yticks` `ticks`).
  - `parts` = axes sites · every artist site · figure titles + texts · axes titles + axis labels · legend sites · figure others.
  - `axes` = axes sites · axes titles + axis labels · axis calls (`xlim` `ylim` `xscale` `yscale` `xinvert` `yinvert` `xticks` `yticks` `ticks` `invert`).
  - `marks` = drawn (non-text) artist sites · legend sites · colorbar axes sites.
  - `values` = drawn artist sites + E3.
  - `columns` = drawn artist sites · axes + figure titles · axis labels · legend sites + E3.
  - the failing check adds the failure's site; run/attach/program carry no recorded set.
- **E2 widening**: program ≤ 65,536 characters + `ast.parse` succeeds ⇒ each line → every statement whose OWN span holds it (simple = whole statement; block statement = decorators … the line before its first body statement; `except` handler = its header) ⇒ that span + the header of every enclosing block (+ handler header); a line no statement holds stays as is. Else the recorded lines stay as they are.
- **E3 trace** (values + columns): seeds = statements holding a drawn artist site. For each seed, needed = names its own expressions read (block statement: header; a def/class taken whole: its free names; less names bound by lambdas, comprehensions, inner defs). Walk earlier statements in reverse source order, skipping statements inside a def/class that does not enclose the seed. A statement BINDS (assign / annotated assign with value / for / with-as / walrus / import / def / class name; an enclosing def binds its parameters) or CHANGES (subscript/attribute target, augmented assign, `del` part, an expression-statement call `x….m(…)` with `m` ∈ {add append clear discard extend insert pop remove reverse setdefault sort update} or `inplace=True`) a needed name ⇒ it enters, unless it is an import or holds a figure/axes site (it builds the chart; its bound names leave `needed`, its reads are not added) or encloses the seed (its header shows anyway); entering: needed = (needed − bound) ∪ its reads. A def/class that enters lists its whole span.
- **E4 rendering** (`checks.py`): program row = whole program (pass unmarked; fail `no_user` whole); run pass = `RAN` note; attach = `NO_LINES` note; skip rows = no listing, no note; other ran rows = `RELATED` label + the row's lines; failing row = its lines with the site marked when listed, DREW sentence iff a mark is shown; a failing row with no lines = `CODE` label + whole program (±2 priority, pre-M20 oracle). Listing: priority = marked line, its ±2 neighbours inside the row's set, then ascending; ≤ 60 lines, ≤ 3,000 characters, lines cut at 400; `ELIDED` = row lines not shown by the caps; `BEYOND` iff the program exceeds 65,536 characters; a gap mark between non-consecutive lines.
- **E5 filter**: the outlet computes the row lines once the description parses (`filter.py::_evidence`), with the judge's site on a block; any exception in `excerpts` ⇒ the evidence keeps program + site alone (pre-M20 listing) and the verdict is unchanged.
- **E6 escaping**: every listing keeps the M18 escaping + trigger-free document (test_paste_in_embed over every reason × language × anchoring with every row listing).
