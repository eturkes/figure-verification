# Q18 — interval rule for a libm call over an interval argument (kernel)

Surface: `webui/paste_in/observe.py` (`_interval` and its helpers) = the observation gate's enclosure of a formula's float64 y at one verified x. Today a libm call (`sin cos tan exp log`) or `**` whose ARGUMENT is already a non-point interval returns None ⇒ the figure withholds (archived reading `m10u2` R4), so `np.exp(-x**2)` and `np.sin(x)**2` withhold even when the sandbox drew the verified values.

User ruling (queue request, approved as drafted): exp, log, sqrt monotone over an interval argument (log needs low > 0, sqrt low ≥ 0); sin, cos via an extremum check (an interior critical point widens to that extremum); tan monotone between poles, a pole inside ⇒ withhold; `**` with a POINT integer exponent over an interval base (even power with 0 in the base ⇒ [0, max]); every endpoint widened outward 1 ulp per libm call; anything else withholds as today.

Predicates (production + independent oracle must agree on each):
- I1 exp over [lo, hi]: [exp(lo), exp(hi)] widened 1 ulp outward; a non-finite endpoint ⇒ None.
- I2 log over [lo, hi]: lo > 0 ⇒ [log(lo), log(hi)] widened; lo ≤ 0 ⇒ None.
- I3 sqrt: unchanged (lo ≥ 0 ⇒ [sqrt(lo), sqrt(hi)], no widening — sqrt is correctly rounded; lo < 0 ⇒ None).
- I4 sin over [lo, hi]: the endpoint values plus every extremum value (+1 at π/2 + 2kπ, −1 at 3π/2 + 2kπ) the interval MAY contain (conservative point test), min/max widened 1 ulp; a span ≥ 2π ⇒ [−1, 1] widened.
- I5 cos: the same with extrema +1 at 2kπ, −1 at π + 2kπ.
- I6 tan over [lo, hi]: a pole (π/2 + kπ) the interval MAY contain ⇒ None; else [tan(lo), tan(hi)] widened.
- I7 `**`: a point base and a point exponent ⇒ unchanged (math.pow, 1 ulp outward). An interval base with a POINT exponent n that is an integer: n = 0 ⇒ (1, 1); n > 0 odd ⇒ [lo^n, hi^n] widened; n > 0 even ⇒ base ⊂ [0, ∞) [lo^n, hi^n], base ⊂ (−∞, 0] [hi^n, lo^n], 0 inside ⇒ [0, max(lo^n, hi^n)] (upper widened); n < 0 ⇒ 0 in the base ⇒ None, else min/max of the endpoint powers widened. A non-integer or non-point exponent with an interval base ⇒ None.
- I8 abs, + − × ÷, Neg, Num, Var, Const: unchanged.
- I9 a point argument gives the same interval as today for every function (no regression on the 58 committed fixtures).
- A1 Acceptance: committed `np.exp(-x**2)` and `np.sin(x)**2` observation fixtures (plot + scatter), regenerated on the installed Open WebUI Pyodide bundle, RELEASE; the same observation with one y moved 1 ulp beyond its interval WITHHOLDS.
- A2 The observe mutation catalogue stays 0 SURVIVED, with a mutant per new predicate.
- A3 The old R4 tests that pinned these shapes as withholding (`test_o5_ambiguous_libm_argument_withholds_even_at_host_value` for `np.sin(x)**2` + `np.exp(-x**2)`, `test_libm_result_cannot_feed_power_then_exponential_without_range_proof`, the differential's `np.exp(-x**2)` row) move to the new reading; `np.sin(np.cos(x))` (sin over an interval) now releases too under I4 — its row moves with it. Original firing recorded in the commit.

Tier kernel. Reviewers: two, blind. Oracle: `tests/oracle_observe.py` re-derived independently from this contract.

Rulings during the unit (MAIN): I7 an even positive power with lo ≤ 0 ≤ hi (zero inside OR an endpoint) has lower bound exact 0.0; a negative power with lo ≤ 0 ≤ hi withholds. I4/I5 threshold = 2π for sin/cos (π is tan's: a span ≥ π certainly holds a pole). Point arguments keep today's interval for every function (I9): extremum inclusion and the pole test apply to NON-point intervals only. The explicit log domain check is redundant with `math.log` raising at or below zero and is omitted.
