# M19.2 — sandbox reader, wrapper, closed description

Tier **kernel**: the description is the judge's ONLY view of the figure; a fact the reader misreports or omits is a verdict no later check can repair, and no downstream re-check exists.

## Rulings

- U1 (MAIN, law `.claude/rules/figure.md`): reader = facts, judge = decisions. The reader never decides a rule; it reports what matplotlib holds after the program ran.
- U2 (MAIN, advisor): reader = `src/verifier/figure/reader.py`, the one `verifier` module importing matplotlib/numpy/pandas — every import through `importlib.import_module` inside a function (so `TID251` never fires and mypy reads them as `Any`). 100% branch coverage on the host (matplotlib 3.9.4): every branch host-drivable; the 3.8.4 span `Polygon` is a JUDGE input shape (reader reports `Polygon` generically), never a reader branch.
- U3 (MAIN): wrapper = `webui/paste_in/sandbox.py` `wrapper_code(program, font)`: loader prelude (as M17) → font bytes to `FONT_PATH` → `exec` of the base64 reader source as `<figure-reader>` → `print(run(<program>, <font path>))`; `run` resets `rcdefaults` + registers the font (one runtime serves many replies). The reader bytes reach the paste-in BY GENERATION as base64 chunks (`webui/paste_in/reader_source.py` `READER_BASE64`; `bundle.GENERATED`, `--check` covers it), split in the RPC wherever the encoding spells the plotting name.
- U5 (MAIN, measured): child axes (inset, `SecondaryAxis`) are axes CHILDREN, so they appear as artists (class + origin, no geometry), never as a second axes record — the contract's `parent` field is dropped. A `Text`'s site = the last program line that set it (`Text.set_text` hook), since `plt.title` sets an artist the Axes created earlier. Legend entries record the handle the program/pandas passed (identity: pandas passes its own containers + collections); a figure legend matches by text + handle colour. Program stdout + stderr → one sink: the sandbox reply is the interpreter's whole stdout.
- U4 (MAIN, advisor): caps — reader side: ≤ 24 axes, ≤ 2,000 axes children per figure (summed over its axes), ≤ 20,000 data coordinates per figure (points, bars, wedges, band vertices, hist + pie inputs), text ≤ 1,000 characters each; at a cap the description is the minimal `too_large` record and no PNG line ⇒ `figure_too_large`, never a silent drop or cut. Description JSON (after the tag) ≤ 400,000 bytes, PNG line ≤ 500,000 characters (else `too_large`), so one reply fits OWUI's 1,000,000-byte frame. Judge side: the decoder measures the same JSON bytes and refuses > 400,000 (⇒ `no_description`).
- U6 (MAIN, reviewer-1 F1-F12, all accepted + fixed): a same-version holder exec'd again is reused (duck-typed by `version`), another version's is unwound; one capture = one draw (`savefig`); construction recorders resolve `data=` names and never raise (a record that cannot be made is skipped ⇒ the judge refuses the mark); band arrays are read back from the final polygon (`fill_between` layout, units converted), `_fv_plain` (no `where`/`step`) recorded alone; a tick's visible label1 OR label2 is reported; a legend entry's text = its displayed text; the description travels ASCII-escaped (U+2028/U+0085 never split the line); the decoder admits finite JSON numbers alone (non-finite only as the three strings) and closed words for error kind, axis kind, transform, orientation, legend-element prop.

## API

- `reader.run(source: str) -> str`: install hooks once per interpreter (idempotent), exec `source` as `<verified-figure>` with `sys.stdout` → sink + warnings recorded + every exception caught (SyntaxError ⇒ `syntax`, other ⇒ `exception`; class name + innermost program line); capture each figure the program shows (its `plt.show` → capture + close) and every figure still open at the end; draw each once with warnings recorded (`Glyph … missing` ⇒ `glyphs` count); return `TAG + json + "\n"` + (exactly one figure + under caps ⇒ `data:image/png;base64,…\n`).
- `description.parse_description(stdout: str) -> Description | None` (stdlib, `src/verifier/figure/description.py`): exactly one `TAG` line, ≤ cap, strict JSON (no NaN/Infinity tokens, duplicate keys refused), every object's key set closed + exact, every value exactly typed; floats as JSON numbers, non-finite as the strings `nan` `inf` `-inf`; anything else ⇒ `None`.
- Types (frozen slots dataclasses, tuples): `Description(version, error, too_large, glyphs, figures)` · `ProgramError(kind, name, line)` (kind ∈ `syntax` `exception` `draw`) · `Figure(site, titles = (suptitle, supxlabel, supylabel), texts, legends, others, axes)` · `Axes(cls, site, position, colorbar_of, shared_x, shared_y, titles, x, y, calls, artists, containers, pies, legend)` · `Axis(label, scale, view, inverted, kind, categories, formatter, formatter_module, offset, order, percent_xmax, ticks, dates, calls)` · `Tick(position, text)` · `Text(text, site)` · `Artist(cls, origin, site, visible, alpha, label, transform, geometry)` with `geometry` ∈ `LineGeometry(x, y, color, marker, linestyle, drawstyle)` · `RectGeometry(x, y, width, height, angle, color)` · `WedgeGeometry(cx, cy, r, width, theta1, theta2, color)` · `PolygonGeometry(xy, color)` · `ScatterGeometry(offsets, sizes, colors, array, colorbar)` · `BandGeometry(paths, color, band: BandArrays(x, y1, y2) | None)` · `TextGeometry(text)` · `NoGeometry()` · `Container(cls, orientation, label, members, hist)` · `HistRecord(values, bins, density, weighted, cumulative, histtype, datasets)` · `PieRecord(values, normalize, wedges, labels)` · `Legend(site, entries)` · `LegendEntry(text, target, container, proxy_color, elements_of)`; `Part(cls, origin, site)`.
- `Axis.kind` ∈ `numeric` `category` `date` `unknown`; `Axis.dates` = (position, ISO text) for every data coordinate + tick position on a date axis (matplotlib date converters → `num2date`; pandas period converter → `Period(ordinal, freq).start_time`).
- Transform kind ∈ `data` `axes` `xaxis` `yaxis` `figure` `other`, from the data-bearing transform (scatter: offset transform; patches: `get_data_transform`; else `get_transform`).

## Predicates

- **P1 hooks.** origin + site per artist on the I1 cases; `plt.bar` ≡ `ax.bar` ≡ pandas `.plot(kind='bar')` → `Axes.bar`; hist bars → `Axes.hist`; stackplot bands → `stackplot`; a user `add_patch`/`add_line` artist → origin `None`; `site` = the program line inside a user function's caller chain. Accept: hand-stated literals.
- **P2 capture.** show-then-draw-again ⇒ two figures; no show ⇒ open figures captured at the end; `plt.close('all')` before the end ⇒ zero; a program exception after `show` ⇒ `error` set AND the shown figure described; program `print` never reaches the returned text. Accept: witnesses.
- **P3 errors.** SyntaxError (line), NameError (line), `ModuleNotFoundError` (name kept), an exception raised inside matplotlib from a program call (innermost PROGRAM line). Accept: hand-stated `ProgramError` literals.
- **P4 facts.** One witness per family in the law's table + every axis kind (category, matplotlib date, pandas period, numeric with ScalarFormatter offset/order, set labels, PercentFormatter, log) + legend entries (artist handle, container handle, pandas proxy, `legend_elements`) + colorbar link + hist/pie/fill_between records + shared/twin axes + inset parent: each reported value hand-stated.
- **P5 caps.** One witness per cap at cap and cap + 1 (points, axes, children per figure, text, description bytes measured as the decoder measures them, PNG chars) ⇒ `too_large`, no PNG line.
- **P6 decode.** `parse_description(run(…))` round-trips every P4 witness; refusal witnesses: two tagged lines, oversize, NaN token, duplicate key, an extra key, a missing key, a wrong type at each nesting level (bool for int, int for float, list for tuple-of-pairs), unknown geometry class ⇒ `None`.
- **P7 sandbox parity.** The I1 census programs (52) run through the production `wrapper_code` in the installed bundle, one runtime in order (`.agent/measurements/` I3), and their descriptions equal the host reader's except the published fields: `boxplot` labels, `reference` span shape (`Rectangle` 3.9.4 vs `Polygon` 3.8.4: the judge reads both), `subplots` positions after `tight_layout`.
