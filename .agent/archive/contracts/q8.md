# Q8 — lexical request anchoring (kernel)

Row: request terms ↔ CSV header, NFKC + full/half-width folding + bounded edit distance, unique match required, ties refused; a refinement over tiers 1-3, never a prerequisite. Accept: false-refusal rate measured per language on a committed corpus + a substitution witness (spec groups by a column the request never names) blocked.

User ruling (queue request, Batch A): refuse substitutions only, new code `column_not_requested` (closed set 52 → 53, REASONS EN/JA + `CHECK_OF` + Show-checks row); NFKC + width folding; edit distance ≤ 1 for terms of ≥ 5 characters; ties refused; a request naming no column passes.

Surface: `src/verifier/pysrc/verify.py` (request anchoring section, `bind_target`) · `csvread.header_names` · `spec.DatasetTarget.request` · `errors.RefusalCode` · `webui/paste_in/{selection,checks,reasons}.py` (the request = `__metadata__["user_message"]["content"]`, the user's own message; the inlet's rendered template never reaches it).

Predicates:
- A1 Substitution = a column the request names is undrawn AND a drawn column is unnamed ⇒ `column_not_requested`; either half alone passes. Drawn = the spec's x and y.
- A2 A request naming no header column, a `None` request, an unreadable header (`header_names` = None: size, BOM, NUL, record endings, UTF-8, the header record itself) or a drawn column absent from the header ⇒ no anchoring; the later checks decide.
- A3 Matching: NFKC + `casefold`; words split at every non-word character (`_` included) and at each ASCII ↔ other-script boundary. ASCII header ≥ 3 chars = an exact word sequence; a one-word ASCII header ≥ 5 chars also = one request word within Levenshtein 1. Non-ASCII header ≥ 2 chars = containment in the request's word string.
- A4 Tie: one request word within 1 edit of two headers, neither named by that word exactly ⇒ `column_not_requested`. An exact word never names its near neighbour.
- A5 Ordering: anchoring sits in the `binding` check, after the path comparison and before recompute.
- A6 Selection threads the request into every dataset candidate.

Acceptance: `tests/test_pysrc_anchoring.py` (substitution witness + A1-A6); A1 measurement (`.agent/measurements/a1_anchor.py`, `expected/A1.json`): 0/18 false refusals per language (EN · JA over a translated header · JA naming the English header); held-out prompts unread. Mutation: `verify.toml` + `csvread.toml` + `selection.toml` additions, 0 SURVIVED.

Tier kernel. Reviewers: two, blind.
