# Q75 — seaborn `hue` legends: ink-free legend proxies

Tier **kernel**: the parts stage decides which artists a figure may hold, and the legend stage which series a name reaches; the values stage re-checks a named series' data (R6), but a proxy admitted with ink would put an unjudged mark on the chart.

## Row

`.agent/deferred.md` (Q73 find): seaborn 0.13.2 adds each `hue` legend handle to the axes as a proxy artist (`Rectangle((0, 0), 0, 0)` for bars, `Line2D([], [])` for lines; no `Axes` origin, label = the hue level, colour = the level's) ⇒ `artist_not_judged` even with `errorbar=None`. Accept: an origin-less proxy that draws no ink and serves only as a legend entry's handle is judged (`.claude/rules/figure.md` closed set; an inked one still blocks), `sns.barplot(…, hue="region", errorbar=None)` + `sns.lineplot(…, hue="region", errorbar=None)` pass over `data/sales.csv` with a misleading twin each blocking its rule, C1 green.

## Predicates

- **P1 admission** — an axes artist with no origin is a legend proxy iff (a) an entry of THAT axes' legend targets it, and (b) it draws no ink by geometry: a `Rectangle` of zero width AND zero height, or a `Line2D` holding no point. It is no mark (never a series, never in `no_data`'s count); every other origin-less artist still blocks `artist_not_judged` (an inked proxy, a proxy no entry targets, a proxy of another class).
- **P2 naming** — a legend entry whose handle is a legend proxy names the one mark of its panel whose colour equals the proxy's (RGB) and whose own label is empty; none or several ⇒ `legend_mismatch`. Each mark is named once (existing rule).
- **P3 values** — unchanged: a named series whose name equals a cell value of a column draws from the rows holding it (R6); a label swapped onto another level's bars ⇒ `value_not_found`.
- **P4 corpus** — `tests/figure_corpus/seaborn.toml`: `seaborn-bar-hue` + `seaborn-line-hue` pass (request names revenue, month, region); `seaborn-bar-hue-from-8000` blocks `zero_not_in_limits`; `seaborn-line-hue-swapped` (legend labels reversed) blocks `value_not_found`; a hand-made inked origin-less patch the legend targets blocks `artist_not_judged`.
- **P5 bundle** — C1 replays every case in the 0.12.3 bundle, host = bundle.
