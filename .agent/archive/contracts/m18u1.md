# M18.1 — source positions: where a refusal sits + which statement served which role

Tier **kernel**: `src/verifier/pysrc/` is the pass/fail boundary and the sole source of what the "Show checks" rows quote (M18.2); a wrong position marks innocent code as refused, a missing one hides the refused construct, and a position that moved a verdict would move the boundary. No downstream re-check exists.

## Rulings

- **U1 (user, this request).** Each "Show checks" row opens to the program lines its check read, the failing span marked. Layering (user): the core carries POSITIONS only — integers + a closed role vocabulary, never a source byte; the wrapper (M18.2) quotes + escapes program lines. Supersedes `Verified`'s docstring "no line number"; its intent (no model-authored text in a verdict) holds.
- **U2 (MAIN).** Positions are diagnostics outside verdict identity: `at`/`trace` fields are `compare=False`, so `==`/`hash` of `Refused`/`Verified` read `code` / `spec`, `table`, `certificate` alone.
- **U3 (MAIN, consultant-1 D2-D4).** `at` = a GENUINE program location alone: admission + projection = the innermost INSTRUMENTED node (wrappers on `_admit_expr`, each top-level statement, projection's `_expr`); prescan = the faulting character/token/line; post-projection = a role hint at exactly four raise sites (`source_not_supplied` + the dataset `target_mismatch` → the `source` statement; `label_not_consistent` → the failing label's statement). Every other post-projection refusal (file, data, request, limit faults) has `at = ()`: M18.2 quotes the check's related lines UNMARKED, never as the fault.
- **U4 (MAIN, consultant-1 D8).** `project()` stays the projection seam `verify_python_source` calls (the ordering bomb in `tests/test_pysrc_verify.py` + the O7 plant in `tests/test_paste_in_observe_fixtures.py` keep patching it); the trace comes from a separate pure classifier over the projected tree. - **U5 check change (implied by U1-U2; original firing recorded at close).** The verdict field-set pins in `tests/test_pysrc_verify.py` (public-surface test: `Verified` + `Refused` `__dataclass_fields__`; E4: the `Verified` field set) gain the new fields; every other conjunct (exports, signature, no-marker walk) kept.
- Unchanged: every refusal code, its precedence + stage order, spec/table/certificate bytes, every digest, `project()`'s signature + return, `PysrcRefusalError(code)` construction.

## API

- New `src/verifier/pysrc/position.py` (stdlib): `Span(line, column, end_line, end_column)` frozen slots dataclass of `int`; `Role` = `Literal["import", "source", "data", "mark", "title", "xlabel", "ylabel", "decoration", "layout", "show"]`; `Step(role: Role, span: Span)` frozen slots; `type Trace = tuple[Step, ...]`.
- Span convention = `ast`'s: lines 1-based, counted at `\r\n` / `\r` / `\n` alone (never `str.splitlines()`'s wider set); columns = UTF-8 byte offsets within the line (a lone surrogate counts 3, its `surrogatepass` length), `end_column` exclusive. A POINT span (`(line, column) == (end_line, end_column)`) marks a position with no character (end of line / end of text).
- `errors.PysrcRefusalError(code, *, at: tuple[Span, ...] = (), role: Role | None = None)`; attributes `.code`, `.at`, `.role`.
- `verify.Refused(code, at=(), trace=())`; `verify.Verified(spec, table, certificate, trace=())`; both new fields `field(default=(), compare=False)`.
- `project.statement_trace(tree: ast.Module) -> Trace` — pure; precondition = `project(tree)` returned.

## Trace

`statement_trace(tree)` = one `Step` per top-level statement, source order: `ast.Import` → `import`; `Assign` of `pd.read_csv(…)` → `source`; every other `Assign` → `data`; a `_DATASET_MARKS`/`_MARKS` call or the accessor → `mark`; `plt.title`/`plt.xlabel`/`plt.ylabel` → `title`/`xlabel`/`ylabel`; `plt.legend`/`plt.grid` → `decoration`; `plt.figure`/`plt.tight_layout`/`plt.xticks` → `layout`; `plt.show` → `show`. `Verified.trace` = it; `Refused.trace` = it for a refusal after projection returned, `()` before (rows up to `chart` quote every line, so no partial trace is needed).
