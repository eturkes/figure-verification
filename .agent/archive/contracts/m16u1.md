# M16.1 — "Show checks": the outlet shows every check a figure faced

Tier **kernel**: `webui/paste_in/filter.py` is the sole publication path; a defect in a diagnostic arm (an escaping exception, a delayed or moved verdict, a ✓ claimed for a check that never ran, untrusted text echoed to the user) has no downstream re-check.

## Rulings (user, this request)

- **V1 surface.** Each reply carries ONE Open WebUI message embed = a collapsed disclosure `Show checks` between the status line and the verdict text (below the image on PASS). Event `{"type": "embeds", "data": {"embeds": [<html>], "replace": True}}`: `replace` makes the stored list exactly this document (`socket/main.py:982-987` otherwise appends the message's earlier embeds; the frontend assigns `message.embeds = data.embeds`, `Chat.svelte`). OWUI 0.10.2 renders `message.embeds` after status + files, before content (`ResponseMessage.svelte:694-739`), through `FullHeightIframe` (raw HTML → `srcdoc`, `sandbox="allow-scripts allow-forms allow-popups allow-downloads"`, + `allow-same-origin` only under the user setting `iframeSandboxAllowSameOrigin`), height set by the frame's own `postMessage({type: 'iframe:height', height})`; precondition = `IFRAME_CSP` empty (default, `config.py:1696`) — a restrictive policy can stop the inline height reporter. Arrival scrolls the embed to centre (`Chat.svelte:661-668`, unconditional; accepted with the surface). Persistence: `socket/main.py` `embeds` arm upserts; the outlet write-back (`utils/middleware.py` `outlet_filter_handler`) upserts `content`/`output`/`originalContent` alone and `outlet_data` omits `embeds`, so neither the DB write nor the frontend `chat:outlet` merge clobbers it.
- **V2 rows.** Row = status mark (✓ / ✗ / –, localized `aria-label`) + check title + what the check covers; the failing row adds its `REASONS` cause (M15.1).
- **V3 outcomes.** FAIL **and** PASS replies carry the embed (supersedes M15.1's "PASS emits neither" for the embed alone; PASS still emits no status event and no log record).
- **V4 unrun checks.** A FAIL lists every check: rows after the failing one read `not checked`.
- **V5 check change (implied by V1 + V3; original firing recorded at close).** Exact event-list assertions gain the embed event, every current conjunct kept: `tests/test_paste_in_filter_reasons.py` (D3, D4, D5, D6, D7, D8 incl. the raising-handler case; absent-emitter `[]` stays), `tests/test_paste_in_filter_differential.py` (`_translate_outlet` + `tests/oracle_filter.py`), `tests/test_paste_in_observe_filter.py` (O5/O6 + PASS list), `tests/test_paste_in_filter_internal.py:201` (PASS list). M15.1 D4's "the status event is the last event emitted" becomes "the status event, then the embed event, last"; D8's per-emit bound becomes C8's shared deadline.
- Unchanged: `PASS_TEXT`, `FAIL_TEXT`, `content`/`output`, the status text (M15.1 D2), the log record (D6), the tool's model-facing strings, the publication gate, `observe.py`'s comparator.
- Model context: OWUI chat flows build model messages from `role`/`content`/`output`/`files`/`contextSummary` (`load_messages_from_db`, `utils/middleware.py:1978`) or, for temporary chats, `{role, output}` per rewritten assistant message (`Chat.svelte`) ⇒ `embeds` never reach a model through them; a raw API caller posting its own fields = outside this claim (as M15.1 U1).
- Scope of a disclosure = the SELECTED candidate (`first_verdict`): its completed prefix, never a trace of each candidate tried.
