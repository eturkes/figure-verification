# M19.4 — judge: values, columns, interpretation

Tier **kernel**: the value stage is the provenance half of the boundary (ruling 4) and the columns stage is the anchoring + G10 law; a wrong match publishes made-up values as data, a missed one blocks an honest chart, and no downstream re-check exists.

## Rulings

- U1 (ruling 4, R2, R4, R6, R7; law `.claude/rules/figure.md` § Values, § Columns): the vocabulary is closed — per attached CSV `raw(K,V)` · `index(V)` · `group(K,V,r)` r ∈ sum mean min max · `count(K)`; a series named by its legend entry with a cell value of column C reads the rows holding it alone (C may be its key); one explanation per series, the rest request numbers; injective, exact binary64 matching (an area point: base + c == far); a strict subset publishes N of M; a column tie is broken by request naming of exactly one, else `column_not_requested`.
- U2 (MAIN): keys — a category axis names the category within half a step; a date axis, the reader's calendar text; a plain numeric axis, the number; a labelled key axis, the label within half the gap between labelled ticks, else (an integral position) a slot bound to the explanation's key order (pandas' order; a raw explanation also its key-sorted order, which a pivot draws). Text keys compare as text, as numbers when both read as numbers, as dates when both read as ISO dates.
- U3 (MAIN): request keys — text must occur in the folded request (R4); a number must be a request number, or every key of the series is the default position 0..n-1; a date must occur as `YYYY-MM-DD` or `YYYY-MM`; a slot is a position. A value typed in the request whose key is not ⇒ `label_not_in_request`.
- U4 (MAIN): reference marks — each value is zero, a request number, a cell of a numeric column, or one whole-column reduction; a value held by exactly one column draws that column, a value several hold draws none and is published as such.
- U5 (MAIN): no attached file and no request number ⇒ integrity alone, disclosed; an attached file the profile refuses whole reports its code when a value stays unexplained.
- U6 (MAIN): drawn columns = K and V of every chosen explanation (+ a reference's one column); R6's label column draws nothing. Anchoring = the moved matcher (`verifier.figure.anchoring`), substitution or strict; G10 over titles, axis labels, suptitle/supxlabel/supylabel, legend entries against every attached header.
- U8 (user R8, session 8; MAIN reading on reviewer-3 F8): a scatter's colour values (colorbar or colour key) and sizes (size key) are drawn values, each bound to its own point's row or group (the scatter's explanation over another numeric column, or a reduction of it per group); their column counts as drawn; a colorbar label is a G10 label. A label no legend shows names nothing (R6 reads the LEGEND label).
- U7 (MAIN): interpretation EN + JA = one sentence per series (source, reduction, N of M, rows per group ≤ 8 shown, request numbers), the integrity-only disclosure, the listed on-chart text (≤ 8 shown).

## Predicates

- **V2** R2: a subset passes with its N of M; a key the source lacks blocks.
- **V3** R4: typed labels both ways, EN + JA; typed ranges (`through`, `to`, `–`, `〜`, `から…まで`) expand; an ASCII hyphen never does.
- **V4** R6: a legend name filters rows; a swapped name blocks.
- **V5** R7: a two-column tie blocks unless the request names one side.
- **V6** U4 reference marks both ways; U5 integrity-only + unreadable file.
- **V7** anchoring: substitution + strict corpora green over value-derived columns (the shipped `tests/test_pysrc_anchoring*.py` stay green on the moved matcher).

- **V9** interpretation: byte-pinned EN + JA sentences for raw, group (with counts), count, subset, request, mixed, reference, integrity-only, listed text, a colour channel.
