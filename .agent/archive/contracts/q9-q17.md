Q17 (a) — compare grid bounds by exact value when both sides fold, sharing Q9's folder. Linspace bounds stay TREES in the projection (only `arange` folds there); the target comparison folds both sides, so `np.linspace(2 + 3, 10, num=3)` binds `x ∈ [5, 10]`.

Soundness guard (MAIN, inside the rulings): every folded NODE must be exact in binary64 and ≤ 2**53 in magnitude, so the fold equals what the executed program computes (Python ints, numpy float64 and IEEE's correctly rounded `+ - * /` all agree there). Without it `np.arange(1/49*49, 5)` folds to start 1 (4 samples) while the program draws from 0.9999999999999999 (5 samples), and a request bound could bind a program bound the program rounds.
