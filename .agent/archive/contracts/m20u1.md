# M20.1 — reader: a draw re-set every text, so each title + label site became the drawing line

Tier **kernel**: `src/verifier/figure/reader.py` is the trusted fact reporter; a text `site` is display only (ruling 13), but no downstream check re-reads it, and M20.2's per-row excerpts list exactly these lines.

## Finding

`Text.draw` re-sets its own text (`with self._cm_set(text=self._get_wrapped_text())`, matplotlib 3.8 + 3.9), and the `set_text` hook recorded the innermost program line on every call ⇒ a draw the program starts — `plt.show()` (the reader captures inside it), `plt.savefig(…)`, `fig.canvas.draw()` — became the site of every title, axis label, suptitle, figure text and axes text. Banner arm `simple`: title/xlabel/ylabel sites 17/17/17 (`plt.show()`), set at 13/14/15. Shipped consequence: a `label_not_consistent` refusal marked the `plt.show()` line.

## Predicates

- **P1** a text set by the program at line L keeps site L across a later draw (`show`, `savefig`, `canvas.draw`, none): titles, axis labels, suptitle, figure text, axes text. `tests/test_figure_reader.py::test_m20_1_a_draw_keeps_each_text_site_at_the_line_that_set_it` (red on `e83878d`: show, savefig, canvas-draw).
- **P2** a later program set outside a draw still moves the site, before and after a draw. `test_m20_1_a_later_program_set_still_wins_after_a_draw` (red on `e83878d`).
- **P3** a `label_not_consistent` refusal carries the refused label's own line under `plt.show()`. `tests/test_pysrc_labels.py::test_m20_1_a_refused_label_marks_the_line_that_set_it` (red on `e83878d`, 3 positions).
- **P4** verdicts unchanged: a site never decides (ruling 13) ⇒ the full suite + rule corpus stay green; C1 + I3 rerun in M20.3.

## Invariants

- Rule: a text's site = the last program line that set it OUTSIDE a draw = no frame named `draw` between the `set_text` call and the program frame (`reader.py::_setter_line`). Artist + legend sites (`_program_line`) unchanged: an artist a draw creates (tick labels) is never reported with a site.
