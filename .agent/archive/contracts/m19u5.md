# M19.5 — Open WebUI wiring: the outlet judges the finished figure

Tier **kernel**: the outlet is the one publication path (tool-call-only PASS transport); a wiring defect publishes an unjudged figure or blocks every figure, and no downstream re-check exists.

## Rulings

- W1 (ruling 1, 7, 10; `.claude/rules/figure.md` § Trust + flow): outlet = receipt → user → browser → owned files → `execute:python` RPC (`webui/paste_in/sandbox.py::wrapper_code(program, font)`, every owned file in `files`) → reply faults (the M15 split, unchanged) → `parse_description(stdout)` (None ⇒ `no_description`) → `judge(description, Sources(owned files as (filename, bytes), receipt request text, artifact anchoring, receipt aliases))` → `Blocked` ⇒ FAIL with its reason + site; `Passed` ⇒ exactly one PNG data-URI line outside the description line (else `no_image`) → one `files` event (raise ⇒ `publish_failed`) → reply `PASS_TEXT + "\n\n" + interpretation` (JA iff kana request). The static path (`first_verdict`, `observe.py`, `selection.py`, `formula_target`) leaves the paste-in.
- W2 (MAIN reading, consultant-1): the CJK font is read (`owui_files.cjk_font`) iff the program or an attached file holds a non-ASCII character, and only after the `no_browser` arm; a font fault ⇒ no font.
- W3 (ruling 8; System-prompt ruling, user session 8: nothing from this repository reaches the production system prompt): the inlet template + the `draw_figure` description state the chart rules. Templates = `webui/paste_in/templates.py`: `Templates(file, no_file)`; `PRODUCTION_TEMPLATES` = base + rules + the `draw_figure` `TRANSPORT` paragraph; `DEMO_TEMPLATES` = base + rules + the bare-source `FORMAT` paragraph (Q40). Inlet: last user message with text content ⇒ the file template over the LAST owned attachment's `/mnt/uploads/` name + its header (core CSV reader), else (no attachment, or a header the reader refuses) the no-file template; non-text content ⇒ body unchanged. The tool returns ONE fixed model-facing string (`verdicts.CHART_SENT`) and decides nothing; the receipt = (program, every attachment id in chat order, request text, parsed aliases).
- W4 (M15/M16/M18 kept; ruling 13): FAIL = one status line `<REASONS sentence> (<reason>)` + one `INFO` log record `figure verification failed reason=<reason>`; every reply = one "Show checks" embed over the 9 checks `program run figure parts axes marks values columns attach` (`CHECK_OF` per the law table, with `category_not_unique` under `values` and `no_image` under `attach`); rows before the failing check ✓, failing ✗ + its cause, rest `not checked`; each row opens to what it does + why it failed + its reference link; the program listing appears on the `program` row once it passed (unmarked) and on the failing row (the judge's `site` line marked as `<mark>`, no site ⇒ unmarked); no other row lists code. Program bytes stay inside the escaped listing alone (M18 escaping + caps kept). Bounded diagnostics (one `STATUS_TIMEOUT_SECONDS` deadline, emits never cost the verdict, cancellation propagates) kept.
- W5: the `columns` row's covers text follows the artifact anchoring (strict = production, substitution = demo), as M16's binding row did.
- W6: the python-mode reference `docs/verification.md` + `.ja.md` = one `check-<id>` section per check with its reasons, data rules, limits incl. the non-adversarial limit (ruling 7); drift test re-keyed to the new checks, reasons + limits (D5's accepted-name scan retires with admission; original firing recorded).

## Predicates

- **O1** outlet order (call-counting bombs on downstream work per arm): no receipt ⇒ `no_tool_call` (no user lookup, no RPC); no user ⇒ `no_user`; no event call / emitter / dict metadata with `session_id` ⇒ `no_browser` (no file fetch, no font read); RPC timeout (60 s) / raise / non-dict ⇒ `browser_timeout` / `browser_error` / `reply_malformed`; reply faults per M15 (`{'error': …}` ⇒ `browser_no_answer`, `loadPyodide` stderr ⇒ `sandbox_unavailable`, other stderr ⇒ `sandbox_error`, null/empty stderr = clean); description absent/garbled/non-string stdout ⇒ `no_description`; judge Blocked ⇒ its reason (+ site into the embed); Passed + no single PNG line ⇒ `no_image`; `files` emit raise ⇒ `publish_failed`; else PASS.
- **O2** RPC payload: `{"type": "execute:python", "data": {"id": <uuid4 str>, "code": wrapper_code(<receipt program>, <font or None>), "session_id": <metadata session_id>, "files": [{"id", "filename"} per owned file, chat order]}}`; a foreign or missing id is dropped; the font read iff W2.
- **O3** Sources threading: the judge sees the owned bytes under their filenames, the receipt's request text, the artifact's anchoring and the receipt's aliases — each pinned by a disagreement witness (a verdict that differs when the threaded value differs).
- **O4** replies: PASS ⇒ last assistant message `content` = its single `output_text` = `Figure verification passed\n\n<interpretation>` (EN; JA on a kana request); every FAIL ⇒ `Figure verification failed, no image produced`; earlier messages untouched; model prose never survives.
- **O5** diagnostics: FAIL ⇒ one status `{description: "<sentence> (<reason>)", done: True}` then one embed `{embeds: [html], replace: True}`; PASS ⇒ `files` event then one all-pass embed, no status, no log; one INFO record per FAIL carrying the code alone; no status/log carries program, request, file or sandbox bytes; bounded emits (M15 D8 + M16 C8 semantics) unchanged.
- **O6** tool: one public operation `draw_figure(program)`; every call writes the receipt (last call wins); returns `CHART_SENT` whatever the program; imports no judge/reader module.
- **O7** inlet: W3 cases both ways; `__metadata__` untouched; a new body + new message dict; production ends in `TRANSPORT`, demo in `FORMAT`, the rest identical.
- **O8** REASONS keys = exactly `FigureReason ∪ OutletCause` (39 + 12 = 51); every text EN = one cause sentence + at most one fix sentence, JA non-empty; `CHECK_OF` total over REASONS, mapping per the law table; hand-stated anchors: `value_not_found` = ("A drawn value is not in your data. Attach a CSV file or write the values in your request.", "描画した値がデータにありません。CSV ファイルを添付するか、依頼文に値を書いてください。"), `bar_not_from_zero` = ("A bar does not start at zero.", "ゼロから始まっていない棒があります。"), `no_description` = ("The browser run did not report the drawn figure.", "ブラウザが描画した図を報告しませんでした。"), `sandbox_unavailable` = M15's bytes.
- **O9** embed: 9 rows in CHECKS order; states per W4; the failing row's cause = REASONS text; `program` row (passed) + failing row list the program, the failing row marks exactly the `site` line (`<span class="line at">…<mark>…</mark>`); site outside the program or None ⇒ no mark; M18 escaping (hidden characters visible, `-.(:=@` as character references, `<`/`&` escaped) + caps (65,536 scanned, ≤ 60 lines, ≤ 3,000 characters, 400 per line) kept; link `SPECIFICATION[lang]#check-<id>` opens a new tab.
- **O10** generated pairs: `--check` clean; artifacts import stdlib + `open_webui` + `pydantic` alone; the filter artifact embeds `verifier.figure.reader` with `__paste_in_source__`; docs drift D3/D4/D6/D7/D9 green over the new tables.
