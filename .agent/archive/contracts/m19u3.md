# M19.3 — judge: figure, parts, axes, marks

Tier **kernel**: these stages are the integrity half of the pass/fail boundary; a rule that misreads a figure publishes a misleading chart or blocks an honest one, and no downstream re-check exists.

## Rulings

- U1 (law `.claude/rules/figure.md`): the judge decides on the reader's final artist facts alone; `origin` attributes a family, `site`/`calls` mark the listing.
- U2 (MAIN): stage order = figure → parts → axes → marks; inside a stage, figures/axes/artists in description order, the first failing rule wins. Axes rule order: `mark_not_in_data` → `scale_not_linear` → `axis_inverted` → `zero_not_in_limits` → `tick_label_mismatch` → `point_clipped` (a truncated bar axis reports the zero rule, not the clip it implies). Mark rule order: `mark_hidden` → `value_not_finite` → bars (`bar_not_from_zero`, `bars_overlap`) → `x_not_ordered` → `hist_counts` → `pie_not_whole` → `area_not_from_zero` → scatter encodings → `legend_mismatch` (all panels, then figure legends).
- U3 (MAIN): a program error outranks everything: `program_syntax_error` (SyntaxError, or text UTF-8 cannot encode) · `module_not_available` (`ModuleNotFoundError`/`ImportError`) · `program_error` (any other exception, or a figure matplotlib cannot draw); then `figure_too_large`, `no_figure`, `multiple_figures` (site = the second figure), `glyph_missing`.
- U4 (MAIN): tick labels — a category axis label must be the category at its position; a date axis passes a matplotlib/pandas date formatter, else each label reads as the ISO date (prefix) at its position; a numeric axis whose labels the program or pandas SET (FixedFormatter, `set_ticklabels`' FuncFormatter, pandas' FuncFormatter) and which carries only keys = a labelled key axis (the values stage reads its labels as keys); every other numeric label must read as a number within half a unit of its last shown digit of its position (ScalarFormatter offset + order, `%` against `PercentFormatter.xmax` else /100 or as is, mathtext powers, `,` groups, one leading currency sign, SI prefix under `EngFormatter`); an `unknown` converter axis with any label blocks.
- U5 (MAIN): a line monotone in key position either way passes `x_not_ordered` (ruling 3: "x monotone per line"); duplicates of a text key are the values stage's `category_not_unique`. Exploded pie wedges keep the radius rule, not a shared centre.
- U7 (MAIN, measured in the corpus): a `%` label reads v/100 or v, never the formatter's `xmax` (a restated 100% rescales the data); one SI prefix (`k`, `M`, …) scales any number label (`1k` at 1000 passes, at 1 blocks); a partial pie needs no rule of its own (its arcs miss 360°).
- U6 (MAIN): an area band = a plain `fill_between`/`stackplot` polygon whose arrays the reader read back; its base edge = the edge that is all zero or equals another band's edge at the same x; else `area_not_from_zero`. A pandas area outline (a plotted line equal to a band edge) is part of that band.

- U8 (MAIN, reviewer-2 F1-F13 accepted; register = `legend_elements` label relabelling + per-bin hist width): a colorbar axes is judged for its own contents + ticks; reference marks clip on every coordinate; a rotated bar is no bar (`artist_not_judged`); pies skip clipping (matplotlib draws wedges `clip_on=False`); power labels `b^{k}` are exact for any base; a currency sign may precede or follow the minus; `.5`, `\%` read; an out-of-range exponent is no number (never an exception); bar overlap compares drawn x/y rectangles with a per-axis tolerance; band stacks must be grounded (bands resting only on each other block); a band that drew fewer points than its call received = `value_not_finite`; pies + reference marks may be legend-named, figure legends resolve handles anywhere, a figure-level `legend_elements` key explains its scatter; `mark_hidden` reads ink (transparent face + edge, no line + no marker, zero size, hidden axes); a call's site = its LAST program line. Legends are read before the mark rules (their encoding keys feed the scatter rule).

## API

`verifier.figure.reasons`: `FigureReason` (closed `Literal`), `Blocked(reason, site)`, `BlockedError`, `block()`. `verifier.figure.parts`: `Mark(family, artists, container, pie, horizontal)`, `Panel(index, axes, marks, texts)`, `panels(description) -> (Figure, tuple[Panel, ...])`. `verifier.figure.shapes`: `Bar`, `bars`, `coordinates`, `band_edges`, `color`, `label`, `series_marks` (one reading of a mark for every stage). `verifier.figure.ticks`: `labelled(axis)`, `mismatched_tick(axis, key_labels=…)`. `verifier.figure.axes_rules.check_axes(panel)`; `verifier.figure.mark_rules.check_marks(panel, colorbars)`; `verifier.figure.legends.read_legends(panels, figure_legends) -> Legends(names, encodings)`. `verifier.figure.judge`: `check_figure(description)`, `integrity(description) -> Judged | Blocked`.

## Predicates

- **J1 figure.** One witness per U3 reason through `reader.run` → `integrity`; ordering bombs: an error + a second figure ⇒ the error; too_large ⇒ no figure count read.
- **J2 parts.** One `artist_not_judged` witness per I1 census family outside the law's table (errorbar, boxplot, violin, contour, hexbin, quiver, eventplot, stem, broken_barh, table, fill, fill_betweenx, step hist, a user patch, a user `Line2D`, an inset axes, a secondary axis); `raster_image` for imshow, pcolormesh, figimage; `axes_not_judged` for polar; `axes_twin` for twinx/twiny; `axes_overlap` for two overlapping `add_axes`; `no_data` for an empty axes; every judged family passes parts (census honest cases).
- **J3 axes.** Each axes rule: ≥1 blocking program + ≥1 honest twin, both through the real reader; every U4 label form both ways.
- **J4 marks.** Each mark rule: ≥1 blocking program + ≥1 honest twin (stacked, grouped, negative stacks, density hist, donut + exploded pie, stackplot + pandas area, size/colour legends + colorbar, pandas + matplotlib legends, figure legend).
- **J5 sites.** Every blocking witness asserts its `site` = the program line the law names (the offending call when one exists, else the artist's line).
