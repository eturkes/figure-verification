# Q74 — the Japanese font cut without fontTools

Tier **kernel**: the cut becomes part of the trusted font (`.claude/rules/claims.md`): a kept character drawn with a wrong outline or advance would show text other than the text the judge read, and no downstream check re-reads glyph shapes; the reader's glyph count catches a MISSING glyph alone.

## Row

`.agent/deferred.md` row 7: with no fontTools in the 0.12.3 image, the filter sends the discovered Japanese font whole (F7 `ja-whole`: 6,141,697 B RPC source vs 77,545 B cut). Accept: a stdlib cut keeps the Q44 characters on an sfnt font with no fontTools present, F7's `ja-font` source stays ≤ 99,999 B with fontTools absent, and every Q44 leg keeps its verdict.

## Design (MAIN)

- ONE path: `webui/paste_in/sfnt.py` (stdlib only) replaces the fontTools subsetter in `fonts.py::cut` on every server ⇒ the same bytes wherever the filter runs, and the measured path = the production path; `fontTools` leaves the generator's admitted import roots (B6/F8 narrow to `open_webui` + `pydantic`). fontTools stays a test-only dev pin = the oracle.
- Any input the cut does not fully understand ⇒ `None` ⇒ `fonts.cut` returns the whole font (today's 0.12.3 bytes): a refusal costs bytes, never glyphs.
- Measured (host fontTools 4.67.0, `ja-font` characters, 118 kept): fontTools cut of `SourceHanSansJP-Regular.otf` = 14,112 B with subroutines, 13,476 B desubroutinized ⇒ desubroutinize: inline every `callsubr`/`callgsubr`, empty Global Subrs, no `Subrs` in any Private DICT; no renumbering, no operand re-encoding.

## Predicates

- **C1 input** — an sfnt face: `0x00010000` / `true` (TrueType `glyf`, no `CFF `) or `OTTO` (`CFF `, no `glyf`); a `ttcf` collection ⇒ face 0 (what matplotlib draws; table offsets from the file's start). CLOSED table set (consultant-1 Q3): verbatim `OS/2 name cvt fpgm prep gasp VDMX`; rebuilt `head hhea hmtx maxp cmap post glyf loca CFF kern vhea vmtx hdmx LTSH`; dropped `GSUB GPOS GDEF BASE JSTF MATH VORG DSIG meta STAT FFTM PCLT` (layout or vertical-layout-only); any other table (`CFF2`, `fvar` + variations, embedded bitmaps, colour…) refuses. cmap source = the subtable FreeType selects (`find_unicode_charmap`: last UCS-4 (3,10)/(0,4), else last Unicode (platform 0 or 2 any encoding, (3,1), (3,10)) — a format 14 one INCLUDED: FreeType then maps nothing, so the cut refuses rather than map more); its format 4/12 must be sorted, disjoint, inside the table (format 4: last end U+FFFF, glyph arrays inside the subtable), else refuse — at least as strict as FreeType's default validation. Refused ⇒ whole also: a `kern` other than version 0 with format-0 subtables whose length = their pairs + no repeated kept pair; `vhea` without `vmtx` or the reverse; an `hdmx` record shorter than its glyphs; an `LTSH` count ≠ numGlyphs; a `post` shorter than its header; hhea/vhea with no long metric; a repeated table tag; a table past the font; a CFF other than version 1 with one font, `CharstringType` ≠ 2, `SyntheticBase`, a predefined charset, FDSelect other than format 0/3; a charstring operator outside the closed set (path, stem, mask, call, return, endchar, flex, dotsection), a `callsubr`/`callgsubr` whose index is not the operand just pushed, a call into absent subroutines or past their count, nesting past 10, `endchar` with ≥ 4 operands (`seac`, width or not), `return` outside a subroutine, no `endchar`, mask bytes past their program.
- **C2 glyph set** — `.notdef` + the glyph of each kept character the face maps + (TrueType) every component of a composite, transitively; new order = `.notdef`, then by first codepoint served, then components; each kept character maps to its original glyph's new index; a character the face lacks stays unmapped (the reader counts it: a miss blocks, unchanged).
- **C3 flattening (CFF)** — tokens read per Type 2: operands 28 / 32-254 / 255, operators 0-31 with `12 x` escapes; `hintmask` + `cntrmask` take ⌈stems / 8⌉ mask bytes, stems counted across the INLINED stream (`hstem` `vstem` `hstemhm` `vstemhm` operands ÷ 2, + the operands pending at the first mask = the implicit `vstem`); a `callsubr`/`callgsubr` index = the literal operand just before it, biased by the SOURCE INDEX count (107 / 1131 / 32768), local subrs = the glyph's FD's Private DICT (CID) or the top Private DICT (name-keyed); the call operand + operator drop, the subroutine's tokens inline in place without its final `return`; `endchar` anywhere ends the glyph; a `return` not at a subroutine's end, a missing `endchar`, a subroutine index out of range ⇒ refuse. Source CFF charset: format 0, 1 or 2 (a predefined charset, offset 0-2, ⇒ refuse); FDSelect format 0 or 3.
- **C3 identity** — for every kept character: the outline (decomposed pen recording, fontTools), `hmtx` + `vmtx` entries, and FreeType's unhinted outline + advances equal the source's; natively hinted outlines + advances (FT2Font `DEFAULT`, 12 + 100 ppem) equal where FreeType hints natively (CFF, or TrueType carrying instructions; an instruction-free TrueType font is autohinted, whose global metrics follow the glyph repertoire — Q44 accepted such raster differences, as fontTools' own cut shows); CFF: the charstring program equals fontTools' desubroutinized program of the source glyph, hints + hintmasks included, and each kept glyph keeps its SID / CID; TrueType: glyph instructions equal, bytes equal except component indices; FreeType kerning among kept characters equal (each `kern` subtable keeps its coverage, override included); Top + FD `FontMatrix`, Private DICTs (widths, hints) carried verbatim.
- **C3b mapping** — FreeType reads every cut's cmap: `FT2Font(cut).get_char_index(ord(c)) != 0` for every kept character the source maps, `== 0` for one it does not (format 4 = sorted segments + the `0xFFFF` end segment, `idRangeOffset` 0).
- **C4 tables** — written: `head` (checkSumAdjustment recomputed, TrueType `indexToLocFormat` = long), `hhea`/`vhea` (long metric count = glyph count), `maxp` (`numGlyphs`), `hmtx`/`vmtx`, `hdmx` (records padded to 32 bits), `LTSH`, `cmap` (3/1 format 4 + 3/10 format 12 when a kept code is past U+FFFF), `post` (version 3, header kept), `glyf` + `loca` or `CFF ` (Top DICT offsets rewritten, Encoding dropped; Global Subrs empty, no Private `Subrs`; CID: charset format 0 keeps each glyph's CID, FDSelect format 3, FDArray = the FDs kept glyphs use, renumbered; name-keyed: charset of the original SIDs, String INDEX verbatim); `kern` subset (pairs sorted); verbatim + dropped as C1. Table records sorted, tables on 4-byte boundaries, per-table checksums, the font summing to 0xB1B0AFBA.
- **C5 path** — `fonts.cut(font, keep)` = the stdlib cut, else the whole font on `None` or any exception; `fonts.cut_for` unchanged; `filter.py` calls it off the event loop as today; no `fontTools` import anywhere in the generated pair.
- **C6 size** — F7 `ja-font` RPC source ≤ 99,999 B with the cut made by `fonts.cut` itself (`f7_export.py` drops its fontTools cut + its collection exit; a collection now cuts face 0); the leg records the cut's wall time (a pure-Python pass over a 19.5 MB collection is unmeasured); every other F7 leg keeps its verdict (`ja-whole`, `ja-no-font`, `ja-mathtext`, `ja-miss`, `ja-second`, `ja-marker-repeat`, `ja-textpath`); PNGs inspected.
- **C7 image** — measurement `Image` cuts a tracked test font inside `ghcr.io/open-webui/open-webui:v0.12.3` (CPython 3.11.17, no fontTools, network off) and the cut's cmap = the kept characters.

## Found during build (MAIN)

- FreeType selects a format 14 subtable when it is the last Unicode one (then maps nothing): the first draft skipped format 14 and would have mapped characters the whole font draws as `.notdef`, passing a figure the whole font blocks ⇒ format 14 counts, a selected non-4/12 subtable refuses (test `…variation_subtable_freetype_selects_refuses`, host FreeType 2.6.1 measured `[0, 0]`).
- An instruction-free TrueType font is autohinted by FreeType even under `DEFAULT`; its global metrics follow the glyph repertoire, so fontTools' own cut moves hinted points too ⇒ the native-hint oracle applies where FreeType hints natively (`_natively_hinted`).
- The name-keyed path built Font DICTs before checking `cid` (IndexError ⇒ whole font): caught by the FontBuilder name-keyed fixture, fixed before review.
