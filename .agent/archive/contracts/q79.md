# Q79 — the model's note as plain text under a bold label

Tier **kernel**: model-authored text renders through Open WebUI's markdown (marked + its KaTeX, citation, mention, details, colon-fence extensions, `replaceTokens`, raw HTML); escaping is the only barrier and nothing downstream re-checks it.

## Request

User: "Instead of outputting the note as a code block, can we just bold "Model note:" (the rest in plain text)?" ⇒ amends Q78 ruling 2 (`.agent/archive/contracts/q78.md`): the label in bold, the note as escaped plain text, inert as before.

## Renderer facts (Open WebUI 0.12.3 frontend source maps)

- `TextToken.svelte` renders `{token.raw}` (Svelte-escaped text) ⇒ an HTML entity shows literally, so entity-encoding cannot carry the text; an `escape` token renders `{unescapeHtml(token.text)}` = the bare character.
- `katex-extension.ts`: inline openers `$`, `$$`, `\(`, `\pu{`, `\ce{`; display `\[`, `\begin{equation}`; extension tokenizers run before marked's escape tokenizer at each position ⇒ escaping `(` or `[` with a backslash would CREATE a math opener.
- `replaceTokens` rewrites `{{user}}`, `{{char}}`, `{{VIDEO_FILE_ID_…}}` (a `<video>`), `{{HTML_FILE_ID_…}}` in the raw string before marked; mention `<@…>`, citation `[1]`, footnote `[^`, `<details>`, `<u>`, colon fence `:::` all need ASCII punctuation.

## Predicates

- **P1 escape** — `inert.prose(text)` = each character through `inert.visible`, every ASCII punctuation character marked can escape prefixed by `\`, except `(` and `[`; so every backslash in the output opens an escape pair, and no `(` or `[` follows an odd backslash run.
- **P2 oracle** — CommonMark (markdown-it-py, raw HTML on): `**Model note:** ` + `prose(t)` = one paragraph, one `strong` = the label, then text tokens whose content = the visible form of `t` (hostile corpus + Hypothesis).
- **P3 reply** — the note line = `\n\n**Model note:** ` / `**モデルの注記:** ` + `prose(note.strip())`; every other Q78 predicate unchanged (independence N5, Valve N6, off-loop N4, fail-closed).
- **P4 live** — Open WebUI 0.12.3's own renderer over a hostile corpus stored as assistant replies: per message no `a`, `img`, `iframe`, `video`, `details`, `u`, `code`, `em`, `del`, KaTeX element; exactly one `strong` (the label); the paragraph text = `Model note: ` + the visible form of the note.
