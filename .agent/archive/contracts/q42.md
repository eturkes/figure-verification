# Q42 — Japanese suffix naming, strict anchoring only (kernel)

Row: Q42 (Q41 find). Q41 reads only a whole kanji run, so a short word glued to a grouping suffix names nothing: `月別の平均体重` never names `年月` (A3 clinical `c11` refuses `column_not_named`); same for `日別`, `月次`, `月毎`, `月単位`.

User ruling (session 7): contract approved as drafted.

Predicates:
- U1 Strict mode: a whole kanji run = a short word + one suffix from the closed list `別` `毎` `次` `単位` names a header when the short word alone would name it under Q41's T1 (2-4 character name minus its first or last character, one fit, no fold twin, no negation cue). `月別` → `年月`, `日別` → `日付`, `月次` → `年月`.
- U2 Part-of-word exclusion: a run that a Japanese header name overlaps stays that header's (`性別`, `病棟別` keep Q41's overlap rule); the suffix is cut once, at the run's end only.
- U3 The shared matcher is unchanged (demo substitution + G10 labels never read suffixes).

Acceptance: A3 clinical strict false refusals 1/20 → 0/20; 0 false names on every A3 leg, the noise leg extended with suffix forms of every clinical request; A1 numbers unchanged; tests red on Q41's matcher; mutants 0 SURVIVED; `.claude/rules/pysrc.md` law + EN/JA admin sentence.

Risk: a word that ends in a listed suffix by itself (`区別` = distinction, `目次` = table of contents) can name a header whose short word it then contains (`区` → `地区`, `目` → `項目`). Tier kernel; reviewers two, blind.

Kernel review (reviewer-q42-1, reviewer-q42-2, blind, K1-K9 at `3257b62`): no implementation defect; F1 (minor) the law called every A3 addition the request's own month column, though the own leg adds `日付` → reworded; F2 (major) the A3 suffix leg rewrote the 13 `ごと` requests alone (156 pairs) → every clinical request (240 pairs: a grouping word or the existing suffix replaced, a scatter's suffix glued to its x word — MAIN readings); register R1 = the brief's "strict only gains names" vs the required run/stem tie (U3 binds the shared matcher). Acceptance re-review (reviewer-q42-3 at `044e315`): A1-A6 pass; register: the 48 scatter forms are negative controls, the 9 `別` forms equal their originals.
