# M15.1 — the outlet says WHY a figure failed

Tier **kernel**: `webui/paste_in/filter.py` is the sole publication path, and a defect in a FAIL arm (an escaping exception, a moved verdict, untrusted text echoed to a user or a log) has no downstream re-check. Adopts `.agent/deferred.md`'s outlet-diagnosis row, its `stderr`-in-log clause SUPERSEDED by ruling U4.

## Rulings (user, this unit)

- **U1 channel.** Each FAIL reply = one Open WebUI `status` event (rendered above the reply by `StatusHistory`, persisted in the message's `statusHistory`) + one server log record. Model context: OWUI 0.10.2's chat flows build model messages from `output` when present (`process_messages_with_output`) and task prompts from `role`/`content` (`utils/task.py`); every reply this filter rewrites carries `output` ⇒ no chat flow sends `statusHistory` to a model. A raw API caller that posts its own `output`-less messages forwards whatever fields it sends — outside this claim. `PASS_TEXT`, `FAIL_TEXT`, `content`, `output` + the tool's model-facing strings stay byte-identical.
- **U2 wording.** Status line = one plain cause sentence (+ one fix sentence where a fix is known: `sandbox_unavailable`, `browser_no_answer`) + ` (<reason>)`; log record = the reason code alone, no prose beyond a fixed greppable prefix, no ids.
- **U3 language.** Japanese iff the user's request text holds ≥1 KANA LETTER; else English.
- **U4 sandbox.** A sandbox failure shows its cause alone, never `stderr` bytes; the MEASURED loader failure (a blocked `pyodide.js`) names the fix (ad blocker off for this site); every other sandbox failure gets a generic cause, since the sandbox host reports non-loader faults (an upload throwing outside the program's `try`) in the same shape. The log carries no `stderr` either (clinical data can reach an error message).
- **U5 check change (approved).** The outlet differential harness (`_translate_outlet` refuses every non-`files` event) + `tests/test_paste_in_observe_filter.py` O5/O6 (`emitter.events == []`) change to assert the EXACT expected status event, every current conjunct kept; the original firing recorded in the unit commit.

## Predicates

- **D1 — vocabulary.** `webui/paste_in/reasons.py` = data only: `OutletCause` + `REASONS: dict[Reason, tuple[str, str]]` (EN, JA), key set = `get_args(RefusalCode)` ∪ the 14 above, disjoint. Accept: exact-set test, the 14 hand-stated as literals.
- **D2 — text law.** Per entry: EN printable ASCII, ends `.`, sentences split at `. ` (a dot inside a code name such as `plt.show()` ends none), each ≤ 25 words, ≤ 2 sentences (2 only for `sandbox_unavailable` + `browser_no_answer`); JA holds ≥1 kana, ends `。`; neither holds `\n`, `{`, `}`. Status text = `f"{sentence} ({reason})"`, display width ≤ 100 columns (`unicodedata.east_asian_width` W/F = 2, else 1) — a proxy for one unclamped line of OWUI's `line-clamp-1` status item at a 1280×800 window with the sidebar open (L4 decides).
