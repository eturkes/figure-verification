- OpenVINO GenAI API gotchas: chat is STATELESS `tok.apply_chat_template(messages, add_generation_prompt=True)` per request (NOT `start_chat`/`finish_chat`, which keep server-side history). The current string overload defaults `GenerationConfig.apply_chat_template=True`: handing the already-templated string to `pipe.generate([str], cfg)` wrapped it AGAIN (live 24 admitted tokens → 43 native), invalidating preflight. Canonical path = `tok.encode(..., add_special_tokens=False)` → pass that exact `TokenizedInputs` to `generate` → `EncodedResults.tokens[0]` → `tok.decode`; admitted then equals native input tokens on CPU + NPU, and NPU overflow returns `prompt_too_long`. Config: start from `cfg = pipe.get_generation_config()` + mutate in place — a fresh `GenerationConfig()` drops eos/stop_token_ids + `repetition_penalty` (1.1→1.0) and defaults `max_new_tokens` to 2**64-1; `GenerationConfig(other)` is NOT a copy ctor. Greedy = `do_sample=False` → byte-identical repeats for a FIXED (device,config) (text is config-sensitive); `do_sample=True` needs `cfg.temperature=` set too (else stuck at 1.0). Usage tokens: `pm.get_num_input_tokens()` / `get_num_generated_tokens()`. Finish reason: `EncodedResults.finish_reasons[0]` = `GenerationFinishReason` (STOP/LENGTH/NONE/TOOL_CALL), authoritative over a `completion_tokens>=max_tokens` heuristic (natural EOS at cap reports STOP) → LENGTH→"length", else "stop".
- Device = `NPU` (default; local OpenVINO preference NPU>GPU>CPU — the symmetric export runs on the AI Boost NPU, byte-deterministic greedy). NPU compiles to STATIC shapes → `Engine.load` passes `MAX_PROMPT_LEN=max_prompt_len` for NPU only (GPU/CPU reject the compile property). Every device preflights the chat-templated prompt with `tok.encode(..., add_special_tokens=False, max_length=cap+1)`, checks `input_ids.shape[-1]`, then forwards that SAME buffer; exact cap generates, over-cap returns canonical HTTP-400 `prompt_too_long` before native generation. The installed tokenizer's `max_length` does not truncate an unpadded sequence, and cap+1 also detects an implementation that truncates at the sentinel. Backend request bodies stop at 128 KiB before decode. Verifier maps ONLY canonical status/media/body bytes to policy 422; lookalikes remain 502. GPU/CPU stay a documented fallback (`MODEL_BACKEND_DEVICE=AUTO:GPU,CPU`, dynamic shapes; the stock asymmetric IR loads there directly).

Response reads request + ENFORCE identity coding, then caps raw bytes at limit+1 before status/decode; ignored identity coding fails 502 before transparent decompression. Trusted-file principle: a transport-edge read of a TRUSTED file maps only genuine absence→404; a present-but-wrong-shape/permission fault propagates→500.
