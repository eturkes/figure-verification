# M10.0 — python mode as the demo's ONE operation

Tier **kernel**. Gate identity `bash tools/gate.sh`; purpose-built checks carry probes in
`tools/gate-probe.sh`. Dispatch: `test` (diff-blind red suite from these predicates) + `orc`
(independent tool-behaviour implementation → differential); MAIN holds the primary tree.

## What this unit ships

1. **A generator** turning tracked sources into the production paste-in. Single source, hand fork
   banned (`.agent/spec.md` § Decisions): the verification core is written once under
   `src/verifier/pysrc/`, and the pasted artifact embeds it BY GENERATION.
2. **The OWUI tool** — one model-visible callable over python mode, reading the user's uploaded CSV
   bytes in-process from Open WebUI storage (user ruling), handing them to the core as
   `DatasetTarget(path, content)`.
3. **The exposure change** — the JSON-spec `proposeSpec` operation becomes unreachable from the demo
   model; the provisioned tool is the sole model-visible callable.

The filter artifact is M10.1's; this unit builds the generator both artifacts share.

## Rulings restated (the agent measures shipped code against these for free)

- The model authors the EXECUTED bytes; a verifier-(re)authored script is REJECTED (ruling 1).
- A grammar may constrain FORMAT, never ADMISSION (ruling 5). No prompt, no tool description and no
  hard-coded branch may move the pass/fail boundary out of the verifier.
- Prompts carry task + format + dataset binding only; admission vocabulary is banned everywhere
  (ruling 6). The 19 stems are `capture/corpus.py` `_BANNED_STEMS`.
- Demo-grade: no sealing, escrow or tamper ceremony (ruling 7).
- Transport ruling (user, this unit): **tool call only**. Only an authentic backend-recorded tool
  call may publish a figure. A fenced program in the reply is not a publication path.
- Packaging ruling (user, this unit): **two generated files**, one per paste target. This supersedes
  `Intent`'s "one file" wording.
- CSV ruling (user, this unit): **OWUI storage in-process**. `open_webui` is part of the image, so
  it sits inside `Intent`'s dependency envelope; the truth source stays the user's own upload.
- The `:8000` service is NOT widened (user): no route, no `PlotSourceKind` member, no SQLite
  schema-version bump.

## Predicates

Bundle — `webui/paste_in/bundle.py` + `tools/generate_paste_in.py`.

| id | predicate | acceptance check |
|---|---|---|
| B1 | Generation is deterministic and idempotent, and the committed artifact equals a fresh generation. | `uv run --locked python tools/generate_paste_in.py --check` rc=0 on a clean tree; a planted one-byte edit to a committed artifact makes it rc=1 naming that file. |
| B2 | Every embedded module source is its tracked file's bytes, prefixed by exactly one `\n` and nothing else. | For each embedded name, `sources[name] == "\n" + tracked_bytes`; a planted edit inside the artifact's embedded blob goes red. |
| B3 | The embedded set is exactly the transitive first-party import closure of the artifact's root module, plus the parent packages that closure needs. | The generator recomputes the closure by AST and asserts set equality with the emitted keys; an extra module and a missing module both fail. |
| B4 | Emission order is a topological order of that closure: every module's first-party dependencies are emitted before it. | Over the committed artifact, each dependency's index is lower; an order reversal fails. |
| B5 | Loading the artifact leaves `sys.modules` exactly as it found it — no key added, no value rebound. | Snapshot/compare around an `exec_module`; red under a loader whose restore is removed. |
| B6 | The artifact's import surface, taken over the wrapper AND every embedded source, is stdlib plus `open_webui` and nothing else. | AST scan naming every offending root; a planted `import numpy` inside an embedded blob fails. |
| B7 | The artifact is self-contained: it works with `verifier` absent and `src/` off `sys.path`. | Subprocess with a scrubbed path verifies a known-good program and refuses a known-bad one, verdicts equal to the in-tree core's. |
| B8 | Generation fails closed on a source it cannot embed faithfully. | A source containing `'''`, or ending in a backslash, or whose emitted first line would exceed the line-length cap, aborts generation naming the file. |

Tool — `webui/paste_in/tool.py`.

| id | predicate | acceptance check |
|---|---|---|
| T1 | The artifact exposes exactly ONE model-visible callable, and the reserved `__…__` parameters are absent from its model-facing schema. | OWUI's own spec builder over the artifact returns one spec whose name is the operation's; the parameter set equals the declared non-reserved set. |
| T2 | The verdict is derived from `verify_python_source` alone. | A mutant returning the pass string for a refused program goes red; a mutant ignoring the refusal code goes red. |
| T3 | The CSV bytes handed to the core are the uploaded file's exact bytes, fetched for the path the program names, and an absent file refuses instead of verifying. | Fake storage: bytes handed to the core are `cmp`-identical to the fake's; a program naming an unattached file returns the refusal. |
| T4 | The tool returns text from a closed set and never echoes model bytes. | The return value is a member of the closed verdict set, refusal codes included; a program whose source contains a marker string returns text not containing it. |
| T5 | The target is `DatasetTarget(path=<the literal the program passed to read_csv>, content=<uploaded bytes>)`, and a path mismatch refuses `target_mismatch` rather than being normalized away. | Spy the core call; a program reading `/mnt/uploads/other.csv` against an attached `sales.csv` refuses `target_mismatch`. |
| T6 | Access control is the caller's: a file the requesting user does not own is never read. | The ownership-checked accessor is the one called; a fake raising on a foreign id makes the tool refuse rather than fall back. |

## Probe seed

Purpose-built checks added here that no upstream tool owns, each earning a `tools/gate-probe.sh`
probe that mutates ONE tracked file and demands a nonzero rc whose output names the cause:

- the artifact-freshness check (B1) — probe plants a byte in a committed artifact;
- the embedded-source identity check (B2) — probe edits an embedded blob only;
- the import-surface check (B6) — probe plants a non-stdlib import inside an embedded blob;
- the banned-stem check over the tool description (E3) — probe plants a stem.

## Amendments

**T4-1 — DROP "refusal codes included" from T4's acceptance check.** The closed return set is
exactly the TWO strings in `webui/paste_in/verdicts.py`. Five of the 52 closed refusal codes carry
the banned stem `admit` (`call_target_not_admitted`, `keyword_not_admitted`,
`statement_not_admitted`, `attribute_not_admitted`, `assign_target_not_admitted`), so a code in the
reply would teach admission vocabulary through the one surface ruling 6 keeps clean. Nothing needs
the code: the outlet filter re-derives the verdict from `sources[].metadata[].parameters`, not from
the reply text. T4's first half — closed set, no model bytes echoed — is unchanged.

**B5-1 — B5's "no key added" is stated over the EMBEDDED module names, not over `sys.modules` as a
whole.** Loading the artifact adds stdlib keys because the embedded sources import them; that is
what any import does, and unregistering them would be the defect. The predicate the loader owns:
after `_load()`, zero `_SOURCES` keys remain in `sys.modules` and zero pre-existing entries are
rebound. Measured over the committed artifact under a scrubbed subprocess: 23 stdlib keys added
(`_blake2 _csv _decimal _hashlib _json copy csv dataclasses decimal fnmatch fractions glob grp
hashlib json json.decoder json.encoder json.scanner ntpath numbers pathlib pathlib._abc
pathlib._local pwd`), 0 embedded names left, 0 entries rebound. Open WebUI's own
`load_tool_module_by_id` registers `sys.modules[f"tool_{tool_id}"]` and never removes it on
success; that residue is OWUI's and outside this predicate.

**B8-1 — B8's unembeddable class gains two fault shapes** beyond `'''`, a trailing backslash and
the line cap:

- a source carrying any of `"from utils"`, `"from apps"`, `"from main"`, `"from config"`. Open
  WebUI's `replace_imports` (`utils/plugin.py:186-200`) rewrites those prefixes in tool content on
  every create and update, so the stored bytes would differ from the generated ones and E2's byte
  equality would fail at provisioning time rather than at generation time.
- a source carrying no `"""`. The embedding delimiter is `'''`, and `ruff format` rewrites a raw
  `'''` literal to `"""` whenever the body permits it, which breaks B1's `--check` on the next gate
  run.
