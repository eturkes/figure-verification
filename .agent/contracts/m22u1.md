## Threat surface (from `.agent/spec.md` `Intent` + `Artifacts`)
- Shipped = the paste-in pairs (`paste-in/figure_verification_{tool,filter}.py` strict; `webui/demo-paste-in/` substitution), import-executed INSIDE an Open WebUI 0.12.3 server on CPython 3.11: tool `draw_figure` (model-called; Valve `column_aliases`, owner/admin/write grant), filter inlet (every chat request: last owned CSV header, template render), outlet (every completion: receipt → request text from chat storage (Q66) → owned files → sandbox isolation → font discovery + stdlib sfnt cut (Q74) → `execute:python` RPC to a browser → description decode → judge → `content`/`output`/`files`/`status`/`embeds`); filter Valve `cjk_font_path` (admin). The trusted reader runs inside Pyodide in the user's browser.
- Demo = `webui/launch.sh` → OWUI :8080 + model backend (Litestar, demo adapter incl. Q65 `History:` parsing) or stub :8001 + the demo pair; harness `webui/client.py`; Node measurement harnesses `.agent/measurements/` (dev-only, never served).
- Actors: any authenticated chat user (request text, uploads, chat params incl. `chat_id`/`message_id`/`session_id`, own stored chat history, own browser answering the RPC); the author of an uploaded CSV (indirect prompt injection); the model (program bytes + tool args: untrusted output; non-adversarial for the VERDICT, never for the server or other users); other users of the instance; a non-admin holding a tool write grant (`column_aliases`); the admin (trusted: Function Valves, env).
- Assets: other users' chats, files + browser sessions; server availability (event loop, worker threads, memory); the OWUI origin (markdown/embed → token theft, exfiltration through rendered URLs); admin settings; server files beyond fonts; the dev host + CI (supply chain); secrets.
- Accepted by `Intent` (not findings unless a doc overstates them): the program runs before any check in the reader's interpreter + reaches the browser's network (CSV + request exposure = stock code-interpreter posture, integrity ruling 7); a user can forge their OWN verdict through their own browser; no sealing/tamper evidence; on-chart prompt injection steering the model's program inside the null-origin sandbox.
