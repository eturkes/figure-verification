# M13.7 — the proposer-side lever M13.6 cannot reach

Tier: **data**. The deliverable is a corpus artifact — one capture run — behind validators that
already exist and re-grade it at every use: `capture/corpus.py` C1-C10, `capture/record.py` R1-R11,
`capture/harness.py` S1-S4, `tests/test_python_capture_run.py` T1-T4. A defect in captured bytes is
caught by the consumer for free and fixes forward by re-capturing. The ONE judgment-bearing byte in
this unit is the prompt template's new sentence, and it is graded by C6 + C7 rather than by
opinion. No adversarial battery; one structural validator plus a live spot-check, per `CLAUDE.md`
Assurance.

## What this unit decides

M13.6 widened the admitted subset to everything the measurement said was blocking, and the design
captures still verify 0/25. 17/25 refuse `name_not_bound` because the proposer writes `pd.read_csv`
with no `import pandas as pd`. The program really would `NameError`, so the refusal is CORRECT and
no admitted width repairs it. The lever is the capture prompt, and it is the user's, inside ruling
6: NAME pandas as the CSV reader — task phrasing, never admission vocabulary.

That reverses one standing line of `.claude/rules/python-corpus.md`, which says the CSV-reading
library is "deliberately unnamed so captures observe the model's own idiom choice". Observing the
idiom choice was worth its cost and the observation is now IN: the model picks pandas and forgets to
import it. The line dies in the commit that supersedes it.

The template is sha256-pinned in `capture/corpus.py` and every capture record carries that hash, so
the edit INVALIDATES every committed run. Template edit + `m12-design`'s removal + the fresh design
capture are ONE commit, or `tests/test_python_capture_run.py` grades a run whose prompt hash no
longer matches.

## Blockers a naive pass walks into

- Editing the template WITHOUT moving `CAPTURE_PROMPT_SHA256` leaves C7 red, which is loud. Editing
  both without removing `m12-design` leaves every record's `capture_prompt_sha256` stale, which is
  ALSO loud — but only through `tests/test_python_capture_run.py`, so a subset test run hides it.
- `--resume` after a partial run refuses on `git_dirty` rather than on anything descriptive. The
  repair is `--overwrite` and a fresh single invocation, not a resume flag hunt.
- A client `--max-tokens` above the server's silently clamps, and the manifest then records a
  ceiling the run never had. Set the SERVER value first.
- The banned-stem regex is word-start with any suffix, so "supported", "policy" and "verifies" all
  fire from ordinary prose. Write the new sentence as a bare instruction.
- `corpus/` holds NO Python: `tests/corpus.py` owns that top-level module name, and a `corpus`
  package raises a duplicate module under mypy.
