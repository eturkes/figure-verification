# M17.2 — Japanese certificate interpretation for a Japanese request

Tier **kernel**: `CoreCertificate.interpretation` = the one core string a clinician reads (tier 3 publication, `.claude/rules/pysrc.md`); a Japanese twin that misnames an axis, a reduction or a count misdescribes the verified figure with no downstream re-check, and the filter's PASS rewrite is the sole publication path.

## Rulings

- **U1 (user).** A request holding a kana letter gets the tier-3 interpretation in Japanese; the verdict line `Figure verification passed` stays English (`Intent`); every other request keeps today's English bytes.
- **U2 (MAIN).** The Japanese rendering lives in the core beside the English one: `CoreCertificate.interpretation_ja: str`, built by `certify` from the same `(spec, table, group_counts, target)`; the certificate stays request-agnostic (both renderings, the reader picks). A new field moves the field-set pin deliberately (original firing recorded at close).
- **U3 (MAIN).** Language switch = the filter's existing `_japanese(__metadata__)` (M15 U3: ≥1 kana LETTER in `__metadata__["user_message"]["content"]`), shared with the status line + the checks embed.
- **U4 check change (implied by U1 + U2).** (a) Assertions that a kana-request PASS reply carries the ENGLISH interpretation change to the Japanese one, every other conjunct kept: `tests/test_paste_in_filter_checks.py` C7 JA PASS cases, `tests/oracle_filter.py` + `tests/test_paste_in_filter_differential.py` PASS expectation, any other suite the tester finds. (b) BOTH certificate field-set pins gain `interpretation_ja`: `tests/test_pysrc_certificate.py` K1 + `tests/test_pysrc_formula_target.py` (its version + refusal-count conjuncts kept). Original firing recorded at close.
- Unchanged: `interpretation` (EN) bytes, `PASS_TEXT`, `FAIL_TEXT`, the FAIL arms, the status text, the embed, the tool's model-facing strings, every digest (`interpretation*` is not hashed).

## Japanese grammar (byte-pinned; human-facing = natural polite Japanese, the admin guide's terms)

Words: marks `bar` 棒グラフ · `barh` 横棒グラフ · `line` 折れ線グラフ · `scatter` 散布図; reductions `sum` 合計 · `mean` 平均 · `min` 最小値 · `max` 最大値; axis letters per mark exactly as the EN `_AXIS_LETTERS` (barh swaps). `{q(s)}` = `json.dumps(s, ensure_ascii=False)` (the EN `_quote`); `{P}` = `binary64-libm-v1`; numbers + expressions = the EN renderers (`_expr_text`). Sentences join with NO separator; one ASCII space separates an ASCII token (letter, number, quoted string, expression) from adjacent Japanese text, never before `。` `、` or after `: `.

- Dataset, column pair: `グラフの種類: {mark}。データはファイル {q(path)} から読み込みます。{A} 軸は列 {q(x)} を表します。{B} 軸は列 {q(y)} を表します。描画する行は {n} 行です。数値はプロファイル {P} に従います。`
- Dataset, aggregate: `グラフの種類: {mark}。データはファイル {q(path)} から読み込みます。{A} 軸は列 {q(x)} のグループを表します。{B} 軸は各グループの列 {q(y)} の{reduction}を表します。{rows} 行から {groups} 個のグループを描画します。数値はプロファイル {P} に従います。`
- Formula: `グラフの種類: {mark}。データは送信されたプログラムから計算します。{bound}Y は {expr(y)} を計算します。X は {expr(start)} から {expr(stop)} までの {samples} 点です。数値はプロファイル {P} に従います。` with `{bound}` = Grid target `数式、x の区間、サンプル数は依頼と一致します。` · Interval `数式と x の区間は依頼と一致します。` · FormulaTarget without grid `数式は依頼と一致します。` · no FormulaTarget `` (empty), exactly as the EN branch.
- Labels, appended in this order when present: `X 軸ラベル: {q(xlabel)}。` `Y 軸ラベル: {q(ylabel)}。` `タイトル: {q(title)}。` (EN: `X label:` / `Y label:` / `Title:`, same order, same presence rule).

## Predicates

- **I1 — field set.** `CoreCertificate.__dataclass_fields__` = the pre-unit 11 names + `interpretation_ja`, in that order. Accept: hand-stated tuple.
- **I2 — Japanese bytes.** One hand-stated literal per branch: column pair over each of `bar` `barh` `line` `scatter`; aggregate over each of `sum` `mean` `min` `max` (one of them `barh`); formula unbound, FormulaTarget grid `None`, Interval, Grid; labels: each of the three alone + all three (order), a label holding `"`, `\` and a newline (JSON-quoted). Accept: literals written from this grammar, never read back from the implementation.
- **I3 — English unchanged.** Every pre-unit `interpretation` witness (`tests/test_pysrc_certificate.py` K6 + the formula-target suite) passes unchanged; plus the same branch set as I2 in English as literals.
- **I4 — model-free + total.** No BOUND program name (`frame`, `grid_points`, `curve_values`, …) becomes interpretation semantics; quoted path, header and label text stays verbatim even where it coincides with a bound name; every Verified the corpus + suites produce carries a non-empty `interpretation_ja` starting `グラフの種類: `; the closed maps (mark, reduction) are exact-key pinned (near-miss: a fifth mark fails at the lookup, no default arm).
- **I5 — filter PASS.** Kana request ⇒ `content` = `PASS_TEXT + "\n\n" + interpretation_ja` and `output` the same single text; a kanji-only or ASCII request, or malformed LANGUAGE subfields inside a valid session `dict` (`user_message` missing / non-`dict`, `content` missing / non-`str`) ⇒ the pre-unit English bytes; a non-`dict` or session-less `__metadata__` still FAILS `no_browser` (unchanged); FAIL arms untouched. Accept: dataset + formula PASS × (kana, kanji-only, ASCII, each malformed language subfield).
- **I6 — differential.** `tests/oracle_filter.py` derives the language from its OWN hand-stated kana rule and expects the matching rendering; `_translate_outlet` compares `content`/`output` exactly. Accept: green on the implementation, red on the pre-unit filter for a kana PASS scenario.
- **I7 — generation.** Both pairs regenerated; `--check` clean; the tool's model-facing strings byte-identical (existing pins).
- **I8 — mutation credit.** `tools/mutants/certificate.toml` + `tools/mutants/filter.toml`: every existing mutant KILLED, one per seed row; `tests/test_mutation_catalogues.py` pins them; 0 SURVIVED, 0 ANCHOR-MISS.
