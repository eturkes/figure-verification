# M21.1 — security review of the implementation
Tier **kernel** for every fix below informational (a security defect has no downstream re-check); the review itself = a judgment pass, rows fixed here BEFORE any reachable code is read.

## Threat surface (from `.agent/spec.md` `Intent` + `Artifacts`)
- Shipped = the paste-in pair (`paste-in/figure_verification_{tool,filter}.py`), import-executed INSIDE an existing Open WebUI server: the tool `draw_figure` (model-called), the filter inlet (every chat request) + outlet (every completion), the `execute:python` RPC to a browser, the trusted reader (`src/verifier/figure/reader.py`) inside Pyodide, the embed HTML + `content` the outlet writes.
- Demo = `webui/launch.sh` → OWUI 0.10.2 :8080 + model backend / stub :8001 + the demo pair; the Node measurement harnesses `.agent/measurements/` (dev-only, never served).
- Actors: any authenticated chat user (request text, uploads, chat params, own browser answering the RPC); the author of an uploaded CSV (indirect prompt injection); the model (program bytes = untrusted output, `Intent`: non-adversarial for the VERDICT, never for the server or other users); other users of the instance; the admin (trusted, Valves).
- Assets: other users' files + browser sessions, server availability (event loop + worker threads + memory), the OWUI origin (embed/markdown → token theft, data exfiltration through rendered URLs), admin settings, the dev host + CI (supply chain), secrets.
- Accepted by `Intent` (not findings unless a doc overstates them): the program runs before any check in the reader's interpreter + reaches the browser's network; a user can forge their OWN verdict through their own browser; no sealing/tamper evidence.

## Rules for findings
Each finding: severity (critical · high · medium · low · informational), `file:line` at the reviewed SHA, a red test or a repro command + its output. Above informational ⇒ fixed in a scoped commit with a green acceptance check, gate green at that commit. Informational ⇒ `.agent/deferred.md` row + acceptance check.
