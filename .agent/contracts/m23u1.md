## Threat surface (from `.agent/spec.md` `Intent` + `Artifacts`)
- Shipped A = the Open WebUI 0.12.3 pairs (`paste-in/` strict, `webui/demo-paste-in/` substitution), import-executed inside the Open WebUI server on CPython 3.11: tool `draw_figure(program, note)` (model-called; Valves), filter inlet (every chat request), outlet (every completion: receipt → request text from chat storage → owned files → isolation → font discovery + stdlib cut → `execute:python` RPC to the user's browser → decode → judge → `content`/`output`/`files`/`status`/`embeds`, the model note under a pass); filter Valves (`cjk_font_path`, `model_note`).
- Shipped B (new since M22.1) = the nucllei skill (`llens/nucllei/tools/figure_verification.py` + `llens/nucllei/skills/figure-verification.md`, from `nucllei_skill/`), import-executed inside a nucllei server (Open WebUI 0.6.5 fork, CPython 3.11): `draw_figure` = stored chat branch read → owned files → ONE `POST /exec` to the user's nsjail sandbox → decode → judge → PNG upload into nucllei storage + file row → ONE `__display__` markdown push + a markdown tool result (the model's text); hooks `available` + `spec_overrides` (model-facing description per turn); its Valves. Plus the static offline guide `llens/ext/public/figure-verification/` an admin serves under `/ext/public/`.
- Demo = `webui/launch.sh` → Open WebUI :8080 + model backend / stub / codex bridge on :8001 (new: `webui/codex_bridge.py` → one `codex app-server` child on the operator's ChatGPT tokens) + the demo or production pair; per-instance signing key file (new); port-ownership teardown (new); harness `webui/client.py`; Node harnesses `.agent/measurements/` (dev-only, never served).
- Actors: any authenticated chat user (request text, uploads + their names, chat params incl. ids, own stored chat JSON, own browser answering the RPC); the author of an uploaded CSV (indirect prompt injection); the model (program bytes + note + tool args = untrusted output: non-adversarial for the VERDICT, never for the server, storage or other users); other users of the instance; a non-admin holding a tool write grant; the admin (trusted: Valves of functions, env, file placement).
- Assets: other users' chats, files, sandboxes + browser sessions; server availability (event loop, worker threads, memory); the host origin (markdown/embed/display → token theft, exfiltration through rendered URLs); server storage + filesystem; admin settings; the operator's ChatGPT tokens + dev host (codex arm); the dev host + CI (supply chain); secrets.
- Trust model (request body): env vars + CLI flags = trusted; the server = the enforcement boundary; framework auto-escaping holds outside raw-HTML sinks. Accepted by `Intent` (findings only where a doc overstates them): the program runs before any check in the reader's interpreter + reaches the browser's network (Open WebUI) or the user's own jail (nucllei); a user can forge their OWN verdict through their own browser or sandbox; no sealing/tamper evidence; prompt injection steering the model's program inside the sandbox; request length + attachment count unlimited (second security-review rulings 1 + 2).
