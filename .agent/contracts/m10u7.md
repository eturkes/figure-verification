# M10.7 — license headers + measurement-harness rerunnability

Tier **docs**, plus one purpose-built gate check: headers carry no behaviour and G14 re-decides
them at every gate run; the harness repair is re-checked by rerunning it. Gate identity
`bash tools/gate.sh`; positive controls `bash tools/gate-probe.sh`. Dispatch: `test` (G14 + its
probe, red at the base), `prod` (headers, the T6 + `versions.mjs` repair, README); MAIN holds the
primary tree + gate and writes the law prose (`.claude/rules/ops.md`, `.agent/spec.md`).

## Rulings restated

- `.claude/rules/ops.md`: license `Apache-2.0 WITH LLVM-exception`; SPDX header in every source
  file.
- `CLAUDE.md` Engineering: a rule a tool can decide belongs to a deterministic check; an uncovered
  invariant gets a purpose-built check wired into the gate, shipped with the input that makes it
  fail, its firing recorded.
- `.agent/measurements/` = frozen evidence, outside the gate and outside `mypy` `files` by ruling;
  a published number is re-derived by RERUNNING a committed harness, never by reading a stored
  file.
