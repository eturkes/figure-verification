# M13.3 — projection (formula arm) + by-construction integrity pins

Tier **kernel**. Dispatch: MAIN authors the core spec representation + `project.py` (judgment-bearing
— projection IS what the verifier claims a program plots); `test` teammate builds the diff-blind red
suite from the predicates below; `orc` teammate writes an independent projection against this
contract alone as a differential oracle.

## What this unit decides

Admitted AST → core plot spec. Admission answers "may these bytes run"; projection answers "what do
they draw". It is the surface where THE PROJECTION GAP is closed: *what the projection says the
script plots* ≡ *what the script plots when executed*. Closed BY CONSTRUCTION here via P11 (total
statement coverage), so no admitted statement can carry an effect the spec omits.

Scope is the formula arm alone — the one the current allowlist already admits. The spec
representation is a tagged union carrying BOTH arms from the start; the dataset variant is declared
and refused-as-unimplemented, so M13.4 widens the allowlist without reshaping the core.

Evaluation policy is NOT this unit. Projection represents faithfully — an `np.pi` endpoint and an
`np.sin` call project to structure, and M13.5 rules how each is compared.

## Surfaces

- `src/verifier/pysrc/spec.py` (new) — stdlib-only frozen dataclasses, no msgspec. Core expression

## Predicates

| id | predicate | acceptance check |
|---|---|---|
| P1 | A program with no mark call refuses `no_mark`. An empty program refuses `no_mark`, not `no_statements`. | admitted decoration-only program → `no_mark` |
| P2 | Exactly one mark call. A second refuses `multiple_marks`. | two `plt.plot` calls → `multiple_marks`; one → spec |
| P3 | The mark's x argument resolves to a grid — a name bound from `np.linspace`/`np.arange`, or that call inline. Anything else refuses `x_not_a_grid`. | `plt.plot(3, y)` → `x_not_a_grid`; both bound + inline forms → equal specs |
| P4 | The mark's y argument resolves to an expression whose only free name is the grid variable. A second free name refuses `y_not_over_grid`. | `x=…; z=…; plt.plot(x, z)` where `z` is its own grid → `y_not_over_grid` |
| P5 | `np.arange` and `np.linspace` project to the SAME `Grid` shape; `linspace` `num` defaults to 50 when absent, `arange` step defaults to 1. | defaults pinned as literals in the test, never read from the module |
| P6 | Sample count is a positive int literal within `limits`; a float, zero, negative or non-literal refuses `grid_not_representable`. | `num=0`, `num=2.5`, `num=n` each → `grid_not_representable` |
| P7 | Decoration calls project to a labels record; a non-string-literal argument refuses `label_not_literal`. | `plt.title(x)` → `label_not_literal`; `plt.title("t")` → `labels.title == "t"` |
| P8 | Exactly one `plt.show()`, and it is the final statement. Zero refuses `no_terminal`; a non-final one refuses `statement_after_terminal`. | all three cases |
| P9 | Rebinding a name already bound refuses `name_rebound`. | `x = np.linspace(0,1); x = np.arange(3)` → `name_rebound` |
| P10 | `plt.bar` refuses `mark_not_valid_for_arm` in the formula arm (G5 — a sampled function has no categorical magnitude). | `plt.bar(x, y)` over a grid → `mark_not_valid_for_arm` |
| P11 | **Total statement coverage.** Every admitted statement contributes to the returned spec; a statement whose effect the spec does not represent refuses `statement_not_projected`. No statement is silently ignored. | an assignment never reaching the mark → `statement_not_projected` |
| P12 | Projection is a pure function of the tree: same tree → equal spec, and the spec holds no `ast` node, no line number and no source text. | equality over two parses of the same bytes; a search test over `spec.py` for `ast.` |

## Integrity pins (G-rules that hold BY CONSTRUCTION)

Each row asserts BOTH halves, because either alone rots: the target name is absent from
`ADMITTED_CALL_TARGETS`/`ADMITTED_KEYWORDS`, AND a concrete program using it is refused. Widening the
allowlist must BREAK these, never silently delete the rule.

| id | pinned absent | refusal witness |
|---|---|---|
| G1 | `plt.ylim` | `plt.ylim(50, 100)` after a bar → `call_target_not_admitted` |
| G2 | `plt.twinx` `plt.subplots` `plt.subplot` `plt.gca` `plt.figure` | each → `call_target_not_admitted` |
| G3 | `plt.yscale` `plt.xscale` `plt.semilogy` `plt.loglog` | each → `call_target_not_admitted` |
| G6 | keyword `s` on `plt.scatter` | `plt.scatter(x, y, s=v)` → `keyword_not_admitted` |

## Invariant surfaces

- Core stays **stdlib-only**: no `msgspec`, `litestar`, `verifier.schema`, `verifier.expr` import
  anywhere under `src/verifier/pysrc/`. One committed search test.
- No prompt text, prompt hash, sample-specific field list or raw model reply in production code
  (existing law; the search test covers the new files).
- Refusal codes stay closed and grouped by stage; a new member needs a distinct fault shape.
- `PysrcRefusalError` carries a code and never bytes from the source.
