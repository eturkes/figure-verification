# M13.2 — AST allowlist by idiom class (contract)

Tier: **kernel** — this IS the pass/fail boundary. Nothing downstream re-checks admission.

Law: `.claude/rules/pysrc.md`. Stdlib-only; input is the text `prescan` returned, never raw bytes.

## Design rule

Admission is a POSITIVE allowlist over idiom classes, never a denylist of bad constructs. A node,
call target, attribute chain or literal kind that is not named is refused, so a construct nobody
thought about fails closed. The subset is designed from IDIOM CLASS, never from memorised sample
outputs, and the held-out corpus stays unread until the config is frozen.

`plt.subplots` and every multi-panel form are refused BY CONSTRUCTION, not by a special case: the
projection targets exactly one chart, so a program producing more than one Axes has no projection.

## Admitted idiom classes (the closed subset, `pysrc-0.1`)

| class | admitted |
|---|---|
| module | `Module` whose body is a flat statement list; no `__future__`, no docstring requirement |
| import | exactly `import matplotlib.pyplot as plt` · `import numpy as np`; alias REQUIRED and fixed |
| assign | `Name = <expr>`, single target, no tuple/starred/augmented/annotated targets |
| expr-stmt | a bare admitted call only |
| call | closed target set (below); positional args + a closed keyword set; no `*args`/`**kwargs` |
| operators | `+ - * / ** ` binary, unary `-`, over admitted operands |
| literals | `int`, `float`, `str`, `bool`; `np.pi`, `np.e` |
| names | bound names only, plus the two import aliases |

Call targets, closed: `np.linspace` · `np.arange` · `np.sin` `np.cos` `np.tan` `np.exp` `np.log`
`np.sqrt` `np.abs` · `plt.plot` `plt.scatter` `plt.bar` · `plt.title` `plt.xlabel` `plt.ylabel`
`plt.legend` `plt.grid` · `plt.show`.

Refused, each needing its own witness: any other import · `plt.subplots` and multi-Axes forms ·
`for`/`while`/comprehensions · `def`/`class`/`lambda` · `try`/`with`/`assert`/`raise`/`del` ·
`global`/`nonlocal` · decorators · `async` · walrus · f-strings · attribute chains deeper than
`alias.attr` · subscripts · dict/set/tuple displays · dunder names · starred args · unknown
keywords · `import x from y` in any form.

## Check set (fixed before implementation)

| id | predicate | acceptance check |
|---|---|---|
| A1 | `ast.parse` failures become verdicts | a syntactically invalid but tokenizable program ⇒ `source_not_parsable`, no `SyntaxError` escapes |
| A2 | admission is positive | a node type absent from the allowlist refuses, proven with a construct the subset never names |
| A3 | the import set is exact | `import numpy` (no alias), `import numpy as onp`, `from numpy import sin` each refuse |
| A4 | call targets are a closed set | a NEAR-MISS of every admitted family refuses (`np.linspaces`, `plt.plott`, `np.random`) |
| A5 | `plt.subplots` refuses | and the refusal reason is the projection's single-chart bound, not a named ban |
| A6 | keywords are closed per target | an unknown keyword refuses; each admitted keyword passes |
| A7 | every name is bound before use | a free name refuses; the two aliases count as bound by their import |
| A8 | attribute depth is bounded | `np.random.rand` refuses on chain depth, not on the leaf name |
| A9 | dunder and private names refuse | `__class__`, `_x` as attribute or name |
| A10 | the admitted set round-trips the design corpus | every simple-arm design program admits; sampled complicated ones refuse |
| A11 | refusal codes are closed and carry no source bytes | as M13.1 P10, extended to the admission vocabulary |
| A12 | admission never evaluates | no `eval`/`exec`/`compile`/`getattr` in the module; committed search |

A10 is measured against the RE-AUTHORED math corpus (M13.5), so it lands as a skipped red until
that corpus exists; the contract records it now so the suite is not silently narrowed later.

## Boundary placement, ruled here so M13.4 inherits it

Admission answers "may these bytes run", never "do they draw a correct chart". Three consequences,
each a calibration lever rather than a safety property:

- `bool` is an admitted literal CLASS. `plt.grid(True)` is an ordinary matplotlib idiom, and the
  bool-vs-int hazard is a per-argument-slot question that only PROJECTION can ask. Admission keeps
  `bool` distinguishable by using exact types instead of `isinstance`.
- A module docstring refuses: a bare `str` statement plots nothing, and admitting it would carry a
  statement class the projection must then ignore.
- The empty program admits. Demanding a chart is projection's predicate, not admission's.

M13.6 measurement, not taste, is what may move any of these.
