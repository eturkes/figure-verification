# M13.5 — verdict + recomputation + certificate: the engine `Intent` already promises

Tier: **kernel**. Judgment-bearing: this unit is where "recomputes every plotted number" stops being
a sentence and becomes a mechanism, and where the certificate starts making claims a reader acts on.
Full adversarial battery — diff-blind red suite, independent oracle + differential, mutation credit.

Predecessors: M13.1 pre-scan, M13.2 admission, M13.3 formula projection, M13.4 dataset projection.
The core today is `prescan → admit → project` and STOPS. There is no public entry, no verdict, no
recomputed table and no certificate, so M10 has nothing to integrate.

## What this unit decides

1. The public entry and the verdict VALUE that M10 consumes.
2. The numeric contract for `sin cos tan exp log sqrt pow` — a RULING, not a port. `expr.py`'s
   exact-rational evaluator is the wrong tool here and is not ported (see § Declared rulings, N).
3. How the user's CSV bytes reach the verifier at all — no such path exists today.
4. The safe CSV profile: what the verifier parses with stdlib `csv` + `float`, and what it refuses
   because the sandbox's `pandas.read_csv` would parse it differently.
5. The plotted table — the static product of recomputation, and the thing the certificate binds.
6. The core certificate, including what it declares OPEN rather than claiming.
7. G7, G8, G9 — three integrity rules that become decidable for the first time because the table
   exists.
8. The work tariff and the resource ceilings that must exist before the verifier reads or evaluates
   anything.

## Surfaces

New, all stdlib-only, all under `src/verifier/pysrc/`:

- `verify.py` — the public entry, arm dispatch, verdict assembly.
- `numeric.py` — the binary64 evaluator over `spec.Expr`, plus the grid materializer.
- `csvread.py` — the safe CSV profile: strict parse, column selection, cell admission.
- `table.py` — `PlottedTable` + its canonical encoding.
- `certificate.py` — `CoreCertificate` + its plain-words interpretation.
- `budget.py` — the work meter, MOVED from `src/verifier/work.py` (see § Declared rulings, W1).

Edited: `spec.py` (targets, provenance), `errors.py` (11 codes), `limits.py` (7 fields), `__init__.py`
(public re-export).

**Named seams (contract-fixed, so the diff-blind suite and the implementation meet).** E1's "only
public entry" is about `verifier.pysrc.__all__`, not about module shape: every stage is an
underscore-free module-level function, which is what makes E3's call-counting bombs patchable and
what M13.1–M13.4 already do (`prescan`, `parse_admitted`, `project`). Fixed here:
`verify.bind_target` · `verify.recompute` · `verify.check_integrity` · `certificate.certify` ·
`numeric.evaluate_expr(expr: Expr, x: float, budget: WorkBudget) -> float` ·
`numeric.materialize_grid(grid: Grid, budget: WorkBudget) -> tuple[float, ...]` ·
`PlottedTable.canonical_bytes() -> bytes`. Nothing else internal is fixed — a predicate whose fault
shape is visible in the returned `Verdict` is exercised through `verify_python_source`, so the
decomposition below these seven stays free.

Tests: `tests/test_pysrc_verify.py` · `tests/test_pysrc_numeric.py` · `tests/test_pysrc_csv.py` ·
`tests/test_pysrc_certificate.py` · G7/G8/G9 into the existing `tests/test_pysrc_integrity.py`.
Mutants: `tools/mutants/verify.toml`, `tools/mutants/numeric.toml`, `tools/mutants/csvread.toml`.

### N — numeric profile and evaluation

| id | predicate | acceptance check |
|---|---|---|
| N1 | Evaluation is IEEE-754 binary64, operator by operator, in the projected tree's own shape: every node rounds to binary64 before its parent reads it. No exact-rational intermediate, no single final rounding. | Witness where exact-then-round and round-at-each-node differ; the evaluator must produce the round-at-each-node value, and it must equal numpy's on the same expression. |
| N2 | `Fraction` literals convert to binary64 exactly as the executed program's decimal literal does: `Num(Fraction(0.1))` evaluates to the float64 `0.1`, not to a rounded `1/10`. | `float(Fraction(0.1)) == 0.1` pinned with a hex-float literal, plus a non-binary decimal (`0.2`) per `assurance.md`. |
| N3 | The evaluator reproduces numpy's IEEE behaviour for every domain and overflow case instead of raising: `x/0` → `±inf`, `0/0` → `nan`, `log(0)` → `-inf`, `log(x<0)` → `nan`, `sqrt(x<0)` → `nan`, negative base with non-integral exponent → `nan`, `exp` overflow → `inf`. The stdlib exceptions (`ValueError`, `ZeroDivisionError`, `OverflowError`) are caught and mapped, never propagated. | Table-driven differential against numpy on every listed case, values compared by bit pattern. |
| N4 | Any non-finite value anywhere in the recomputed table refuses `value_not_finite`. This is the SOLE domain refusal: N3 makes every domain fault produce a non-finite, so no domain-classification logic exists to get wrong. | One witness per N3 row reaches `value_not_finite`; a mutant that special-cases any single domain fault into its own code survives nothing. |
| N5 | `Const("pi")` and `Const("e")` evaluate to `math.pi` and `math.e`, pinned as hex-float literals and asserted bit-equal to `numpy.pi` / `numpy.e`. | Hex-float literal comparison, both directions. |
| N6 | Grid materialization reproduces `np.linspace` and `np.arange` bit-for-bit over the admitted subset. `Grid.stop` is inclusive; `arange` bounds are integers only (M13.3 law). | Differential against numpy over the M13.3 grid corpus, compared on bit patterns, zero disagreements required. |
| N7 | The numeric profile is NAMED (`binary64-libm-v1`), published in the certificate, and splits every admitted operator into two classes: **standard-exact** (`add sub mul div`, unary minus, `abs`, `sqrt`, literal conversion, `pi`, `e`, and both grid constructors) where agreement is guaranteed by IEEE-754 and measured at 0 ulp; and **libm-dependent** (`sin cos tan exp log`, `pow`) where agreement is a MEASURED band on a named environment pair, not a proof. | The class table is a literal in the test, not read from production; the certificate string is byte-pinned. |
| N8 | The published band for the libm-dependent class is 1 ulp, backed by the recorded measurement, and `pow` carries its own measurement rather than inheriting the band by assumption. | `pow` measured host-vs-Pyodide on ≥1,000,000 stratified inputs before the band is published; result recorded in § Verdicts. |

## The C10 ruling — RESTRICT, and the profile is measured

Decided by the rule fixed BEFORE the data ("prefer RESTRICT if a 0-disagreement region covers
non-exponent texts with ≤15 significant digits and ≤6 decimal places"). `spike-m13u5b` found exactly
that region and measured it at **0/4,000,000** bit mismatches against target Pyodide — 1,000,000
fixed decimals and 1,000,000 signed-32-bit integers, each in plain and fully quoted form. The band
is unnecessary inside the region and reimplementing pandas' `xstrtod` is unnecessary unless a later
corpus proves the restriction misses real data.

What forced the restriction: stdlib `float` and the sandbox's DEFAULT `pandas.read_csv` disagree on
326,834 of 1,000,000 adversarial cells (314,781 at 1 ulp, 12,053 at 2–7,262 ulp); only
`float_precision="round_trip"` agrees fully; and no significant-digit cap alone repairs it, since
even `1e-23` disagrees.

**The admitted profile, six clauses. `csvread.py` implements exactly this.**

1. **Bytes and dialect.** Strict UTF-8. Refuse an initial BOM and any NUL. Comma delimiter, `"`
   quote, doubled `""`, `escapechar=None`, `comment=None`; backslash is ordinary text. LF or CRLF
   records, and correctly quoted embedded LF/CRLF. `csv.reader(strict=True)` must consume the bytes
   with no post-quote junk.
2. **Shape and header.** Exactly one header record and ≥1 data record. Every header cell nonempty
   and unique. Every data record exactly the header's width. Selected headers matched by exact
   decoded text.
3. **Selected-column kinds.** `y` numeric for every mark. `x` numeric for `line` and `scatter`. For
   `bar`, `x` is wholly numeric or wholly categorical — a mixed column refuses. A categorical cell
   is nonempty, outside the NA set, fails `float(text)`, and case-folds outside `{true, false}`
   (otherwise pandas infers `bool`, not `object`). Categorical `x` values unique.
4. **Numeric cells.** The whole decoded token matches ASCII `-?(?:0|[1-9][0-9]*)(?:\.[0-9]{1,6})?`;
   ≤15 significant digits counting explicit trailing zeros; value in `[-2147483648, 2147483647]`,
   finite, and NOT a sign-bearing zero. All-integral tokens make pandas infer `int64`; any token
   with a point makes it `float64`.
5. **NA and row semantics.** Refuse an empty selected cell and each of the 19 measured pandas NA
   spellings, quoted or plain: `''` `#N/A` `#N/A N/A` `#NA` `-1.#IND` `-1.#QNAN` `-NaN` `-nan`
   `1.#IND` `1.#QNAN` `<NA>` `N/A` `NA` `NULL` `NaN` `None` `n/a` `nan` `null`. Preserve file order;
   never sort.
6. **Renderer closure — the clause that is not about parsing.** The int32 range excludes Pyodide
   `plt.bar`'s signed-32-bit overflow, which RAISES rather than mis-draws; the negative-zero refusal
   excludes matplotlib bar's only measured bit change (99/1,024 heights: every `-0x0.0p+0` becomes
   `+0x0.0p+0`). Line and scatter preserved every tested bit (0/40,000 each). A categorical bar maps
   unique labels to float64 centers in FIRST-OCCURRENCE order, which is why duplicate categories
   overplot and G8 refuses them.

The refusal set is the exact complement, and every member lands on `value_not_in_profile`,
`csv_not_parsable`, `column_not_numeric`, `column_not_present` or `category_not_unique` — no new
code. Unselected cells stay unrestricted once the structural byte checks pass.

Two consequences to record rather than hide. The int32 range is a SUFFICIENT condition measured as
one profile, not a necessary one: a float column is `float64` and is not bound by matplotlib's
integer-bar path, so the float branch could widen on its own measurement — deferred, not assumed.
And the profile was measured on Pyodide 0.28.1 / pandas 2.3.1 / NumPy 2.2.5, while
`.claude/rules/owui.md` records the demo's sandbox as Pyodide `0.28.0.dev0` with pandas 2.3.1;
released 0.28.0 bundles pandas 2.3.0. M10 must reconcile that identification against the live
sandbox before the profile's measurement is claimed of it.

## Declared rulings

- **N.** `expr.py` is NOT ported, in whole or in part. Its evaluator is exact over `Fraction`; the
  executed program is numpy float64 and rounds at every operator. An exact engine that rounds once
  at the end would compute a number the program never computes, so the "more precise" engine is the
  LESS faithful one. This supersedes `pysrc.md` § Layering item 4's framing of the port as partial.
- **Formula-arm claim (user).** Without a `FormulaTarget` the formula arm establishes internal
  consistency — the plotted numbers are what the submitted program's own expression computes — and
  publishes the intent gap in plain words, printing the expression back so a human checks it against
  their own request. Tier-1 provenance is claimed for the dataset arm and for a targeted formula arm
  ONLY. A model-produced reading of the request may never become the target (`pysrc.md` § Deployment).
- **G7/G8 (user).** Both close BY CONSTRUCTION here rather than remaining declared-open as m13u4
  ruled, because recomputation plus C9's NA refusal makes them true and each is pinned against
  allowlist widening. The LIVE G-table in `pysrc.md` moves in this unit's commit; the archived m13u4
  contract stays as the record of what m13u4 decided with the mechanism it had.
- **G9 (user).** Uniform spacing is dropped from G9's predicate with its reason recorded; ordering
  survives. `pysrc.md`'s G-table row is rewritten in this unit's commit.
- **W1.** Moving the meter into the core rather than copying it is what keeps the single-source
  ruling true: a copied meter is a hand fork, which `Decisions` bans for the paste-in.
- **Refusal-code economy.** `target_mismatch` is ONE code across both arms — the fault shape is
  "the submitted program is not about the artifact the user supplied", and the arm is evident from
  the program. `value_not_finite` is likewise one code for every domain and overflow fault, because
  N3 makes them all produce a non-finite value.
- **Structural note.** The model supplies a program, never values, so no CLAIMED number exists to
  contradict statically. Recomputation's static product is the TABLE. `Intent`'s "code, recomputed
  table, emitted artifact and certificate mutually consistent" closes against the emitted artifact
  only through fork (b), which M10 owns. K4 states that split rather than letting the verdict imply
  it.
