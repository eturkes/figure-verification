# M18.3 — the python-mode reference: what the verifier checks, in full

Tier **docs** (consistency pass) + one deterministic drift check: the reference is human-facing, every sentence restates shipped law, and the drift check is what re-derives it for free whenever the allowlist, the reasons or the limits move.

## Rulings (user, this request)

- **D1.** A new human-facing reference of python mode (`pysrc-0.1`) = the "complete documentation" each "Show checks" row links: `docs/verification.md` (EN, ASD-STE100) + `docs/verification.ja.md` (natural polite Japanese, the admin guide's terms `検証器`/`ブラウザ`/`受け入れる`). `VPlot_SEMANTICS.md` stays the JSON-spec modes' agent-register contract and is not linked from the embed.
- **D2.** Each check's section opens with `<a id="check-<id>"></a>` (language-independent fragment; GitHub keeps it as `user-content-check-<id>` and scrolls to `#check-<id>`, measured in a sandboxed popup, Chromium 151).

## Content (both languages, same order + same facts)

1. What the verifier does + what it never claims (tier 1-3, intent not checked; renderer, browser, Pyodide + pixels trusted) — restates `POC_SCOPE.md` / `.claude/rules/pysrc.md` / `.claude/rules/claims.md`.
2. How to read "Show checks" (row states, the code listing, the marked span, the link).
3. One section per check, `CHECKS` order: anchor, heading = the `TEXTS` title, what it checks (the `EXPLAIN` text, expanded), the rules it enforces, a table of every reason `CHECK_OF` maps to it: `` `code` `` + its `REASONS` sentence (the outlet causes included).
4. Accepted Python: imports + fixed aliases; statements; call targets by group + each target's keywords; attributes; operators; literal types; the `groupby` chain + reductions; the plotting accessor + kinds; `reset_index`; formula functions + constants.
5. Chart reading rules (one source, one mark, literal labels, `plt.figure` before drawing, `plt.show()` last, names bound once + every binding used).
6. Data rules: the CSV profile (cell forms, NA spellings, int32 + 15-digit bounds, unique categories), formula request grammar (`pyexpr-0.1`: carriers, interval forms, `n =`), request anchoring (strict = production, substitution = demo, aliases, Japanese short words).
7. Integrity rules G1-G11 in plain words.
8. Rendering + match: the sandbox run, the observation, exact equality (file) + bounded (formula).
9. Limits: every `DEFAULT_LIMITS` field with its value.

## Predicates

- **D3 — anchors.** Each doc holds exactly 11 `<a id="check-<id>"></a>` in `CHECKS` order, each followed by a heading whose text holds that check's `TEXTS` title (EN doc: EN title; JA doc: JA title). Accept: drift test.
- **D4 — reasons.** Every `Reason` (55 `RefusalCode` + 14 `OutletCause`) appears as `` `code` `` exactly inside its `CHECK_OF` check's section (between its anchor and the next), in both docs. Accept: drift test.
- **D5 — allowlist.** Every `ADMITTED_IMPORTS` module + alias, `ADMITTED_CALL_TARGETS` entry, keyword in `ADMITTED_KEYWORDS`, `ADMITTED_CONSTANT_ATTRS`, `ADMITTED_VALUE_ATTRS`, `ADMITTED_ACCESSOR_KINDS` key, `ADMITTED_UNWRAPPED_ATTRS`, reduction name appears in backticks in both docs. Accept: drift test (red when one target is added to `admit.py` without the docs).
- **D6 — limits.** Every `DEFAULT_LIMITS` field name appears in backticks with its value (digits, `_` or `,` grouping allowed) in both docs. Accept: drift test.
- **D7 — links.** Every relative link resolves to a tracked file; one H1 each; Marksman-clean (no `][` outside code, no bare `<nonterminal>`). Accept: drift test + LSP diagnostics.
- **D8a — coverage (consultant-1 D7).** A token inventory cannot prove an explanation, so each content item 1-9 above is one review row: present in both docs, its facts restating the cited law (CSV profile + NULL refusal, grouping/accessor/`reset_index` shapes, formula grammar, formula bounds vs file exactness, strict vs demo anchoring + aliases + short words, G1-G11 incl. by-construction status, limits, intent gap, trusted renderer/pixels). The reference says it describes the current release on `main`. Accept: closing reviewer table, one row per item.
- **D8 — truth + register.** Every sentence matches shipped behaviour; no sentence claims more than the code enforces (`match` = bounded for formulas, `binding` per anchoring rule, G10 lexical, intent never verified); EN ASD-STE100, JA natural polite; parity of facts between the two. Accept: closing reviewer under a fixed register + claim lens.
- **D9 — reachability.** Root `README.md` + both admin guides link the reference. Accept: drift test.
