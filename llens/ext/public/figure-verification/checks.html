How the verifier works

Each check shows a one-line summary; the tables below list every rule. Dashed boxes: what the language model writes. Red dashed arrows: where a failed check stops the chart.

  1. Load. nucllei loads the figure-verification skill through load_skill, or automatically for a CSV attachment. The skill makes draw_figure available to the model.
  2. Call. The model sends one complete Python program to draw_figure. The tool reads your own messages and files from the stored chat branch. It checks the caller before any run.
  3. Run and read. The tool first writes each attached file to /workspace/imports/ with the sandbox's file write, which follows no links. Then it sends one /exec request to your code sandbox, with the trusted figure reader and the program, unchanged. The reader hooks matplotlib, runs the program and draws each figure once. It reports every artist as JSON: class, plotting call, transform, coordinates, axes, ticks, colors, sizes, visibility and the recorded inputs of hist, pie, fill_between and stackplot. It also returns one PNG. There is no separate receipt or browser code runtime.
  4. Judge. On the nucllei server, standard-library Python applies the rules below to that description, in order. The first failure stops the chart. The judge compares drawn values with your files and request. No model and no guesswork take part.
  5. Display. On a pass, the tool saves the PNG as your file and shows it with the verdict, interpretation and any model note. On a failure, it shows the verdict and cause, without an image or a note. These appear outside the collapsed tool block. The check list appears inside that block and also reaches the model. If the display fails, read the cause in the tool result.

Not checked: whether the chart answers your question; text on the chart (text, annotate, bar_label), which the reply lists; the model's note or its reply text; the program itself. The program must be non-adversarial: it runs before the checks, in the reader's interpreter, and can read your attached files. The verifier trusts the sandbox, interpreter, matplotlib, fonts, browser and pixels. The sandbox has no network. Other tools, such as run_python and fetch_from_workspace, can show a chart outside this skill and its checks.

4. Only chart parts the verifier checks

The reader records each artist's class and the plotting call that made it (the outermost matplotlib.axes frame on the stack at the artist's creation). Each pair must be in this closed set: lines (plot, step), points (scatter), bars (bar, barh, grouped, stacked), histograms (hist, filled, one data set), pies (pie), areas (fill_between, stackplot), reference lines and bands (axhline, axvline, axhspan, axvspan), text (titles, axis labels, legends, tick labels, text, annotate, bar_label), a colorbar for scatter colors.

Rule How Code
no image (imshow, pcolormesh, matshow) no AxesImage, QuadMesh or FigureImage in the artist tree raster_image

no twin axes (twinx, twiny) no two axes share an x or y axis at the same position axes_twin
no overlapping panels the axes positions do not overlap axes_overlap

7. Drawn values come from your data

A series = one line, scatter collection, bar container, pie, area band, reference mark or histogram input. For each series, the judge searches this closed list for one CSV explanation whose values equal the points exactly (the same 64-bit float), each CSV row backing one point at most. Each point that it leaves must be a typed number.

  • CSV file: a column's values, or one sum, mean, min, max or count per group, computed as pandas computes it, bit for bit. A subset of rows passes, and the reply states it, for example 2 of 6 drawn.
  • Request: typed numbers after NFKC, ranges expanded (1 to 10, 1 through 10, 1–10, 1〜10, 1から10まで; never 1-10; at most 10,000 numbers), and typed category labels.
  • One computation of these: square, running total, change, share or percent of one series; ratio, difference, product or sum of two CSV columns, per row or per group.
  • Reference lines and bands: also 0, or one summary of a whole column.
  • A legend label equal to a cell value: the series comes from the rows that hold that value.
  • Scatter colors and sizes that a key shows: drawn values, from their point's row or group.
  • No file and no numbers: integrity alone; the reply says so.
Rule How Code
CSV at most 8 MB, 100,000 rows, 128 columns, 512 bytes per cell the tool reads the user's own files from the stored chat branch and checks each file's owner before reading its bytes; the judge checks the caps csv_too_large
CSV readable a reader restricted to what pandas.read_csv reads the same way csv_not_parsable
matching within the work limit the judge counts work units, 5,000,000 at most (MAX_WORK) work_budget_exceeded
each category once per series (a scatter series may repeat one) no two points of one series other than a scatter share a text key category_not_unique
every drawn value found in a source the search above finds an explanation for every point value_not_found
every typed category label in the request the label occurs in the request after NFKC and case folding label_not_in_request

8. Drawn columns match your request

CSV figures only. The drawn columns are the columns of the explanations that check 7 found. The judge matches the request against the file's header after NFKC and case folding: whole words (Japanese names: containment), one typing error in a one-word name of 5 or more characters, the aliases that your administrator declares and, in production, Japanese short forms (月 for 年月, also 月別).

Rule How Code
no column that the request names replaced by another no named column undrawn while a drawn column is unnamed column_not_requested
values that fit two columns: the request names one of them two explanations with different columns: the request names the columns of exactly one column_not_requested
production: if the request names or excludes a column, it names every drawn column each drawn column is among the named columns column_not_named
titles, axis labels, legends and colorbar labels: no undrawn column; over a total or mean per group, no other summary the same matcher reads each label against the header and the summary words; the column whose cell values name the legend's series counts as drawn label_not_consistent
