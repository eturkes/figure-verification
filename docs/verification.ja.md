# 図の検証：検証器がチェックする内容

このリファレンスは、Open WebUI で図の検証器が実行するチェックを説明します。`main` ブランチの現在のリリースが
対象です。グラフの返信の下にある **チェック項目を表示** の各行は、ここの該当する節にリンクしています。英語版は
[verification.md](verification.md) を参照してください。

## 検証済みの図の意味

言語モデルは、グラフを 1 つ描く短い Python プログラムを書きます。モデルが描画する数値を渡すことはありません。
検証器はプログラムを調べ、あなたが用意したデータから描画するすべての値を計算し直し、すべてのチェックに合格した
場合だけグラフを表示します。それ以外の場合、返信には `Figure verification failed, no image produced` が
表示されます。

検証器は次の 3 種類の保証をします。

1. **出所。** 描画するすべての値を、検証器が独自のコードで、あなたの CSV ファイルまたは依頼文の数式から
   計算し直します。
2. **完全性。** グラフは決まった描画規則に従います。たとえば、棒はゼロから始まり、行の欠落はありません。
3. **解釈。** 合格した返信は、検証した内容を平易な言葉で示します。グラフの種類、列、グループ化、行数です。

検証器は、グラフが質問に答えているとは主張しません。正しい数値でも、意図と違う量を示す場合があります。たとえば、
平均がほしいときの合計です。何を検証したかは、グラフの下の説明を読んで確認してください。

次の部分は信頼しており、検証はしません。ブラウザ、Python を実行する Open WebUI のサンドボックス（Pyodide）、
その中のグラフ描画ライブラリ、画像のピクセルです。

## 「チェック項目を表示」の読み方

**チェック項目を表示** は、11 個のチェックを実行順に並べます。各行の状態は次の 3 つのどれかです。

- ✓ **合格**：チェックが完了しました。
- ✗ **不合格**：このチェックが図を止めました。行に理由が表示されます。
- – **未実施**：前のチェックが不合格だったため、このチェックは実行していません。

行をクリックすると開きます。開いた行には、チェックの内容、チェックが読んだプログラムの行、不合格の理由、この
リファレンスへのリンクが表示されます。検証器が問題の正確な位置を特定できた場合は、その部分のコードに印が付きます。
ファイル、依頼文、または上限による問題は、プログラム内に位置がありません。そのため、関係する行を印なしで表示します。

表示されるのは、モデルが送ったプログラムそのものです。プログラムに含まれる文字列、たとえばファイル名や依頼文から
写した語もそのまま表示されます。制御文字などの見えない文字は、見える記号で表示されます。

## チェック

<a id="check-program"></a>

### 1. モデルからグラフのプログラムを受信

モデルはグラフ用のツールを呼び出し、Python プログラムを 1 つ送る必要があります。返信の本文に書いたプログラムは
グラフになりません。図を作れるのは、ツールで送られたプログラムだけです。1 つの返信でモデルがツールを複数回呼び出した
場合、検証器は最後のプログラムをチェックします。

| 理由 | 意味 |
|---|---|
| `no_tool_call` | モデルからグラフのプログラムが届きませんでした。 |

<a id="check-data"></a>

### 2. 添付ファイルまたは依頼文の数式

検証器には、あなたが用意したデータが必要です。次のどちらかを読み取ります。

- チャットに添付した CSV ファイル
- 依頼文に書いた 1 つの数式と 1 つの区間（[依頼文の数式](#formulas-in-a-request) を参照）

| 理由 | 意味 |
|---|---|
| `no_user` | サインインしているユーザーがいません。 |
| `no_target` | 検証器が読み取れる CSV ファイルも、依頼文の数式もありません。 |

<a id="check-readable"></a>

### 3. Python として読み取り可能

検証器は、内容を調べる前にプログラムをテキストとして読み取ります。プログラムは正しい UTF-8 で、NUL 文字を含まず、
[上限](#limits) のサイズ以内である必要があります。その後、プログラムを Python のトークンに分け、括弧とインデントを
確認し、構文を解析します。

| 理由 | 意味 |
|---|---|
| `source_too_large` | プログラムが長すぎます。 |
| `source_not_utf8` | プログラムが正しい UTF-8 テキストではありません。 |
| `source_has_nul` | プログラムに NUL 文字が含まれています。 |
| `line_too_long` | プログラムに長すぎる行があります。 |
| `source_not_tokenizable` | プログラムを Python のトークンとして読み取れません。 |
| `too_many_tokens` | プログラムのトークンが多すぎます。 |
| `nesting_too_deep` | プログラムの括弧の入れ子が深すぎます。 |
| `unbalanced_brackets` | プログラムの括弧の対応が取れていません。 |
| `indent_too_deep` | プログラムのインデントが深すぎます。 |
| `source_not_parsable` | プログラムが正しい Python ではありません。 |

<a id="check-accepted"></a>

### 4. 検証器が受け入れる Python のみ使用

検証器が受け入れる Python の範囲は決まっています。その範囲の外にあるものは、Python で実行できる場合でもチェックを
止めます。範囲を小さくしているのは、受け入れるすべての構文がグラフに与える効果を把握するためです。

**import。** 次の 3 つだけで、別名は固定です。

- `import matplotlib.pyplot as plt`
- `import numpy as np`
- `import pandas as pd`

**文。** 検証器が受け入れるのは、import、1 つの名前への代入（`name = ...`）、文としての関数呼び出しです。ループ、
条件分岐、関数定義、`with`、`try`、`from ... import`、累算代入（`+=`）は受け入れません。名前は使う前に代入する
必要があります。`_` で始まる名前は受け入れません。

**関数呼び出しと引数。** 各呼び出しで受け入れるキーワード引数は、表のものだけです。

| 呼び出し | 受け入れるキーワード引数 |
|---|---|
| `pd.read_csv` | なし |
| `np.linspace` | `num` |
| `np.arange` | なし |
| `np.sin`、`np.cos`、`np.tan`、`np.exp`、`np.log`、`np.sqrt`、`np.abs` | なし |
| `plt.plot` | `label`、`color`、`marker`、`linestyle` |
| `plt.scatter` | `label`、`color`、`marker` |
| `plt.bar`、`plt.barh` | `label`、`color` |
| `plt.title`、`plt.xlabel`、`plt.ylabel`、`plt.legend`、`plt.grid` | なし |
| `plt.figure` | `figsize`（2 つの数値の組） |
| `plt.tight_layout` | なし |
| `plt.xticks` | `rotation` |
| `plt.show` | なし |

`plt.figure`、`plt.tight_layout`、`plt.xticks` は位置引数を受け入れません。

**グループ化。** CSV ファイルの行をグループに分け、グループごとに 1 つの列を集計するチェーンが 1 つあります。

```python
totals = df.groupby("region")["revenue"].sum()
```

集計は `sum`、`mean`、`min`、`max` のどれかで、引数は取りません。グループのキーと列は、それぞれ引用符で囲んだ
固定の名前 1 つで書きます。グラフは `totals.index`（グループ）を x、`totals.values` を y として描くか、系列が
`.plot(kind=...)` で自分自身を描きます。

チェーンの最後に `.reset_index()` を付けることもできます。この呼び出しは系列を 2 列の表に戻すため、グラフは
両方の列を名前で選ぶ必要があります。

```python
table = df.groupby("region")["revenue"].sum().reset_index()
plt.bar(table["region"], table["revenue"])
```

このような表の `index` は行の番号なので、グラフには使えません。また、この表は `.plot` で自分自身を描けません。

**pandas による描画。** 集計した系列は `.plot(kind=...)` で自分自身を描けます。`kind` は `bar`、`barh`、`line`
のどれかです。この呼び出しは位置引数を取らず、受け入れるキーワードは `kind` と `color` だけです。

**値。** 検証器が受け入れるのは、数値のリテラル、文字列のリテラル、`True`、`False`、`np.pi`、`np.e` です。
代入した名前の `index` と `values` 属性、固定の名前 1 つで選んだ列（`df["revenue"]`）も受け入れます。

**演算子。** 検証器が受け入れるのは、`+`、`-`、`*`、`/`、`**` と先頭のマイナス記号です。比較、リスト、辞書、
内包表記、f 文字列、`lambda` は受け入れません。タプルも、`figsize` の組を除いて受け入れません。

| 理由 | 意味 |
|---|---|
| `statement_not_admitted` | 検証器が受け入れない文が使われています。 |
| `expression_not_admitted` | 検証器が受け入れない式が使われています。 |
| `import_not_admitted` | 検証器が受け入れない import 文があります。 |
| `assign_target_not_admitted` | 検証器が受け入れない代入先が使われています。 |
| `call_target_not_admitted` | 検証器が受け入れない関数が呼び出されています。 |
| `keyword_not_admitted` | 検証器が受け入れない引数を渡す呼び出しがあります。 |
| `attribute_not_admitted` | 検証器が受け入れない属性が使われています。 |
| `operator_not_admitted` | 検証器が受け入れない演算子が使われています。 |
| `literal_not_admitted` | 検証器が受け入れないリテラル値が使われています。 |
| `name_not_bound` | 定義されていない名前が使われています。 |
| `column_not_literal` | 列の選択またはグループ化が、固定の列名 1 つで書かれていません。 |

<a id="check-chart"></a>

### 5. プログラムからグラフを読み取り可能

検証器は、プログラムが描くグラフを読み取ります。すべての文がそのグラフに関係する必要があります。効果を特定できない
文があると、チェックは止まります。

**CSV ファイル** のグラフの形は次のとおりです。

1. 固定のファイル名 1 つを使う `df = pd.read_csv("/mnt/uploads/<ファイル名>")` が 1 つ。
2. x と y の描画呼び出しが 1 つ。x と y はそのファイルの列（`df["region"]` またはそれを代入した名前）です。
   グループ化の `index` と `values`、またはリセットしたグループ化の名前付きの 2 列も使えます。グループ化は
   `.plot(kind=...)` で自分自身を描くこともできます。

**数式** のグラフの形は次のとおりです。

1. `np.linspace(start, stop, count)` または `np.arange(start, stop, step)` による x の値のグリッドが 1 つ。
   `np.linspace` の点の数は数値で書いた整数で、省略すると 50 点です。`np.arange` の start、stop、step は、
   それぞれ ±2\*\*52 以内の整数で、数値または数値どうしの簡単な計算で書きます。step は 0 ではなく、start から
   stop の方向を向く必要があり、グリッドは `stop` の手前で終わります。グリッドの点の数は 2 以上 100,000 以下です。
2. 受け入れる関数と演算子でそのグリッドから計算する y の式が 1 つ。
3. `plt.plot(x, y)` または `plt.scatter(x, y)` が 1 つ。数式のグラフを棒グラフにはできません。

pandas を import したプログラムは、数式のグリッドを使えません。どちらの形でも、次の規則があります。

- 直接の描画呼び出し（`plt.plot`、`plt.scatter`、`plt.bar`、`plt.barh`）は、x と y の 2 つの位置引数だけを
  受け取ります。プログラムが描く系列は 1 つです。
- `plt.title`、`plt.xlabel`、`plt.ylabel` はそれぞれ文字列のリテラルを 1 つ受け取り、呼び出しは各 1 回までです。
  `plt.legend()` と `plt.grid()` も各 1 回までです。
- `plt.figure(figsize=(width, height))` は、何かを描く前に呼び出す必要があります。
- 各名前への代入は 1 回だけで、代入したすべての名前を使う必要があります。
- `plt.show()` が最後の文です。

| 理由 | 意味 |
|---|---|
| `no_mark` | グラフとして読み取れる描画の呼び出しがありません。 |
| `multiple_marks` | プログラムが複数の系列を描いています。 |
| `mark_arity_not_projected` | 描画の呼び出しの引数が x と y の 2 つではありません。 |
| `mark_not_valid_for_arm` | 数式のグラフではこの種類のグラフを使えません。 |
| `x_not_a_grid` | 描画の呼び出しが x を np.linspace または np.arange から直接受け取っていません。 |
| `y_not_over_grid` | y の値が x のグリッドから計算されていません。 |
| `grid_not_representable` | x のグリッドの範囲または点の数を使えません。 |
| `expression_not_projected` | 式が何を計算するかを特定できません。 |
| `label_not_literal` | ラベル、タイトル、またはスタイルの呼び出しの形式を、検証器が受け入れません。 |
| `name_rebound` | 同じ名前に 2 回代入しています。 |
| `no_terminal` | プログラムが plt.show() を呼び出していません。 |
| `statement_after_terminal` | plt.show() の後に文があります。 |
| `statement_not_projected` | 文が何を描くかを特定できません。 |
| `arm_ambiguous` | プログラムが pandas をインポートし、数式のグリッドも使っています。 |
| `no_source` | プログラムが CSV ファイルを読み込んでいません。 |
| `multiple_sources` | プログラムが pd.read_csv を 2 回以上呼び出しています。 |
| `source_not_literal` | pd.read_csv の呼び出しが、固定のファイル名 1 つだけを受け取っていません。 |
| `column_not_from_source` | 描画する列が CSV ファイルから取られていません。 |
| `aggregation_not_projected` | グループ集計が何を計算するかを特定できません。 |
| `figure_orphans_mark` | 描画の後に plt.figure() が呼び出されています。 |

<a id="check-binding"></a>

### 6. プログラムが添付ファイルまたは依頼の数式と一致

検証器は、プログラムがあなたのデータを使うことを確認します。

**CSV ファイル。** `pd.read_csv` のファイル名は、添付したファイルのパス `/mnt/uploads/<ファイル名>` である必要が
あります。複数のファイルを添付した場合、検証器は 1 つずつ試します。

**依頼文の列名。** 検証器は、依頼文に書かれた列名と、グラフが描く列を比べます。規則は 2 つあります。

- **厳格な規則（本番用）。** 依頼文がファイルの列を 1 つ以上挙げるか除外する場合に適用します。描く列のうち
  依頼文で名前を指定できる列（下の名前の長さを参照）は、すべて依頼文で挙げる必要があります。そうでない場合、
  チェックは `column_not_named` で不合格になります。
- **置き換えの規則（デモ用）。** 依頼文がグラフの描かない列を挙げ、かつグラフが依頼文にない列を描く場合、チェックは
  不合格になります。

列を挙げない依頼文では、どの列を描くかはプログラムに任されます。比較するのは語であり、意味ではありません。

- 大文字と小文字、全角と半角の違いは区別しません。列名の下線は空白として読むため、`unit_price` は `unit price`
  の 2 語です。
- ASCII 文字だけの列名は、依頼文がその語を順に含む場合に指定されます。このような名前には 3 文字以上が必要です。
  日本語や `é` など ASCII 以外の文字を含む列名には 2 文字以上が必要で、依頼文がその名前を含む必要があります。
- 1 語で 5 文字以上の名前は、1 文字の変更、追加、削除がある語にも一致します。
- 2 つの列の名前に当てはまる依頼文の語は、同点として扱います。どちらの規則でも、同点のチェックは
  `column_not_requested` で不合格になります。
- `not`、`without`、`except`、`instead of` などの語の後、または `ではなく`、`以外` の前にある列名は、除外として
  読みます。
- 厳格な規則でだけ、日本語の短い語が短い日本語の列名を指定できます。その語は漢字の連なり全体で、検証器は
  `別` などのグループ化の接尾語を 1 つ取り除きます。残りが、2～4 文字の列名から最初または最後の 1 文字を除いた
  ものと同じである必要があります。たとえば `月ごと` と `月別` は `年月` を指します。2 つの列に当てはまる連なりは
  どちらも指さず、連なりの中に日本語の列名そのものがある場合はそちらを優先します。
- 管理者はツールの設定で、列の別名（column aliases）を宣言できます。宣言した別名は、その列の名前として扱います。
  2 つの列が共有する別名は同点です。

<a id="formulas-in-a-request"></a>

**依頼文の数式。** 検証器は最初に依頼文を正規化します（Unicode NFKC）。そのため、全角の文字は ASCII として
読みます。依頼文に数式が 1 つと区間が 1 つだけある場合、それが数式の対象になります。

- 数式：`y = <式>` または `f(x) = <式>`
- 区間：`x ∈ [a, b]`、`x in [a, b]`、`from a to b`、または `aからbまで`
- 任意の点の数：`n = <数>`

式に使えるのは、数値、`x`、`+ - * /`、括弧、`sin cos tan exp log sqrt abs`、`pi`、`e` です。べき乗 `**` の
指数は、`x**2` や `x**-1` のように数値で書いた整数です。プログラムの y の式は同じ式であり、グリッドの始点と終点は
区間の両端と同じである必要があります。依頼文に `n` がある場合、グリッドの点の数はその数と同じである必要が
あります。数式がない依頼文、または数式や区間が 2 つある依頼文は、対象になりません。

| 理由 | 意味 |
|---|---|
| `source_not_supplied` | プログラムは CSV ファイルを読み込みますが、添付がありません。 |
| `target_mismatch` | プログラムが添付ファイルにも依頼の数式にも一致しません。 |
| `column_not_requested` | グラフが依頼の列を別の列に置き換えたか、依頼の語が 2 つの列に当てはまります。 |
| `column_not_named` | 描いた列の名前が依頼にありません。列名はファイルのとおりに書いてください。 |

<a id="check-recompute"></a>

### 7. 描画する値をデータから再計算

検証器は、描画するすべての値を、ファイルまたは数式から独自のコードで計算し直します。

**CSV ファイル。** 検証器が読み取るのは、ブラウザの pandas とまったく同じ結果になるファイルだけです。

- バイト順マークと NUL 文字のない UTF-8 テキストで、区切りはコンマです。ヘッダー行が 1 行あり、列名は重複せず
  空でもありません。各行のセルの数は同じです。セルは二重引用符で囲めます。行の終わりは `\n` または `\r\n` です。
- 検証器は、描画する 2 列のセルを 1 つずつ確認します。その他の列は、ファイルの上限の計算にだけ含まれます。
- 数値のセルは、`-12.5` のような通常の小数で書きます。小数点以下は 6 桁まで、有効数字は 15 桁までで、
  プラス記号、指数、先頭のゼロは使えません。`-0` や `-0.0` などの負のゼロは拒否します。
- 小数点のあるセルが 1 つもない列は整数の列で、値は -2147483648 から 2147483647 までです。小数点のあるセルが
  1 つでもある列は小数の列で、15 桁の上限が値を制限します。
- 描画する列では、空のセルと、pandas が欠損値として読むすべての表記を拒否します。そのため、行が気づかれずに
  抜けることはありません。表記は `#N/A`、`#N/A N/A`、`#NA`、`-1.#IND`、`-1.#QNAN`、`-NaN`、`-nan`、
  `1.#IND`、`1.#QNAN`、`<NA>`、`N/A`、`NA`、`NULL`、`NaN`、`None`、`n/a`、`nan`、`null` です。大文字と小文字に
  関係なく `true` と `false` も拒否します。
- y の列は数値である必要があります。x の列は数値、または棒グラフと折れ線グラフではテキストのカテゴリです。
- グループ化は、pandas と同じくファイルの順に各グループを集計します。グループの並びも pandas と同じで、数値は
  値の順、テキストは Unicode のコードポイントの順です。
- グループ化の棒グラフは、ブラウザが正確に描ける範囲に収まる必要があります。整数の合計、最小値、最大値は
  -2147483648 から 2147483647 まで、それ以外の結果は ±2\*\*53 以内です。

**数式。** 検証器は、グリッドの各点で式を 64 ビット浮動小数点数で評価します。numpy と同じく、1 つの演算ごとに
丸めます。

すべての結果は有限の数である必要があり、計算量は [上限](#limits) 以内である必要があります。

| 理由 | 意味 |
|---|---|
| `csv_too_large` | CSV ファイルが大きすぎます。 |
| `csv_not_parsable` | CSV ファイルを読み取れません。 |
| `column_not_present` | プログラムが使う列が CSV ファイルにありません。 |
| `column_not_numeric` | 描画する列に数値でない値があります。 |
| `value_not_in_profile` | CSV の値またはグループの値の形式や大きさを、検証器が受け入れません。 |
| `value_not_finite` | 計算した値に有限でない値があります。 |
| `work_budget_exceeded` | グラフに必要な計算量が上限を超えています。 |

<a id="check-integrity"></a>

### 8. グラフの完全性

検証器は、グラフがデータを誤って伝えないようにします。最初の 8 つの規則は、受け入れる Python では破れないため
成り立ちます。最後の 3 つは、検証器が再計算した表で確認します。

- **棒はゼロから。** 軸の範囲を設定できないため、棒の長さが値を表します。
- **軸は 1 組。** 2 つ目の軸やパネルは作れません。
- **線形の目盛り。** 対数などの目盛りは設定できません。
- **目盛り。** プログラムは x の目盛りのラベルを回転できますが、目盛りの位置やラベルは設定できません。
- **数式のグラフ。** 数式のグラフは折れ線または散布図で、棒グラフにはなりません。
- **マーカーの大きさ。** 散布図の大きさのキーワード `s=` は受け入れないため、マーカーの大きさが値を表すことは
  ありません。
- **データの全範囲。** プログラムは行や軸の範囲を絞り込めないため、グラフは描画する各列の全体を表します。
- **行の欠落なし。** ファイルのすべての行が描かれるか、そのグループの集計に含まれます。合格した返信は、各グループの
  行数を示します。
- **カテゴリの重複なし。** テキストのカテゴリによる棒グラフでは、各カテゴリを 1 回だけ描きます。重複すると棒が
  重なるためです。
- **折れ線の x は順序どおり。** 2 列の折れ線グラフはファイルの順を保ちます。数値の x は減少せず、テキストの
  カテゴリはそれぞれ 1 回だけ現れます。グループ化の折れ線グラフは、各グループを並べ替えた順に 1 回ずつ描きます。
- **ラベル。** タイトル、軸ラベル、凡例のラベルは、検証器が認識できるファイルの列のうち、グラフが描かない列の名前を
  挙げてはいけません。グループ化したグラフでは、別の種類の集計（たとえば合計のグラフの `平均`）も挙げてはいけません。
  検証器が読むのは語だけなので、すべてのラベルを判断できるわけではありません。

| 理由 | 意味 |
|---|---|
| `category_not_unique` | グラフに同じカテゴリが 2 回以上あります。 |
| `x_not_ordered` | 折れ線の x の値が昇順ではありません。 |
| `label_not_consistent` | グラフのラベルが、グラフにない CSV の列または集計を挙げています。 |

<a id="check-render"></a>

### 9. ブラウザでグラフを描画

ブラウザは、モデルのプログラムを変更せずに Open WebUI のサンドボックス（Pyodide）で実行します。検証器が加えるのは、
描画した値を記録して PNG 画像を 1 枚保存する外側の処理だけです。ラベルまたはファイルに日本語の文字がある場合、検証器は
Open WebUI の日本語フォントもプログラムと一緒に送ります。グラフを描いている間は、チャットのタブを開いたままにして
ください。

| 理由 | 意味 |
|---|---|
| `no_browser` | グラフを描くブラウザのセッションがありません。 |
| `browser_timeout` | ブラウザが 60 秒以内に応答しませんでした。 |
| `browser_error` | ブラウザの呼び出しに失敗しました。 |
| `browser_no_answer` | チャットのタブが応答しませんでした。タブを開いたままにしてください。 |
| `reply_malformed` | ブラウザの応答の形式が不明です。 |
| `sandbox_unavailable` | Pyodide を読み込めません。このサイトの広告ブロッカーをオフにしてください。 |
| `sandbox_error` | ブラウザの実行環境がエラーを報告しました。 |
| `no_image` | ブラウザでの実行で PNG 画像が 1 枚だけ作られませんでした。 |

<a id="check-match"></a>

### 10. 描画された値を再計算した値と照合

検証器は、ブラウザが描画したと報告した値と、検証器が計算した値を比べます。実行では、1 組の軸に系列を 1 つだけ描く
必要があります。

- **ファイルの値** は、数値の誤差を許さず、再計算した値と完全に一致する必要があります。
- **数式の値** は、定めた数値誤差の範囲内である必要があります。ブラウザの数学ライブラリは、`sin`、`cos`、`tan`、
  `exp`、`log` とべき乗で、最後の 2 進数の桁が検証器と異なることがあります。そのため、描画した各値は、検証器が自分の
  値の周りに計算した範囲内にある必要があります。

| 理由 | 意味 |
|---|---|
| `no_observation` | ブラウザが描画した値を報告しませんでした。 |
| `observation_mismatch` | 描画された値が再計算した値と一致しません。 |

<a id="check-attach"></a>

### 11. 返信に画像を添付

Open WebUI は、グラフの画像を返信と一緒に保存します。保存できない場合、検証器は画像を表示しません。

| 理由 | 意味 |
|---|---|
| `publish_failed` | Open WebUI が画像を添付できませんでした。 |

<a id="limits"></a>

## 上限

検証器は、次の上限を超える処理を拒否します。

| 上限 | 値 | 対象 |
|---|---|---|
| `max_source_bytes` | 20,000 | プログラムのバイト数 |
| `max_tokens` | 4,000 | プログラムの Python トークン数 |
| `max_bracket_depth` | 16 | 括弧の入れ子 |
| `max_indent_depth` | 4 | インデントの入れ子 |
| `max_line_bytes` | 400 | プログラムの 1 行のバイト数 |
| `min_grid_samples` | 2 | 数式のグリッドの最少の点の数 |
| `max_grid_samples` | 100,000 | 数式のグリッドの最多の点の数 |
| `max_csv_bytes` | 8,000,000 | CSV ファイルのバイト数 |
| `max_csv_rows` | 100,000 | CSV ファイルのデータ行数 |
| `max_csv_columns` | 128 | CSV ファイルの列数 |
| `max_csv_cell_bytes` | 512 | CSV の 1 セルのバイト数 |
| `max_table_rows` | 100,000 | 描画する表の行数 |
| `max_expr_nodes` | 1,000 | 数式 1 つの要素数 |
| `max_groups` | 1,000 | グループ化したグラフのグループ数 |
| `max_work` | 390,000 | 再計算の作業量（約 1 秒分） |
