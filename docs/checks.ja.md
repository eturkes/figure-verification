# 図のチェック: 簡単なガイド

検証器は、次の 9 つのチェックにすべて合格したグラフだけを表示します。**チェック項目を表示** の
各行は、ここにある対応するチェックにリンクしています。すべての規則の詳細は
[リファレンス](verification.ja.md) をお読みください。[English](checks.md)

合格とは、グラフがこれらの規則に従い、データを用意した場合はその値がそのデータから来ていることを
意味します。グラフが質問に答えていることは意味しません。検証器はグラフ上の文字を判断しません。
また、プログラムを信頼しているため、検証器を欺こうとするプログラムはそれができます。プログラムは、
Open WebUI が実行する他のコードと同じく、添付ファイルを読み取り、ブラウザのネットワークに
アクセスできます。

<a id="check-program"></a>

### 1. モデルからグラフのプログラムを受信

モデルは、プログラムをグラフ用のツールで送る必要があります。不合格の場合は、もう一度依頼して
ください。[詳細](verification.ja.md#check-program)

<a id="check-run"></a>

### 2. ブラウザでプログラムを実行

プログラムは、Open WebUI のサンドボックスでエラーなく実行できる必要があります。numpy、pandas、
matplotlib は使えますが、seaborn は使えません。不合格の場合は、チャットのタブを開いたままにして、
もう一度試してください。[詳細](verification.ja.md#check-run)

<a id="check-figure"></a>

### 3. 図を 1 つ描画

プログラムは matplotlib の図をちょうど 1 つ描く必要があります。1 つの図には複数のパネルを
入れられます。[詳細](verification.ja.md#check-figure)

<a id="check-parts"></a>

### 4. 検証器がチェックできる部品だけを使用

グラフに使えるのは、折れ線、点、棒、ヒストグラム、円、面、基準線、テキストです。エラーバー、
箱ひげ図、画像、2 つ目の y 軸など、それ以外の部品があるとグラフは止まります。
[詳細](verification.ja.md#check-parts)

<a id="check-axes"></a>

### 5. 正しい軸

各軸は線形で通常の向きである必要があり、すべてのデータ点が軸の範囲の中にある必要があります。
棒グラフ、ヒストグラム、面グラフの値の軸はゼロを含む必要があります。対数軸は、そのラベルか
パネルのタイトルに `対数` とある場合に限り合格します。ゼロを含まない軸が必要な場合は、折れ線
グラフか散布図を依頼してください。[詳細](verification.ja.md#check-axes)

<a id="check-marks"></a>

### 6. 正しいグラフ要素

棒と面はゼロまたは積み上げの上から始まる必要があり、棒は重なってはいけません。ヒストグラムの棒は
正しい度数を、円グラフの扇形は正しい割合を示す必要があります。折れ線の点は x の順に並ぶ必要が
あります。マーカーの大きさや色が異なる場合は凡例かカラーバーが必要で、凡例はすべての系列を示す
必要があります。[詳細](verification.ja.md#check-marks)

<a id="check-values"></a>

### 7. 描画した値があなたのデータにある

描画した各値は、CSV ファイルの値か依頼文の数値である必要があります。合計のようなグループごとの
集計や、累計や割合のような簡単な計算でもかまいません。不合格の場合は、CSV ファイルを添付するか、
値とラベルを依頼文に書いてください。ファイルも数値もない場合、検証器はほかの規則だけを
チェックします。[詳細](verification.ja.md#check-values)

<a id="check-columns"></a>

### 8. 描いた列が依頼と一致

CSV ファイルを添付した場合は、グラフに描く各列の名前を依頼文に書いてください。タイトル、
軸ラベル、凡例は、グラフにない列や集計を挙げてはいけません。
[詳細](verification.ja.md#check-columns)

<a id="check-attach"></a>

### 9. 返信に画像を添付

Open WebUI がグラフの画像を返信と一緒に保存する必要があります。不合格の場合は、もう一度試して
ください。[詳細](verification.ja.md#check-attach)
